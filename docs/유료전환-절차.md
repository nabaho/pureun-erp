# 유료(Blaze) 전환 절차

작성 2026-08-07 · 프로젝트 `pureun-erp`

목적 — 사진을 실시간DB에서 **파일 창고(Storage)** 로 옮겨,
화질을 깎지 않고 용량 문제를 없앤다. 예상 실비 **월 0원**(무료 몫 안).

---

## 지금 상태 (확인 완료)

| | 상태 |
|---|---|
| 창고 주소 | `pureun-erp.firebasestorage.app` — 설정에 이미 있음 |
| 창고 SDK | 명함첩·사진첩 모두 이미 불러오고 있음 |
| 막는 것 | **요금제 하나뿐.** 신규 버킷은 유료에서만 열린다 |

즉 **요금제만 올리면 코드는 거의 그대로 이어 붙는다.**

---

## 대표님이 하실 일 (제가 대신 못 하는 부분)

결제 정보 입력은 제가 대신 할 수 없습니다. 아래 순서대로만 해주세요.

### 1단계 · 결제 계정을 법인으로 만든다  ⏱ 5분

Firebase 콘솔 → 왼쪽 아래 **⚙ → 사용량 및 결제 → 세부정보 및 설정** → **요금제 수정** → **Blaze**

계정을 새로 만들 때 **반드시 이렇게** 하세요.

| 칸 | 넣을 것 |
|---|---|
| 계정 유형 | **비즈니스** (개인 ✕) |
| 이름/상호 | 푸른노무법인 |
| 사업자등록번호 | 법인 사업자등록번호 |
| 주소 | 법인 주소 |
| 결제 수단 | **법인카드** |

> 나중에 바꾸기 번거롭습니다. 처음에 법인으로 넣으세요.
> 개인카드로 등록하면 비용처리 때 정산이 지저분해집니다.

### 2단계 · 예산 알림을 먼저 건다  ⏱ 3분 · **건너뛰지 마세요**

Google Cloud 콘솔 → **결제 → 예산 및 알림** → **예산 만들기**

- 이름: `푸른 파이어베이스`
- 금액: **월 30,000원**
- 알림: 50% / 90% / 100% 에서 메일

예상 사용량이 무료 몫 안이라 **이 알림이 울리면 뭔가 잘못된 것**입니다.
울리면 바로 알려주세요. 원인을 찾아 드립니다.

### 3단계 · 창고(Storage) 버킷을 만든다  ⏱ 2분

Firebase 콘솔 → **Storage** → **시작하기**

**위치(리전)는 `asia-northeast3 (서울)` 로 하세요.**

> ⚠ **위치는 나중에 못 바꿉니다.** 서울로 하는 이유 두 가지 —
> ① 직원들이 국내에서 쓰니 사진이 빨리 뜬다
> ② 명함 사진은 개인정보다. 국내에 두는 편이 설명하기 쉽다
> (실시간DB가 싱가포르인 것과 달라도 문제 없습니다)

규칙은 **「테스트 모드」가 아니라 「프로덕션 모드」** 로 시작하세요.
바로 다음 단계에서 제대로 된 규칙을 넣습니다.

### 4단계 · 창고 보안규칙을 붙여넣는다  ⏱ 2분

`docs/firebase-storage-규칙.txt` 파일 내용을 통째로 복사해서
Firebase 콘솔 → **Storage → Rules** 에 붙여넣고 **게시**.

### 5단계 · 여기까지 하고 알려주세요

「Blaze 됐고 서울로 버킷 만들었다」고 알려주시면
사진을 창고로 옮기는 작업을 제가 이어서 합니다.

---

## 그다음 제가 할 일

1. 명함첩이 사진을 **창고에 올리고 창고에서 읽도록** 고친다
2. 실시간DB `pucards/photos` 에 있는 사진을 **창고로 옮기는 도구**를 만든다
   (한 장씩 옮기고 확인되면 원본을 지운다 — 중간에 끊겨도 이어서)
3. 옮기고 나면 실시간DB 용량이 **1.7GB → 0.1GB** 로 떨어진다
4. 보관 화질을 되돌린다(명함 1600px / 서류는 2400px 로 올릴 수도 있다)
5. 사진첩(`pu-photos`)도 같은 방식으로 — `js/pu-photo-store.js` 의
   `var mode = 'rtdb'` 한 줄만 `'storage'` 로 바꾸면 되게 만들어 둔 상태

---

## ⚠ 그 전까지 하지 마실 것

**`pucardsShrinkPhotos()` 를 돌리지 마세요.**
지금 돌리면 원본 1600px 이 800px 로 덮어써지고 **되돌릴 수 없습니다.**
유료로 가면 원본 화질을 그대로 창고에 옮길 수 있으니, 깎을 이유가 없습니다.

용량이 급하면 이 둘만 하세요 — 화질과 무관하고 되돌릴 수 있습니다.

```
erpBackupPruneNow()      ERP 옛 백업 지우기
pucardsMoveThumbs()      명함첩 목록 가볍게 (사진 화질과 무관)
```

---

## 돈 이야기 정리

| 항목 | 무료 몫 | 우리 예상 | 초과분 요금 |
|---|---|---|---|
| 창고 보관 | 5GB | 약 1.7GB | — |
| 창고 내려받기 | 하루 1GB | 하루 0.1GB 안팎 | — |
| 실시간DB 보관 | 1GB | 사진 옮긴 뒤 0.3GB | — |
| 실시간DB 내려받기 | 월 10GB | 월 2~3GB | — |

**전부 무료 몫 안 → 월 0원.**
유료 전환의 값어치는 「돈을 더 내는 것」이 아니라
**같은 0원으로 화질을 지키고 용량 걱정을 없애는 것**입니다.

비용처리·부가세는 `docs/사진-화질-보관-장기방안.md` 와 별도 안내 참고.
계정과목은 ERP 「외부지급 → 시스템」.
