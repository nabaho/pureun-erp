# 급여 아웃소싱 자동화 — 하네스 1차 구축 지시문 (v2.1)

> **투입 방법**: 이 파일을 Claude Code 세션에 올리고 "이 지시문대로 하네스 1차 시작"이라고 요청.
> **v2.1 변경점**: D1(산정기간)·D2(동명이인) 조사 정식 편입 + 패밀리별 채점 분리 + 근태↔대장 매칭 키 실태 조사 추가.

## 배경
나는 노무법인 대표다. 약 110개 사업장의 급여 아웃소싱 자동화 시스템의 첫 단계로,
"골든(완성 급여대장) 파서 + 채점 기반"인 하네스를 만든다.
**이번 세션 목표는 하네스 1차뿐. 그 이상 만들지 마라.** (엔진·어댑터·서버·계산교정은 다음 세션.)

## 폴더
- `./samples/{담당자}/…/{월}/` = 완성 급여대장(골든)
- ※ 원본 zip을 리눅스에서 풀 경우 한글 파일명 CP949 주의(`unzip -O cp949` 또는 파이썬 cp437→cp949 재해석). 폴더 구조 없는 낱개 급여대장(담당자 루트에 존재)도 정상 입력으로 취급.
- ※ 실측: .xls 구형이 담당자 2명 합계 142개로 많음 — 1차는 규칙대로 건너뛰되 리포트에서 비중 확인, 크면 2차에서 .xls 판독(xlrd) 추가 결정.
- `./raw/` = 근태 원천
- `./payroll_mvp.html`, `./puerp/` = 참고(수정 금지)
- 결과 → `./harness/`

## 반드시 알아야 할 사실 (실측 확인)
1. 사업장은 급여 프로그램이 아니라 **수기 엑셀** — 고용보험 단수처리(절사/올림/반올림)가 뒤섞여 단일 규칙으로 전원 안 맞는다. 요율도 0.9%/0.899%/면제 혼재.
2. **국민연금·건강보험은 공단 고지액 그대로**(연금 월 고정, 건보 4월 변동) — 계산 재현 시도 금지.
3. **골든 자체에 오류 있을 수 있음** — 맹신 금지. 골든은 정답이 아니라 참고.
4. 지방소득세 = 소득세×10% 절사 (이 규칙만 확실).

## 목표 (이것만)

### 1) 골든 파서: 전 급여대장 엑셀 → 직원별 JSON
필드: `{성명, 입퇴사일, 유형추정, 기본급, 수당들, 과세총액, 소득세, 지방세, 연금, 건보, 장기, 고용, 공제총액, 실수령}`
- 2단 병합 헤더 평탄화 / 급여대장 시트 자동 식별(시트 혼재)
- **파일명 불신** — 내용으로 귀속월 판별(5월 폴더에 6월 파일 실재)
- 양식 패밀리 6종 태깅: 표준형 / 단순형 / ★DB형 / 직군분리형 / 근태기반형 / 연간누적형
- `.xls` 구형·손상·PDF는 건너뛰고 **사유 기록**
- **주민등록번호 추출 금지(성명만). 외부 API 전송 금지 — 전부 로컬.**

### 2) 단수처리 자동 판정
사업장별 고용보험 절사/올림/반올림 중 **최다 일치 방식** 리포트 (+요율 0.9%/0.899%/면제 편차 감지).

### 3) 산정 기간 자동 감지 (D1)
각 사업장 대장의 날짜 범위를 역산 → "1일~말일 / 26일~25일" 등 판별. 감지 실패 시 사유 기록.

### 4) 동명이인 실태 조사 (D2)
사업장 내 동일·유사 이름 목록화. 유사 판정은 이름 정규화(공백·한자·오타) 후 비교.

### 5) [신규] 근태↔대장 매칭 키 실태 조사
근태표엔 이름만 있고 주민번호 추출은 금지 → 이름만으로는 동명이인·투잡에서 매칭 필연 실패.
※ 근태 확보 현황: 주민정·박은비·김보람 3명분 있음 / 신욱임 근태 미제출 — 신욱임 담당 사업장은 "근태 미제출"로 기록하고 조사에서 제외, 추후 도착 시 증분 조사.
**대장·근태 양쪽에 어떤 매칭 키 후보가 실재하는지 조사**: 사번, 부서, 입사일, 직급, 연락처 뒷자리 등.
- 각 사업장별로 "이름 단독 매칭 가능 / 보조키 필요 / 매칭 불가" 3분류
- 근태·대장 이름 대조 시 한쪽에만 있는 이름(unmatched) 목록

### 6) [신규] 급여일 분포 조사
사업장별 급여 지급일(대장·파일명·내용에서 추정) 분포표 — 10일·25일·말일 집중도 파악(담당자 5명 처리 캘린더 설계용). 추정 불가 시 사유 기록.

### 7) 커버리지 리포트 (HTML 1장)
- 사업장 × 월 성공/부분/실패 표
- 사업장별 실수령 합계(눈대조용)
- 실패 사유
- 단수 판정 / 산정기간 / 동명이인 / 매칭 키 실태 / 급여일 분포

## 성공 기준 (v2.1 — 패밀리별 분리)
파싱 가능 엑셀(구형·손상·PDF 제외 = 모수 산출) 중 **전체 92%+**에서 직원별 실수령 추출.
**단, 전체 92%만 보지 말고 패밀리 6종 각각의 성공률을 별도 표기**한다.
- 특정 패밀리(특히 DB형)에 실패가 몰리면 전체 92%를 넘겨도 "그 패밀리는 실사용 불가"로 판정 → 리포트에 경고.
- 패밀리별 모수가 너무 작아(예: 3건 이하) 통계가 무의미하면 그렇게 명시.
- **모수 산출 근거를 리포트에 명시**: 전체 파일 N개 중 제외 M개(구형/손상/PDF 각각 몇 개), 파싱 대상 모수 = N−M.
