# 명함첩 → 다음메일 보내기

작성 2026-08-07 · 대상 `pu-cards.html`

## 왜 필요한가

명함 6,275건의 이름과 이메일이 명함첩에 있는데, 이걸로 메일을 보낼 길이 사실상 없다.

지금 있는 것은 `mailSel()` 하나뿐이고 이렇게 동작한다.

```js
location.href = `mailto:?bcc=${encodeURIComponent(emails.join(','))}`;
```

`mailto:` 주소는 **약 2,000자를 넘으면 동작하지 않는다.** 이메일 한 개가 평균 25자쯤이니

| 인원 | 주소 길이 | 결과 |
|---|---|---|
| 50명 | 약 1,250자 | 열린다 |
| 100명 | 약 2,500자 | **아무 반응 없이 실패** |

지금 「단체 메일」 단추는 **100명만 넘어도 조용히 실패한다.** 대표는 눌렀는데 아무 일도 안 일어나는 것을 보게 된다.

### 명함첩이 직접 메일을 보낼 수는 없다

명함첩은 서버 없는 정적 사이트(GitHub Pages)다. 발송 서버가 없으므로 **명함첩이 직접
메일을 쏘는 기능은 만들 수 없다.** 대표의 메일함을 열어 주거나, 주소를 넘겨 주는 데까지가
한계다. 이 설계는 그 전제 위에 있다.

### 다음메일 연결에 대해 확인한 것과 못 한 것

- **확인함**: `mailto:` 는 컴퓨터에 기본 메일로 등록된 프로그램을 연다. 다음메일을 기본으로
  등록해 두면 다음메일 쓰기창이 열린다(Chrome 은 `chrome://settings/handlers` 에서 관리).
- **확인 못 함**: 다음메일이 스스로 mailto 처리기 등록을 요청하는지, 다음 주소록이 정확히
  어떤 CSV 형식을 받는지. 확인하려면 대표 계정으로 로그인해야 하는데 그렇게 하지 않았다.

그래서 이 설계는 **mailto 에 기대지 않는 길(복사·내보내기)을 주된 수단으로** 삼는다.

## 정한 것 (대표 결정)

| 물음 | 결정 |
|---|---|
| 어떤 수단 | **주소 복사 + 주소록 CSV 내보내기 둘 다** |
| 용도 | 업무 연락과 광고·홍보성 안내 **둘 다** |
| 수신거부 | **명함별 체크 + 주소 목록 둘 다** |
| 광고 수신동의 | **명함첩에서 관리하지 않는다** — 다른 경로(계약서·상담신청서)에서 받고 있다 |

## 1. 거르는 규칙 — 한 곳에서만

복사와 내보내기가 **같은 함수**를 쓴다. 두 곳에 따로 만들면 한쪽만 고쳐져 수신거부한
사람에게 메일이 나간다.

```
선택한 명함
   ↓ ① 이메일 없음              → 뺀다
   ↓ ② 형식이 이상함 (a@b 꼴 아님) → 뺀다
   ↓ ③ 명함에 「수신거부」 체크    → 뺀다
   ↓ ④ 수신거부 목록에 있음       → 뺀다
   ↓ ⑤ 같은 주소가 여러 장        → 하나로 합친다
받는사람 명단
```

### 결과를 반드시 숫자로 보여준다

```
120명 준비됨 · 이메일 없음 45 · 수신거부 3 · 중복 12 제외
```

몇 명에게 나가는지 모르고 보내는 일이 없어야 한다. 특히 **수신거부로 빠진 수**는
반드시 보여준다 — 0 이 아닌데 안 보이면 거른 것을 믿을 수 없다.

### 주소 비교는 소문자로

`Hong@A.com` 과 `hong@a.com` 을 다른 사람으로 보면 거부한 사람에게 또 나간다.
비교 전에 앞뒤 공백을 지우고 소문자로 바꾼다.

### 저장하는 곳

| | 자리 | 뜻 |
|---|---|---|
| 명함별 체크 | 명함 기록의 `noMail` | 그 사람 명함을 열면 바로 보인다 |
| 주소 목록 | `pucards/config/mailBlock` (전 직원 공유) | 다음메일에서 받은 반송·거부 주소를 무더기로 붙여넣는다 |

`mailBlock` 은 **소문자 주소를 키로 하는 객체**로 둔다(`{ "hong@a.co.kr": true }`).
배열로 두면 같은 주소가 여러 번 들어가고 지울 때 번거롭다.

**잠긴 폴더의 명함은 대상에서 뺀다.** 이미 있는 `inLockedGroup(it)` 으로 거른다 —
공유 검색목록에서 빼는 데 쓰는 것과 같은 판단이다. 개인 폴더를 열어 둔 채 전체 선택을
하면 개인 명함이 단체 메일에 섞일 수 있다.

### 대상은 반드시 「선택한 명함」이다

엑셀 내보내기(`exportXlsx`)는 아무것도 안 골랐으면 **전체**를 내보낸다. 메일 쪽은 그렇게
하지 않는다 — 실수로 아무것도 안 고른 채 누르면 6,275명의 주소가 통째로 복사된다.
**하나도 안 골랐으면 "명함을 먼저 선택하세요" 라고 알리고 아무것도 하지 않는다.**

## 2. 화면 — 선택 도구모음

지금 줄에 두 단추를 이어 붙인다.

```
[3개 선택] 📁폴더이동 🏷탭에담기 👤담당자 📋단체복사
           📧 주소 복사   📇 주소록 내보내기   🗑삭제  선택해제
```

### 📧 주소 복사

받는사람 칸에 그대로 붙여넣게 쉼표로 묶어 복사한다.

```
hong@a.co.kr, kim@b.com, lee@c.kr
```

길이 제한이 없어 몇 명이든 된다. 다음메일 쓰기창을 열고 **숨은참조 칸**에 붙여넣는다.

복사 뒤 안내에 *"숨은참조 칸에 붙여넣으세요"* 를 함께 띄운다. 받는사람 칸에 넣으면
서로의 주소가 모두 노출된다 — 광고성 단체 메일에서는 그 자체가 사고다.

### 📇 주소록 내보내기

다음 주소록에 가져올 CSV 를 만든다.

```
이름,이메일,회사,직책,휴대폰
홍길동,hong@a.co.kr,가나상사,팀장,010-1111-2222
```

- 파일 이름 `명함첩_주소록_YYYY-MM-DD.csv`
- **UTF-8 BOM 을 붙인다.** 없으면 엑셀·주소록에서 한글이 깨진다
- 쉼표·따옴표·줄바꿈이 든 값은 따옴표로 감싸고 안쪽 따옴표는 두 번 쓴다

## 3. 화면 — 수신거부 관리

`⚙️환경설정 → 📥데이터` 안에 넣는다.

```
🚫 메일 수신거부 관리              현재 3명

┌──────────────────────────────────┐
│ hong@a.co.kr                     │
│ kim@b.com                        │
│ (한 줄에 하나씩 붙여넣으세요)      │
└──────────────────────────────────┘
        [저장]

※ 여기 있는 주소는 복사·내보내기에서 자동으로 빠집니다
```

다음메일에서 반송되거나 수신거부한 주소를 **그대로 긁어 붙여넣을 수 있어야 한다.**
줄마다 이름·날짜가 섞여 있어도 **이메일처럼 생긴 것만 골라낸다.** 형식을 맞춰 달라고
요구하면 결국 손으로 다듬게 되고, 그러면 안 쓰게 된다.

저장은 **덮어쓰기가 아니라 합치기**로 한다. 기존 목록에 더한다 — 실수로 빈 칸을 저장해
그동안 모은 거부 명단이 통째로 날아가는 일을 막는다. 지우려면 목록에서 개별로 지운다.

### 명함 하나만 거부 표시

명함 우클릭 메뉴에 **`🚫 메일 안 받음`** / **`✅ 메일 받음`** 을 넣는다(현재 상태에 따라 문구가 바뀐다).
전화로 "그만 보내주세요" 할 때 그 자리에서 누른다.

## 4. 기존 「단체 메일」 고치기

지금은 100명이 넘으면 아무 반응 없이 실패한다.

```
50명 이하 → 지금처럼 메일앱이 열린다
50명 초과 → "주소가 많아 메일앱이 안 열립니다. 주소를 복사했으니
             다음메일 숨은참조 칸에 붙여넣으세요" 안내하고 곧바로 복사해 준다
```

50 은 주소 길이 2,000자를 평균 25자로 나눈 80 에서 여유를 둔 값이다. 주소가 긴 회사
메일(부서명이 들어간 주소)이 섞이면 80 도 넘칠 수 있다.

## 잘못될 수 있는 곳과 대비

| 위험 | 대비 |
|---|---|
| 수신거부한 사람에게 메일이 나감 | 거르는 함수 하나만 두고 복사·내보내기가 같이 쓴다. 거른 수를 화면에 보여준다 |
| 대소문자가 달라 거부가 안 걸림 | 비교 전에 소문자로 바꾸고 공백을 지운다 |
| 거부 명단이 통째로 날아감 | 저장은 덮어쓰기가 아니라 합치기 |
| 받는사람 칸에 붙여넣어 주소가 모두 노출됨 | 복사할 때마다 "숨은참조 칸에" 안내를 띄운다 |
| 개인 폴더 명함이 단체 메일에 섞임 | `inLockedGroup(it)` 으로 거른다 |
| **아무것도 안 고른 채 눌러 6,275명이 복사됨** | 선택이 비면 알리고 아무것도 하지 않는다. 엑셀 내보내기와 달리 전체로 넘어가지 않는다 |
| CSV 한글 깨짐 | UTF-8 BOM 을 붙인다 |
| 다음 주소록이 이 CSV 를 못 읽음 | **먼저 2~3명으로 시험**하도록 안내한다. 6,000건을 먼저 넣으면 주소록이 엉킨다 |
| 단체 메일이 조용히 실패 | 50명 초과면 안내하고 복사로 넘긴다 |

## 확인 방법

`pu-cards.html` 은 빌드 없는 단일 파일이므로 이 파일이 이미 쓰는 방식을 따른다.

1. **문법 검사** — 인라인 `<script>` 를 뽑아 `node --check`.
2. **순수 로직 검사** (`node --test`, `vm` 샌드박스) — 거르는 함수만 떼어 검사한다.
   - 이메일 없는 명함이 빠지는지
   - `a@b` 꼴이 아닌 값이 빠지는지
   - `noMail` 체크된 명함이 빠지는지
   - 거부 목록에 있는 주소가 빠지는지, **대소문자가 달라도** 빠지는지
   - 같은 주소가 하나로 합쳐지는지
   - 센 숫자(준비·이메일없음·수신거부·중복)가 실제와 맞는지
   - 붙여넣은 글에서 이메일만 골라내는지 (이름·날짜가 섞여 있어도)
   - 잠긴 폴더 명함이 빠지는지
   - CSV 의 쉼표·따옴표·줄바꿈이 든 값이 깨지지 않는지
3. **기능 검사** (로컬 서버 + 브라우저 자동화)
   - 복사 단추를 눌렀을 때 클립보드에 들어가는 문자열이 정확한지
   - 50명 초과 단체 메일이 메일앱을 열지 않고 복사로 넘어가는지
   - 수신거부 저장이 기존 명단을 지우지 않고 합치는지
   - 내보낸 CSV 첫 줄에 BOM 이 붙는지

## 안 하기로 한 것

- **명함첩에서 메일 발송** — 서버가 없다. 만들 수 없다.
- **광고 수신동의 관리** — 다른 경로에서 받고 있다(대표 결정).
- **발송 이력 기록** — 명함첩이 보내지 않으므로 무엇이 나갔는지 알 수 없다. 안다고
  적어 두면 거짓이 된다.
- **다음메일 쓰기창 주소 직접 채우기** — 다음의 주소 형식을 확인할 수 없었다.
  확인되면 그때 더한다.
