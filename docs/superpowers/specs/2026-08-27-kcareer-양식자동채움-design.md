# kcareer 기관 양식 자동 채움 (1단계) — 설계서

2026-08-27. 대표 승인: 「순서대로」(1→2→3 단계 중 1단계).

## 0. 한 줄
기관이 준 한글(HWPX) 양식을 **그대로** 올리면, 앱이 표의 「성명」「연락처」「학력」「경력」
칸을 알아보고 프로필·경력 데이터를 채운 뒤, 한글 화면으로 보여 주고 PDF/HWPX로 저장한다.
`{{토큰}}`을 한글에서 손으로 넣던 단계를 없앤다.

## 1. 지금과 무엇이 다른가
- 지금: `hwpxFill`이 `{{성명}}` 같은 토큰만 바꾼다 → 양식마다 한글을 열어 토큰을 심어야 했다.
- 바꾼 뒤: 토큰이 있으면 그대로 쓰고(하위호환), **없어도** 표의 라벨 칸을 읽어
  바로 옆 빈 칸에 값을 넣는다. 결과는 즉시 「한글로 보기」로 떠서 사람이 확인한다.
- **완전 무인이 아니라 반자동이다.** 채운 결과를 눈으로 확인하고 저장하는 단계를 남긴다
  — 양식마다 칸 이름이 달라 100% 매핑은 불가능하고, 잘못 낸 서류가 확인 한 번보다 비싸다.

## 2. 판정 규칙 (순수 모듈 js/kcareer-hwpxfill.js)
- **단일 값**: 한 행 안에서 「라벨 칸 → 바로 다음 빈 칸」. 한 행에 라벨이 여러 개면 각각.
  라벨 사전(초판): 성명/이름/신청자(명)/성함→name · 생년월일/생일→birth · 성별→gender ·
  연락처/전화(번호)/휴대폰/핸드폰→phone · 이메일/전자우편/(E-)mail→email · 주소→addr ·
  자격(증)/보유자격→license · 소속(기관)/근무처/회사명→org
- **목록 표**(학력·경력): 머리행의 칸이 2개 이상 목록 열쇠와 맞으면 목록 표로 본다.
  학력 열쇠: 기간/연도→period · 학교(명)→school · 전공/학위/졸업→major
  경력 열쇠: 기간/연도→period · 기관/근무처/소속/발급기관→org · 직위/직책/내용/담당(업무)/활동→role
  school 열이 있으면 학력 표, 없고 org·role이 있으면 경력 표.
  머리행 **아래의 완전히 빈 행**에만 한 줄씩 채운다. 행이 모자라면 넣을 수 있는 만큼만 넣고
  「경력 12건 중 8건만 들어감(칸 부족)」을 보고한다. **행을 새로 만들지 않는다**(v1 —
  rowCnt·lineseg를 함께 고쳐야 해 위험).
- **빈 칸 판정**: `<hp:t></hp:t>`·`<hp:t/>`·run에 t 없음·문단에 run 없음 → 전부 빈 칸.
  글자가 한 자라도 있으면 **절대 덮지 않는다**.
- **안전선**: 셀 안에 표가 또 있는(중첩) 표는 건너뛴다(정규식 파서의 한계를 안전하게).
  값은 XML 이스케이프해서 넣는다.

## 3. 앱 연결 (kcareer.html)
- `hwpxFill(id)` 하나로 합친다: ①기존 토큰 치환 → ②남은 칸을 라벨 채움 →
  ③결과를 `openHwpViewer`로 표시(요약: 인적 N칸 · 학력 N줄 · 경력 N/M줄) → ④⬇ 저장.
  UI 버튼은 지금 그대로 「✏️ 값채우기」 — 사용자가 배울 게 없다.
- 데이터 출처는 빠른 이력서와 같다: `profile_info`(인적) · `edu`(학력) ·
  wiccok+consult+case+lecture+fund+etc(경력, renderQuickCV와 같은 매핑).
- **PDF**: 뷰어에 「🖨 PDF」 추가 — 이미 그려진 A4 캔버스를 이미지로 인쇄(@page A4 margin 0)
  → 한글 모양 그대로의 PDF. 브라우저 인쇄창에서 「PDF로 저장」 한 번.

## 4. 하지 않는 것 (1단계 범위 밖)
- 옛 .hwp(이진) 채움 — 「한글에서 hwpx로 저장해 올려주세요」 안내만.
- 빈 행 자동 추가, 사진 칸 채움, AI 라벨 판독(성공률 보고 2차에 검토).
- 회의·강의비 동의서/서명/메일(2·3단계).

## 5. 검증
- 순수 모듈 테스트: 라벨 변형·이웃 빈 칸·비어 있지 않으면 안 덮음·목록 표 머리행 인식·
  행 부족 보고·중첩 표 건너뜀·XML 이스케이프. 픽스처는 hwpx_gen.tablePara로 **진짜 모양** 생성.
- 통합: hwpx_gen으로 양식을 만들어 zip까지 돌리고 rhwp inspect로 열리는지 확인.
