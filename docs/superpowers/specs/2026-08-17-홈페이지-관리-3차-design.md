# 홈페이지 관리 3차 — 화면 배치와 퇴사 처리

작성일 2026-08-17 · 목업 `docs/mockups/homepage-manage-v4.html` (승인)
1차 `2026-08-16-홈페이지-관리-design.md` · 2차 `2026-08-17-홈페이지-관리-2차-design.md`

대표 지시 세 가지. **1·2차의 판정 규칙과 안전장치는 하나도 바꾸지 않는다.** 이번은 화면 문제다.

## 1. 「홈페이지에 남기기」가 눌리지 않는다 — 가장 급한 것

사유를 받는 창을 브라우저 기본 `prompt()` 로 만들었다. **앱으로 설치해 쓰는 창에서는 차단된다.**
눌러도 아무 일이 없고 오류도 안 뜨니 「클릭이 안 된다」로 보인다.

**기본 창을 전부 화면 안 창으로 바꾼다.** `prompt` 4곳, `confirm` 4곳, `alert` 이 대상이다.

- 사유 입력은 화면 안 여러 줄 입력칸으로 받는다. **사유가 비면 저장하지 않고 왜 안 했는지 말한다**
  (2차 설계 §4 의 「사유를 반드시」는 그대로다)
- 예외 풀기·쪽 추가·목록에서 분리·되돌리기 확인도 같은 방식으로 바꾼다
- 알림도 화면 안에서 보여준다. 기본 창에 의존하면 안 된다

## 2. 누를 때마다 화면이 흔들린다

오른쪽 편집칸 높이가 사람마다 다르다(박성수 7줄 / 권형하 18줄). 그래서 **페이지 전체 길이가
늘었다 줄었다** 하고 스크롤이 튄다. 쪽을 고르면 안내 상자가 붙어 더 심하다.

**틀을 붙박이로 만든다.**

| 바꾸는 것 | 왜 |
|---|---|
| 몸통 높이를 창에 맞춰 고정 | 고르는 대상이 바뀌어도 페이지 길이가 안 바뀐다 |
| 목록·편집칸을 **각각 따로** 굴린다 | 목록을 굴려도 편집칸이 안 움직인다 |
| 편집칸 **머리(안내 띠)와 발(단추줄)을 고정** | 경력이 길어도 「저장」·「복사」가 늘 같은 자리 |
| 목록 줄 높이 62px 고정 | 딱지가 둘이어도 줄이 안 밀린다 |
| 페이지 자체는 굴리지 않는다 | 흔들림의 뿌리 |

**상단 고정**: 머리띠(제목·확인 시각·단추)와 갈래를 위에 붙인다.

**갈래를 왼쪽 기둥에서 상단 탭으로 옮긴다.** 기둥 168px 을 되찾아 목록을 **268 → 360px** 로 넓힌다.
이름·직책·딱지가 겹치지 않고 한눈에 보인다.

**눈이 편하게**: 배경·선을 한 톤 낮추고 **딱지만 색을 남긴다.** 상태 없는 줄은 흰 딱지라 눈에 안 걸리고,
퇴사·남김·명부없음만 도드라진다. 글자 14px, 줄간 1.7.

## 3. 퇴사 정보가 「확인 전」에는 안 보인다

지금은 「홈페이지 다시 확인」을 눌러야 퇴사가 보인다. 그런데 **퇴사 여부는 홈페이지와 상관없이
푸른ERP 명부만 보면 아는 것**이다. 확인을 누르기 전에도 보여준다.

- 목록 줄에 `퇴사 2026-06-30` 처럼 **명부 기준 딱지**를 대조 딱지와 **따로** 보여준다
- 목록 머리에 「구성원 9명 · 퇴사 3」처럼 몇 명인지 적는다
- 편집칸 머리에 띠로 알리고, **내리는 방법**(삭제가 아니라 비공개)을 함께 적는다
- 명부에 없는 사람은 「명부에 없음」으로 밝힌다

**대조 딱지와 명부 딱지는 다른 것이다.** 섞지 않는다 — 대조 딱지는 「홈페이지 다시 확인」을
누를 때만 새로 붙고, 명부 딱지는 화면을 열 때 바로 붙는다.

## 안 바꾸는 것

- **총괄관리자만** 쓰는 구조 (대표가 못 박은 사항)
- 대조 규칙(`tidy`·`signature`·`parsePageText`)과 딱지 판정
- 「홈페이지로 글을 보내지 않는다」 — 나가는 요청은 `readHomepage` 하나뿐
- 홈페이지에서 사람을 자동으로 내리기 — 여전히 사람이 확인 후 비공개로 바꾼다
- 쪽은 대조 전용(붙여넣기 없음)
