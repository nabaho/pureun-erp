# 기업정보 — 폴더와 탭 (사업별로 모아 관리하기)

작성 2026-08-13 · 대상 `pu-cards.html`, `js/pu-doc-file.js`

## 왜 필요한가

대표의 말: *"컨설팅 신청이 들어온 사업장 정리하고 관리하기 위함이다. 개별 계약서
작성 및 정부사업 신청서 등을 받아서 관리 정리하고 싶은 것이다."*

지금 기업정보의 폴더는 **저절로 생기는 것 셋뿐**이다.

```
📋 전체 4,141      모든 회사
🏢 거래처만  184   푸른이알피 업체관리에 있는 곳
📁 <서류이름>      사진첩에서 그 서식을 보낼 때 저절로 생김
```

문제는 **사람이 손으로 만들 수 없다는 것**이다. 실제 일은 이렇게 돌아간다.

```
① 「2026 통합기술보호지원반」 사업 공고가 뜬다
② 사업장 여러 곳에서 컨설팅 신청이 들어온다
③ 신청서·계약서를 받아 사진첩에 담는다
④ 「이 사업에 신청한 곳이 어디어디였지」를 한 자리에서 봐야 한다
```

④를 지금은 못 한다. 사업 폴더가 **서류 이름으로만** 생기는데, 같은 사업이라도
서류 이름이 제각각이다(신청서·계약서·자가진단 결과…). 그래서 한 사업이 여러 폴더로
흩어지고, 반대로 사업 이름과 서류 이름이 다르면 아예 안 묶인다.

## 사업자 갈래는 이미 이 구조를 갖고 있다

베낄 본이 이미 있다 — 새로 설계할 것이 아니라 **같은 모양으로 맞추면 된다.**

| | 사업자 | 기업정보(지금) |
|---|---|---|
| 옆줄 폴더 | `1.업체관리 86` `2.기타 사업장` `우리법인` … 손으로 만듦 | 저절로 생기는 셋뿐 |
| 위 탭 | `전체 344` `자문 63` `급여 50` … `＋탭 추가` | 없음 |
| 저장 자리 | `pucards/groups` (폴더) · `views` (탭) | 없음 |

## 만들 것

### 1. 폴더 — 손으로 만들고 회사를 담는다

```
pucards/coFolders/<id> = { name, ord, at, by }
pucards/coInfo/<회사열쇠>/folder = <폴더id>
```

- 옆줄 「폴더」 아래에 `＋` 를 둔다. 명함·사업자와 같은 자리, 같은 손놀림.
- 회사는 **한 폴더에만** 든다(명함 폴더와 같은 규칙). 여러 사업에 걸치는 것은
  아래 「사업 탭」이 맡는다 — 둘을 한 가지로 만들면 「이 회사가 왜 여기 있지」가 된다.
- 담는 길: 목록에서 네모로 고른 뒤 **「📁 폴더로 옮기기」**. 네모와 전체 고르기는 이미 있다.

### 2. 탭 — 여러 사업에 겹쳐 드는 것을 다룬다

지금 자동으로 생기는 「사업 갈래」(`coInfo/<키>/tags`)를 **탭으로 올리고 손으로도
만들 수 있게** 한다. 저장 자리는 그대로 쓴다.

```
[전체 4,141] [거래처만 184] [2026 통합기술보호 12] [기술·경영 혁신 5] [＋탭 추가]
```

- 한 회사가 **여러 탭에 들 수 있다.** 사업은 겹치는 것이 정상이다.
- 사진첩에서 서식을 보낼 때 붙는 딱지가 곧 탭이다 — 지금 동작을 그대로 잇는다.
- `＋탭 추가` 로 만든 탭에는 목록에서 골라 담는다.

### 3. 폴더와 탭을 왜 둘 다 두나

하나로 합치자는 생각이 들지만 **성질이 다르다.**

| | 폴더 | 탭 |
|---|---|---|
| 뜻 | 이 회사는 **무엇인가** (거래처·잠재고객·기관) | 이 회사가 **무엇에 참여했나** |
| 겹침 | 한 곳만 | 여럿 |
| 언제 바뀌나 | 드물게 | 사업마다 |

합치면 「2026 통합기술보호」에 넣는 순간 「거래처」에서 빠진다. 그건 틀렸다.

## 잘못될 수 있는 곳과 대비

| 위험 | 대비 |
|---|---|
| 회사 열쇠가 바뀌어 폴더가 끊어짐 | 열쇠는 **사업자번호**다. 번호가 생기면(등록증이 나중에 옴) 이름 열쇠에 있던 폴더·탭을 옮겨 붙인다 |
| 폴더를 지우면 안에 있던 회사가 사라져 보임 | 폴더를 지우면 그 안 회사는 **폴더 없음**으로 돌아간다. 회사 자체는 안 지운다 |
| 탭 이름에 `. # $ [ ] /` | 실시간DB 열쇠에 못 쓴다. 이미 `sendToCoInfo` 가 빼내고 있다 — 손으로 만들 때도 같이 뺀다 |
| 4,141곳에서 고르다 실수 | 「폴더로 옮기기」는 **고른 수를 보여주고** 확인을 받는다 |
| 사업이 끝나도 탭이 쌓임 | 탭에 **숨기기**를 둔다. 지우면 어느 회사가 그 사업이었는지 잃는다 |

## 확인 방법

1. **순수 로직** (`node --test`) — 폴더·탭 붙이기/떼기, 열쇠가 바뀔 때 옮겨 붙기,
   못 쓰는 글자 빼기, 폴더 지웠을 때 회사가 안 사라지는지.
2. **화면** — 옆줄 `＋` 로 폴더를 만들고, 목록에서 셋을 골라 담고, 그 폴더를 눌러
   셋만 나오는지. 탭도 같게.
3. **실제 자료** — 대표의 컨설팅 건 하나를 사진첩에서 보내 그 사업 탭에 들어오는지.

## 안 하기로 한 것

- **폴더 안 폴더** — 명함·사업자도 1단계다. 여기만 다르면 헷갈린다.
- **회사를 손으로 새로 만들기** — 기업정보는 이미 있는 것(사업자등록증·명함·ERP)을
  모아 보는 화면이다. 여기서 만들면 어디에도 없는 유령 회사가 생긴다.
- **탭 지우기** — 숨기기만 둔다.
