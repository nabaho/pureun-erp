# kcareer 증명서 보관 구현계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 외부기관이 발급해준 실적증명서·경력증명서 PDF를 위촉장 수준으로 관리한다 — 폴더 스캔 일괄 등록, OCR로 발급기관·발급일 추출, 표 목록, 외부기관 실적과 양방향 연결.

**Architecture:** 기존 `경력증명서 보관`(`DOMAINS.certdoc` + `renderDocStore`)을 살린다. 레코드에 `docSrc`(made/received)를 달아 두 종류를 나누고, `certdoc`에서만 카드 대신 표로 그린다. 판정 규칙은 이미 테스트된 `js/kcareer-scan.js`를 재사용하고, 원본은 위촉장과 같이 경로 참조(`src:'fs'`, `relPath`)한다.

**Tech Stack:** 순수 ES5 스타일 JS(빌드 없음), File System Access API, Gemini/Claude OCR, `node:test` + `node:assert/strict`

**설계서:** `docs/superpowers/specs/2026-08-01-kcareer-증명서보관-design.md`

## Global Constraints

- **`made`(직접 만든 증명서)는 스캔·OCR·정규화가 건드리지 않는다.** 기존 발급 흐름(양식 가져오기·채우기·저장)은 그대로다.
- 원본은 **복사하지 않고 경로 참조**(`src:'fs'`, `relPath`). 끌어다 놓기로 들어온 폴더 밖 파일만 base64 저장.
- **서류 폴더는 위촉장 작업에서 연결된 핸들(`fsRoot()`)을 그대로 쓴다.** 폴더를 다시 지정하지 않는다.
- 스캔은 **미리보기 → [등록]**. `scanId` 단위 되돌리기. 등록된 `relPath`는 건너뛴다.
- **OCR을 자동 실행하지 않는다.** 행의 `🔍 다시 읽기`를 누를 때만. (41개 자동 실행 금지)
- **환경설정으로 안내하는 문구 금지** — 비관리자에게 숨겨져 막다른 길이 된다(회귀테스트 있음).
- 반복문 안에서 `set()` 금지 — 스토어별 단일 쓰기.
- `pu-erp data/` 읽기는 `_puUnwrap()`을 거친다(봉투 형식).
- 작업 폴더는 `C:\Users\fair0\Documents\pureunall-kcareer` (main 고정). 매 태스크 끝 즉시 커밋, push 전 `git pull --rebase origin main`.

## 코드 사실 (2026-08-01 확인)

- `DOMAINS.certdoc`(kcareer.html:2687): `store:'certdoc'`, `extra:[issuer, usage, coverage]`, `body:'cdBody'`, `search:'cdSearch'`, `orgFilter:'cdOrgFilter'`, `cnt:'cdCnt'`, `addExisting:'cdAddExisting'`.
- `renderDocStore(domain)`(:3009): 연도별 **카드**를 그린다. 검색은 `kind·org·memo·year`. 카드에 `showBig(r.genFileId)`를 **무조건** 그린다.
- `confirmResumeSave()`(:2980)가 저장하는 필드: `{id, kind, year, org, memo, genFileId, genName, origFileId, origName, submits:[], savedAt}` + extra 3개.
  `mode==='existing'`이면 업로드 파일을 `genFileId=id`로 저장하므로 **업로드 경로는 정상 동작한다.**
- **⚠ 필드 이름이 어긋나 있다.** `fsCommitScan`의 certdoc 분기는
  `{id, title, org, date, note, fname, src:'fs', relPath, ...}`를 쓴다. 화면은 `kind·year·memo`를 읽는다.
  그래서 스캔으로 들어온 **14건은 종류가 `-`, 연도 묶음이 `undefined`, `📄 경력증명서` 버튼이 빈 것을 가리킨다.**
  → Task 1에서 쓰는 쪽(`fsCommitScan`)을 고치고 이미 들어온 것은 정규화한다.
- **끌어다 놓기는 이미 완성돼 있다**: `pageDropFile`(:3540) → certdoc은 `CAREER_CFG`에 없으므로
  doc-store 경로 → `_docQueue` → `_nextDocQueue()` → `openDocSaveModal(domain,'existing',file)`.
  여러 파일도 순차 처리한다. **이번에 만들 것은 없고**, Task 4에서 OCR 자동 채움만 얹는다.
- 재사용: `KcareerScan.classify/cleanCore`, `fsRoot()`, `openLocalOriginal`, `hasOriginal`, `openOriginal`,
  `matchByFilename`, `_agencyNorm`, `renderPuAgency`, `_geminiOCR`, `PAGE_OCR_PROMPT`.

**3-1.** `renderDocStore` 함수(3009행) **바로 위**에 추가:

```js
/* ===== 증명서 출처 구분 =====
   경력증명서 보관은 '내가 만들어 발급하는 증명서'를 전제로 만들어졌다(genFileId).
   외부기관이 발급해준 것은 만든 파일이 없고 받은 PDF 하나뿐이라 구분이 필요하다. */
function _cdSrc(r){
  if(!r) return 'made';
  if(r.docSrc) return r.docSrc;
  if(r.relPath || (!r.genFileId && r.fname)) return 'received';   /* 스캔·업로드로 들어온 것 */
  return 'made';
}

/* 스캔이 남긴 어긋난 필드 이름을 화면이 읽는 이름으로 옮긴다(앱 시작 시 1회, 멱등).
   fsCommitScan이 title·date·note로 쓰던 것을 화면은 kind·year·memo로 읽어
   종류가 '-', 연도 묶음이 undefined로 나왔다. */
function _cdNormalize(){
  var arr = get('certdoc'), n = 0;
  arr.forEach(function(r){
    if(_cdSrc(r) !== 'received') return;
    if(!r.kind && r.title){ r.kind = r.title; n++; }
    if(!r.year){ var d = r.date || r.fileMtime || ''; if(d){ r.year = String(d).slice(0,4); } }
    if(!r.memo && r.note) r.memo = r.note;
    if(!r.submits) r.submits = [];
    if(!r.docSrc) r.docSrc = 'received';
  });
  if(n) set('certdoc', arr);
  return n;
}
```

> `n`은 `kind`를 새로 채운 건수만 센다. 나머지는 딸려 오는 정리라 두 번째 실행에서 0이 나온다.

function _cdFindAttachTarget(file, db){
  var pool = (db||[]).filter(function(r){ return _cdSrc(r)==='received' && !hasOriginal(r); });
  if(!pool.length) return null;
  /* matchByFilename은 org·titleVal/title을 보므로 issuer를 org 자리에 얹은 사본으로 넘긴다 */

function cdScanCommit(){
  if(!_cdScanCtx){ toast('스캔 결과가 없습니다'); return; }
  var c = _cdScanCtx, db = get('certdoc'), n = 0, att = 0;
  var seq = 1;

    var mk = function(){ return 'CD' + String(seq).padStart(4,'0'); };
    while(db.some(function(x){ return x.id === mk(); })) seq++;
    return mk();
  }
  c.adds.forEach(function(f){
    db.unshift({ id: nextId(), kind: KcareerScan.cleanCore(f.name), org: '', issuer: '', usage: '', coverage: '',
      year: (String(f.name).match(/(20\d{2})/)||[])[1] || String(f.mtime||'').slice(0,4), date: '', memo: '',
      docSrc: 'received', src: 'fs', relPath: f.relPath, fileSize: f.size, fileMtime: f.mtime,
      scanId: c.scanId, submits: [], savedAt: new Date().toISOString() });
    n++;
  });

    var r = db.find(function(x){ return x.id === a.id; });
    if(!r) return;
    r.src = 'fs'; r.relPath = a.f.relPath; r.fileSize = a.f.size; r.fileMtime = a.f.mtime;

function cdUndoScan(scanId){

  var left = db.filter(function(r){ return r.scanId !== scanId; });

}

    var root = await fsRoot();
    if(!root){ toast('서류 폴더가 연결돼 있지 않습니다 — 위촉장 › ⋯ 더보기 › 서류 폴더 연결'); return null; }
    var segs = String(r.relPath).split('/'), dir = root;
    for(var i = 0; i < segs.length - 1; i++) dir = await dir.getDirectoryHandle(segs[i]);
    var fh = await dir.getFileHandle(segs[segs.length - 1]);
    var f = await fh.getFile();
    ext = (segs[segs.length - 1].split('.').pop() || '').toLowerCase();
    b64 = abToB64(await f.arrayBuffer());
  } else {
    var g = await getFileAsync(r.genFileId || r.id);
    if(!g || !g.base64){ toast('원본이 없습니다'); return null; }
    ext = (g.ext || (g.name || '').split('.').pop() || '').toLowerCase();
    b64 = g.base64;
  }
  var mime = ext === 'pdf' ? 'application/pdf' : ext === 'png' ? 'image/png' : 'image/jpeg';
  if(['hwp','hwpx','docx'].indexOf(ext) >= 0){ toast('HWP·DOCX는 OCR로 읽을 수 없습니다 — 손으로 입력해 주세요'); return null; }
  return { b64: b64, mime: mime };
}

/* 행의 🔍 — 사람이 누를 때만 OCR한다(41개 자동 실행 금지) */
async function cdReOcr(id){
  var db = get('certdoc'), r = db.find(function(x){ return x.id === id; });
  if(!r){ toast('증명서를 찾을 수 없습니다'); return; }
  if(_cdSrc(r) !== 'received'){ toast('직접 만든 증명서는 다시 읽기 대상이 아닙니다'); return; }
  if(!getGeminiKey() && !getApiKey()){ toast('API 키가 필요합니다 — ⋯ 더보기에서 키를 넣어주세요'); return; }
  toast('⏳ 증명서 읽는 중…');
  try{
    var got = await _cdFileBytes(r);
    if(!got) return;
    var parsed = null;
    var gj = await _geminiOCR(PAGE_OCR_PROMPT.certdoc, got.b64, got.mime);
    if(gj && gj.parsed) parsed = gj.parsed;
    if(!parsed){ toast('읽지 못했습니다 — 손으로 입력해 주세요'); return; }
    if(parsed.kind) r.kind = parsed.kind;
    if(parsed.issuer){ r.issuer = parsed.issuer; if(!r.org) r.org = parsed.issuer; }
    if(parsed.date){ r.date = parsed.date; r.year = String(parsed.date).slice(0,4); }
    if(parsed.coverage) r.coverage = parsed.coverage;
    if(parsed.usage && !r.usage) r.usage = parsed.usage;
    set('certdoc', db);
    renderDocStore('certdoc');
    toast('✅ ' + (parsed.issuer || '') + ' ' + (parsed.date || '') + ' — 확인해 주세요');
  }catch(e){ console.warn('cdReOcr', e); toast('읽기 실패 — 원본을 확인해 주세요'); }
}
