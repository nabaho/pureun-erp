# 명함첩 개인 폴더 진짜 잠금 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 잠긴 폴더의 명함·사진·폴더 이름을 대표 계정만 읽을 수 있는 창고로 옮겨, 화면에서 가리던 것을 서버 규칙이 막게 바꾼다.

**Architecture:** 잠긴 자료를 `pucards_private/<대표uid>/` 로 옮기고 Firebase 규칙 `auth.uid === $uid` 로 막는다(같은 저장소의 푸른사진첩과 같은 방식). 앱은 비밀번호가 맞은 뒤에만 그 경로를 구독한다 — 맞히기 전에는 브라우저에 자료가 오지 않는다. 비밀번호는 저장하지 않고 PBKDF2 해시로 검사만 한다.

**Tech Stack:** 빌드 없는 단일 HTML + 바닐라 JS · Firebase RTDB(compat 10.12) · `crypto.subtle` (PBKDF2) · 검사는 `node --test` + `vm` 샌드박스

- [ ] **Step 3: 순수 로직 구현**

`pu-cards.html` 파일 끝에서 마지막 `</script>` 를 찾아, 그 **바로 위**에 넣는다.

```js
/* ══════ 개인 창고 — 순수 로직 (테스트 대상) ══════
   비밀번호를 저장하지 않는다. 같은 방식으로 다시 계산해 견주기만 한다.
   자료를 들여다봐도 비밀번호를 알아낼 수 없다. */
const PW_ITER = 100000;
const _b64 = buf => btoa(String.fromCharCode.apply(null, new Uint8Array(buf)));
const _unb64 = s => { const b=atob(s); const u=new Uint8Array(b.length);
  for(let i=0;i<b.length;i++) u[i]=b.charCodeAt(i); return u; };
function newSalt(){ const u=new Uint8Array(16); crypto.getRandomValues(u); return _b64(u.buffer); }
async function pwHash(pw, saltB64, iter){
  const enc = new TextEncoder();
  const key = await crypto.subtle.importKey('raw', enc.encode(String(pw)), 'PBKDF2', false, ['deriveBits']);
  const bits = await crypto.subtle.deriveBits(
    { name:'PBKDF2', salt:_unb64(saltB64), iterations: iter||PW_ITER, hash:'SHA-256' }, key, 256);
  return _b64(bits);
}
/* 옮길 자리 목록을 만든다 — 값이 아니라 '어느 경로를 건드리는가'가 핵심이라
   그것만 따로 계산해 검사할 수 있게 뺐다.
   dir='lock'   공용 → 개인 (공용 자리는 null 로 지운다)
   dir='unlock' 개인 → 공용 (개인 자리는 null 로 지운다)
   실제 값(명함 내용·사진)은 화면 쪽에서 채워 넣는다. */
function movePaths(ids, gid, dir){
  const P = privRoot(); const out = {};
  const lock = dir === 'lock';
  (ids||[]).forEach(id=>{
    out[`${P}/items/${id}`]  = lock ? 1 : null;
    out[`${P}/photos/${id}`] = lock ? 1 : null;
    out[`${DB_ROOT}/items/${id}`]  = lock ? null : 1;
    out[`${DB_ROOT}/photos/${id}`] = lock ? null : 1;
    /* 공유 검색목록에는 잠글 때도 풀 때도 '지우기'만 넣거나(잠글 때)
       되살릴 값을 넣는다(풀 때). 개인 명함이 여기 남으면 다른 앱이 읽는다. */
    out[`${DB_ROOT}/idx/${id}`] = lock ? null : 1;
  });
  out[`${P}/groups/${gid}`]        = lock ? 1 : null;
  out[`${DB_ROOT}/groups/${gid}`]  = lock ? null : 1;
  return out;
}
/* ══════ 개인 창고 — 화면 ══════ */
```

- [ ] **Step 3: 옛 폴더 열기 함수 정리**

3685~3697행 `function tryUnlockFolder(id){...}` 전체를 바꾼다. 새 구조에서는 개인 폴더가 이미 비밀번호를 지나 열려 있으므로 따로 물을 것이 없다. 옛 방식으로 잠긴 폴더(아직 안 옮긴 것)만 기존처럼 처리한다.

```js
/* 폴더를 열 수 있나.
   새 방식(개인 창고)은 이미 비밀번호를 지나 열려 있으므로 그냥 통과시킨다.
   옛 방식으로 잠긴 폴더는 아직 안 옮긴 것이라 예전대로 비밀번호를 묻는다. */
function tryUnlockFolder(id){
  if(state.priv.groups[id]) return true;
  const g=state.groups[id]; if(!g) return false;
  if(!g.locked) return true;
  if(state.unlocked && state.unlocked[id]) return true;

  if(pw!==g.pw){ toast('비밀번호가 틀렸습니다'); return false; }
  if(!state.unlocked) state.unlocked={};
  state.unlocked[id]=true;
  toast('잠금을 풀었습니다 (이 세션 동안 표시)');
  return true;
}
```
