# 푸른카메라 — 카메라 하나 · 찍으면 알아서 제자리로

**2026-08-08** · 대표 지시
> "스마트폰에서 리멤버처럼 독립적인 카메라 기능 만들어 줄 수 있나"
> "카메라는 하나로 하고 알아서 자동으로 위치로 보내는 기능을 만드는 게 좋을 것 같은데"

---

## 1. 지금 어디까지 되어 있나

**자동 배송은 이미 절반이 돌아가고 있습니다.** 사진첩에 담기면 AI가 읽고, 검증을 통과한 것은 사람 손 없이 제자리로 갑니다.

| 찍은 것 | 지금 | 사람이 하는 일 |
|---|---|---|
| 명함 | → **명함첩** 자동 | 없음 |
| 사업자등록증·중소기업확인서 | → **명함첩 + 업체관리** 자동 (빈 칸만 채움) | 없음 |
| 회의·현장 사진 | → 사진첩에 남음 | 컨설팅에서 **당겨감** |
| 급여서류 | → 사진첩에 남고 「지우세요」 경고 | 지움 |
| 검증에 걸린 것 | → 사진첩에 남고 **「확인 필요」** | 열어 보고 「확인했음」 |

> ⚠ **회의·현장 사진을 컨설팅에 자동으로 붙이는 것은 대표님이 2026-08-02 에 범위에서 빼신 것**입니다("사진첩은 보관까지, 각 프로그램에서 업무수행자가 스스로 조정해 입력"). 이 계획서도 그 결정을 지킵니다.

## 2. 그런데 카메라가 둘입니다

| | 어디 | 찍으면 |
|---|---|---|
| **푸른카메라** `pu-camera.html` (525줄) | 독립 앱. 포털 타일에 **없음** — 폰에 설치한 사람만 씀 | **명함첩으로 직행** (자동 분류 없음) |
| **사진첩 카메라** `pu-photos.html` 안 | 연속촬영·명함틀·손전등·탭 초점 | 사진첩 → **자동 배송** |

**같은 명함을 어느 카메라로 찍느냐에 따라 가는 곳이 다릅니다.** 그리고 촬영 코드가 두 벌이라 한쪽만 고치는 사고가 납니다(주석에도 "푸른카메라에서 검증된 순서를 그대로 가져왔다"고 적혀 있습니다 — 복사본이라는 뜻입니다).

## 3. 그리고 배송이 눈에 안 보입니다

지금은 **찍고 나서 카메라를 닫고 목록을 봐야** 어디로 갔는지 압니다. 「알아서 보낸다」는 느낌이 안 나는 진짜 이유가 이것입니다.

---

## 4. 이렇게 만듭니다

### 코드는 하나, 입구는 둘

- **촬영 코드는 사진첩 것 하나만** 남깁니다(연속촬영·명함틀·손전등·탭 초점이 다 여기 있습니다)
- `pu-camera.html` 은 **껍데기만 남기고** 열리면 곧바로 사진첩 카메라로 넘깁니다
  → 폰에 이미 설치한 분의 **아이콘·바로가기가 그대로 살아 있고**, 누르면 **바로 카메라**가 켜집니다
- 사진첩 안에서도 지금처럼 카메라를 엽니다

**대표님이 원하신 「카메라 하나」와 「홈에서 바로」를 둘 다 지키는 방법입니다.**

### 찍으면 배송표가 뜹니다

카메라를 닫지 않고, 찍은 사진 아래에 **한 줄씩 쌓입니다.**

```
📇 김철수 · 푸른노무법인        → 명함첩       ✓
🏢 (주)대한산업                → 명함첩·업체관리 ✓
📷 현장 사진                    → 사진첩에 보관
⚠ 사업자번호를 다시 봐 주세요   → 확인 필요
🚫 급여서류 — 보관하지 않습니다  [지금 지우기]
```

- 판독은 **뒤에서** 돌고 카메라는 계속 켜져 있습니다(기다리지 않음)
- 줄을 누르면 그 사진이 열립니다
- **실패한 것도 그대로 보여줍니다** — 조용히 넘어가면 못 간 걸 아무도 모릅니다

---

## 5. 배송 규칙 — 어디로 보내나

**규칙은 새로 만들지 않습니다.** 지금 사진첩이 쓰는 것을 그대로 씁니다.

| AI가 읽은 것 | 검증 | 가는 곳 |
|---|---|---|
| 명함 | 통과 | 명함첩 |
| 사업자등록증 | 사업자번호 **체크섬 통과** | 명함첩 + 업체관리(빈 칸만) |
| 중소기업확인서 | 사업자번호 통과 | 업체관리(빈 칸만) |
| 회의·현장 | — | 사진첩 보관 (컨설팅이 당겨감) |
| 급여서류 | — | **안 보냄** · 지우라고 알림 |
| 못 읽음·검증 실패 | — | 사진첩 + **확인 필요** |

⚠ **검증을 통과한 것만 자동으로 보냅니다.** 사업자번호를 한 자리 잘못 읽은 채 업체관리에 들어가면 4대보험 신고서·계약서로 흘러가 되돌리기 어렵습니다. 이 규칙은 대표님이 2026-08-03 에 정하신 것이고 바꾸지 않습니다.

## 6. 단계

| 단계 | 무엇 | 시간 | 없어도 되나 |
|---|---|---|---|
| **1** | **카메라 하나로 · 푸른카메라는 곧바로 카메라로 넘기는 껍데기** | 하루 | 아니오 |
| **2** | **배송표** — 찍으면 어디로 갔는지 그 자리에서 | 하루 | 아니오 |
| 3 | 자동 촬영 (멎으면 저절로 찍힘) | 하루 | 예 |
| 4 | 테두리 찾아 잘라내기 | 2~3일 | 예 |

**1·2단계가 대표님이 말씀하신 것입니다.** 3·4는 리멤버의 「빠름」을 더하는 것이라 나중에 해도 됩니다.

### 1단계에서 조심할 것

- 푸른카메라를 **지우지 않습니다.** 폰에 설치한 분의 아이콘이 깨집니다. 껍데기로 남겨 넘깁니다
- 넘길 때 **로그인을 두 번 거치지 않게** 합니다(포털 → 사진첩 → 카메라가 한 번에)
- 옛 푸른카메라로 찍던 분은 **명함첩 직행에서 자동 배송으로** 바뀝니다 — 명함은 결과가 같고, 사업자등록증은 **업체관리에도 가서 더 좋아집니다**

### 2단계에서 조심할 것

- 배송표가 **화면을 다 먹으면 안 됩니다** — 최근 5줄만 보이고 나머지는 접습니다
- 판독이 느릴 때 **「읽는 중」 상태가 보여야** 합니다. 아무 줄도 없으면 고장으로 보입니다
- 배송에 실패한 줄에는 **다시 보내기** 단추

## 7. 안 만드는 것

| | 왜 |
|---|---|
| 회의·현장 사진을 **컨설팅에 자동 첨부** | 2026-08-02 에 범위에서 뺀 것입니다. 어느 일정인지 기계가 정하면 엉뚱한 건에 붙습니다 |
| 검증 실패한 것도 **일단 보내기** | 잘못 읽은 사업자번호가 계약서로 흘러갑니다 |
| 명함 앞뒤 자동 합치기 | 규칙이 애매합니다. 두 장 찍고 합치는 지금이 확실합니다 |

## 8. 어떻게 확인할까

숫자로 보고드리겠습니다.

- **터치 수** — 아이콘을 누르고 명함 3장을 명함첩에 넣기까지 몇 번 만지는가 (지금 먼저 재고 시작)
- **자동 배송률** — 명함 20장 중 손대지 않고 명함첩까지 간 것이 몇 장인가
- **잘못 간 것** — 엉뚱한 곳에 들어간 것이 있는가 (0장이어야 합니다)
- **옛 카메라 사용자** — 껍데기로 넘긴 뒤에도 아이콘이 그대로 열리는가

## 9. 정해 주실 것

1. **푸른카메라 아이콘을 남길까요?**
   - **남긴다**(권장) — 폰 홈에서 바로 카메라. 설치한 분의 아이콘도 안 깨집니다
   - 없앤다 — 사진첩 안에서만 카메라를 엽니다. 아이콘은 하나가 되지만 터치가 한 번 늘어납니다

2. **배송표를 어디에 둘까요?**
   - **카메라 화면 아래**(권장) — 찍으면서 바로 봅니다
   - 카메라를 닫은 뒤 한 번에 — 화면이 덜 복잡하지만 늦게 압니다

정해 주시면 **1단계부터 목업을 그려** 보여드리고 시작하겠습니다.
