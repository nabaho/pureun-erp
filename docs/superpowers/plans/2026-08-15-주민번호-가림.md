# 주민등록번호 가림 실행 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 급여데이터함이 서류 사진을 AI 판독기(구글)로 보내기 전에, 사람이 사각형을 그어 주민등록번호를 가리고(1차) 기계가 인쇄체를 찾아 미리 칠해 주는(2차) 화면을 만든다.

**Architecture:** 계산(좌표 환산·주민번호 꼴 찾기·캔버스로 칠하기)은 새 파일 `js/pu-rrn-mask.js` 에 모으고, 화면(드래그·그리기·단추)은 `pu-paydata.html` 의 판독 패널 자리에 붙인다. 지금 「판독하기」가 곧바로 판독기를 부르는 길을 끊고, **가림 화면을 거쳐 나온 사본만** 판독기에 실린다.

**Tech Stack:** 빌드 없는 단일 파일 HTML + `js/*.js` 전역 모듈 · 브라우저 캔버스 · 검사는 `node --test` + `node:vm` (DOM·캔버스는 가짜로 세운다) · 2차 글자인식은 tesseract.js(CDN, 처음 쓸 때만 받는다)

**설계서:** `docs/superpowers/specs/2026-08-15-주민번호-가림-design.md`

## Global Constraints

- **빌드 과정이 없다.** 새 파일은 `<script src="js/...">` 로 바로 실린다. `import`/번들러 금지.
- **실시간DB·창고 경로를 화면에 적지 않는다.** 경로를 아는 곳은 `js/pu-paydata-store.js` 하나뿐이다(`tests/paydata-store-path.test.js` 가 지킨다).
- **주석은 한국어.** 「무엇을」이 아니라 **「왜」**를 적는다(이 저장소의 기존 주석 방식).
- **검사 판정은 종료코드로 한다:** `node --test tests/*.test.js` 가 `0` 이어야 한다. 출력을 골라 읽지 말 것.
- **커밋은 경로를 지정한다:** `git commit -m "..." -- <파일들>`. 이 작업트리는 다른 세션과 함께 쓴다.
- **`js/*.js` 를 고치면 부르는 html 의 `?v=` 를 올린다.** 안 올리면 브라우저 캐시에 묵은 옛 파일이 그대로 돈다.
- **원본은 손대지 않는다.** 창고 파일도, 창고에 담긴 내용도 바뀌지 않는다. 가린 사본은 메모리에만 있고 저장하지 않는다.

## File Structure

| 파일 | 맡는 일 |
|---|---|
| `js/pu-rrn-mask.js` (새로) | 계산만 한다 — 드래그 → 사각형(비율), 비율 → 원본 픽셀, 캔버스에 칠해 사본 만들기, 주민번호 꼴 찾기, 글자인식 결과 → 사각형 |
| `pu-paydata.html` (고침) | 가림 화면(그리기·지우기·단추) · 판독 배선 갈아 끼우기 · 글자인식 도구 늦게 받기 |
| `tests/paydata-rrn-mask.test.js` (새로) | `js/pu-rrn-mask.js` 계산 검사 |
| `tests/paydata-mask-screen.test.js` (새로) | 가림 화면·배선·새는 길 검사 |

**왜 파일을 새로 만드나:** `pu-paydata.html` 은 이미 2,300줄이 넘는다. 좌표 환산과 캔버스 칠하기는 화면 없이도 검사할 수 있는 순수한 계산이라, 화면에서 떼어 놓으면 검사가 쉽고 나중에 사진첩에서도 쓸 수 있다.

```js
/* 주민등록번호 가림 — 계산 층
   AI 판독기로 보내기 **전에** 사진에서 주민번호 자리를 까맣게 덮는다.
   설계서: docs/superpowers/specs/2026-08-15-주민번호-가림-design.md

   ⚠ 왜 화면에서 떼어 놓았나
   좌표를 잘못 환산하면 **엉뚱한 자리가 덮이고 주민번호는 그대로 나간다.**
   화면 없이 숫자로 검사할 수 있어야 그 실수를 잡는다.

   ⚠ 사각형은 픽셀이 아니라 **비율(0~1)** 로 담는다
   폰을 돌리거나 창을 줄이면 사진이 보이는 크기가 달라진다. 픽셀로 담으면
   그때마다 가린 자리가 어긋난다. */
(function (global) {
  'use strict';

  function clamp01(v) {
    var n = Number(v);
    if (!isFinite(n)) return 0;
    return n < 0 ? 0 : (n > 1 ? 1 : n);
  }

  /* 손이 떨려 점만 찍힌 것은 사각형으로 치지 않는다 — 눈에 보이지도 않는 칸이
     목록에 쌓이면 「3군데 가림」이 거짓말이 된다. */
  var MIN_SIDE = 0.005;

  /* 드래그한 두 점(화면 픽셀) → 사각형 하나(비율). 못 만들면 null. */
  function rectFromDrag(x0, y0, x1, y1, viewW, viewH) {
    if (!(viewW > 0) || !(viewH > 0)) return null;
    var left = clamp01(Math.min(x0, x1) / viewW);
    var top = clamp01(Math.min(y0, y1) / viewH);
    var right = clamp01(Math.max(x0, x1) / viewW);
    var bottom = clamp01(Math.max(y0, y1) / viewH);
    var box = { x: left, y: top, w: right - left, h: bottom - top };
    if (box.w < MIN_SIDE || box.h < MIN_SIDE) return null;
    return box;
  }

  /* 비율 사각형 → **원본 크기** 픽셀. 사진 밖으로 넘치면 사진 안에서 끝낸다. */
  function toPixels(box, imgW, imgH) {
    var x = clamp01(box && box.x);
    var y = clamp01(box && box.y);
    var w = Math.min(1 - x, Math.max(0, Number((box && box.w) || 0)));
    var h = Math.min(1 - y, Math.max(0, Number((box && box.h) || 0)));
    return {
      x: Math.round(x * imgW), y: Math.round(y * imgH),
      w: Math.round(w * imgW), h: Math.round(h * imgH)
    };
  }

  global.PuRrnMask = {
    rectFromDrag: rectFromDrag,
    toPixels: toPixels
  };
})(typeof window !== 'undefined' ? window : globalThis);
```

- [ ] **Step 3: 구현한다**

`js/pu-rrn-mask.js` 의 `toPixels` 아래에 넣고, 내보내기에 한 줄 더한다:

```js
  /* 원본을 그리고 사각형을 까맣게 칠한 뒤 JPEG data URL 로 뽑는다.
     ⚠ **원본 크기**로 그린다. 화면에 보이는 크기로 그리면 좌표가 어긋나
     엉뚱한 데가 덮이고 주민번호는 그대로 남는다.
     ⚠ 반투명이 아니라 **완전히 까맣게** 칠한다 — 옅게 덮으면 밑이 비쳐 읽힌다.
     ⚠ 사진 크기를 모르면 던진다. 조용히 원본을 돌려주면 **안 가려진 사진이 나간다.** */
  function maskToDataUrl(img, boxes, opts) {
    opts = opts || {};
    var w = (img && (img.naturalWidth || img.width)) || 0;
    var h = (img && (img.naturalHeight || img.height)) || 0;
    if (!w || !h) throw new Error('사진 크기를 알 수 없습니다 — 다시 열어 주세요');
    var make = opts.makeCanvas || function (cw, ch) {
      var c = global.document.createElement('canvas');
      c.width = cw; c.height = ch;
      return c;
    };
    var canvas = make(w, h);
    var ctx = canvas.getContext('2d');
    ctx.drawImage(img, 0, 0, w, h);
    ctx.fillStyle = '#000';
    (boxes || []).forEach(function (b) {
      var p = toPixels(b, w, h);
      if (p.w > 0 && p.h > 0) ctx.fillRect(p.x, p.y, p.w, p.h);
    });
    return canvas.toDataURL('image/jpeg', opts.quality || 0.92);
  }
```

내보내기:

```js
  global.PuRrnMask = {
    rectFromDrag: rectFromDrag,
    toPixels: toPixels,
    maskToDataUrl: maskToDataUrl
  };
```

`maskPanelHtml()` 아래에 넣는다:

```js
/* ── 긋기 ──
   ⚠ 움직이는 동안 App.render() 를 부르면 안 된다. 다시 그리면 지금 손이 얹혀
   있는 요소가 통째로 새로 만들어져 드래그가 끊긴다(판독 표에서 글자마다 다시
   그리지 않는 것과 같은 까닭). 그래서 움직이는 동안에는 미리 보이는 칸 하나만
   손보고, 손을 뗄 때 한 번 다시 그린다. */
let maskDrag = null;

/* 사진이 **화면에 보이는 크기** — 원본 크기가 아니다. 비율로 바꾸는 데 쓴다. */
function maskViewRect() {
  const img = $('maskImg');
  return img ? img.getBoundingClientRect() : null;
}

function maskDown(ev) {
  const r = maskViewRect();
  if (!r) return;
  ev.preventDefault();
  maskDrag = { x0: ev.clientX - r.left, y0: ev.clientY - r.top, w: r.width, h: r.height };
  try { ev.currentTarget.setPointerCapture(ev.pointerId); } catch (_) { /* 손가락 못 잡아도 그리기는 된다 */ }
  maskShowPreview(maskDrag.x0, maskDrag.y0, maskDrag.x0, maskDrag.y0);
}

function maskMove(ev) {
  if (!maskDrag) return;
  const r = maskViewRect();
  if (!r) return;
  ev.preventDefault();
  maskShowPreview(maskDrag.x0, maskDrag.y0, ev.clientX - r.left, ev.clientY - r.top);
}

function maskUp(ev) {
  const d = maskDrag;
  maskDrag = null;
  maskHidePreview();
  if (!d) return;
  const r = maskViewRect();
  if (!r) return;
  const box = PuRrnMask.rectFromDrag(d.x0, d.y0, ev.clientX - r.left, ev.clientY - r.top, r.width, r.height);
  if (!box) return;                       // 점만 찍은 것은 사각형이 아니다
  box.by = 'me';
  App.maskState.boxes.push(box);
  App.render();
}

function maskShowPreview(x0, y0, x1, y1) {
  const el = $('maskPreview');
  const r = maskViewRect();
  if (!el || !r) return;
  const left = Math.min(x0, x1), top = Math.min(y0, y1);
  el.style.display = '';
  el.style.left = (left / r.width * 100) + '%';
  el.style.top = (top / r.height * 100) + '%';
  el.style.width = (Math.abs(x1 - x0) / r.width * 100) + '%';
  el.style.height = (Math.abs(y1 - y0) / r.height * 100) + '%';
}

function maskHidePreview() {
  const el = $('maskPreview');
  if (el) el.style.display = 'none';
}

/* 기계가 칠한 것도 지울 수 있다 — 잘못 잡는 일이 실제로 있다(계좌번호 등). */
function maskDelBox(i) { App.maskState.boxes.splice(i, 1); App.render(); }
function maskUndo() { App.maskState.boxes.pop(); App.render(); }
function maskClear() { App.maskState.boxes = []; App.render(); }

/* 가림을 그만두면 판독도 안 한다 — 안 가린 채로 새는 길을 두지 않는다. */
function maskCancel() {
  App.maskState = { status: 'idle', url: '', boxes: [], err: '', autoNote: '' };
  App.render();
}
window.maskDown = maskDown; window.maskMove = maskMove; window.maskUp = maskUp;
window.maskDelBox = maskDelBox; window.maskUndo = maskUndo; window.maskClear = maskClear;
window.maskCancel = maskCancel;
```

```js
  /* ── 주민번호 꼴 ──
     세 가지를 잡는다: 900101-1234567 · 900101 - 1234567 · 9001011234567.
     ⚠ 하이픈 없는 13자리를 잡으면 계좌번호처럼 긴 숫자를 잘못 칠할 수 있다.
     그래도 잡는다(대표 결정 2026-08-15) — **잘못 칠한 것은 사람이 지우면 되지만
     못 잡은 것은 그대로 나간다.**
     ⚠ 앞뒤가 숫자면 아니다 — 14자리 이상인 것을 13자리로 잘라 잡으면 안 된다.
     ⚠ 뒤돌아보기(lookbehind)를 쓰지 않는다 — 옛 아이폰 사파리에서 통째로 터진다. */
  function looksLikeRrn(text) {
    var t = String(text == null ? '' : text).replace(/\s+/g, '');
    if (/(^|\D)\d{6}[-–—]\d{7}(\D|$)/.test(t)) return true;
    if (/(^|\D)\d{13}(\D|$)/.test(t)) return true;
    return false;
  }

  /* 글자 가장자리가 남으면 그 한 자리로도 읽힌다 — 조금 넓게 덮는다. */
  var PAD = 0.01;

  /* 글자인식이 준 낱말들 → 가릴 사각형(비율).
     ⚠ 낱말이 「900101」 「-」 「1234567」 로 갈라져 오는 일이 흔하다. 그래서
     한 낱말씩만 보지 않고 **이어 붙인 세 낱말까지** 본다. 긴 쪽을 먼저 본다 —
     짧은 쪽부터 잡으면 뒷조각이 안 덮인 채로 끝난다. */
  function boxesFromWords(words, imgW, imgH) {
    var list = (words || []).filter(function (w) {
      return w && String(w.text == null ? '' : w.text).trim();
    });
    var out = [];
    var i = 0;
    while (i < list.length) {
      var hit = 0;
      for (var n = 3; n >= 1; n--) {
        if (i + n > list.length) continue;
        var joined = list.slice(i, i + n).map(function (g) { return String(g.text).trim(); }).join('');
        if (looksLikeRrn(joined)) { hit = n; break; }
      }
      if (!hit) { i += 1; continue; }
      var group = list.slice(i, i + hit);
      var x0 = Math.min.apply(null, group.map(function (g) { return Number(g.x0) || 0; }));
      var y0 = Math.min.apply(null, group.map(function (g) { return Number(g.y0) || 0; }));
      var x1 = Math.max.apply(null, group.map(function (g) { return Number(g.x1) || 0; }));
      var y1 = Math.max.apply(null, group.map(function (g) { return Number(g.y1) || 0; }));
      var x = clamp01(x0 / imgW - PAD);
      var y = clamp01(y0 / imgH - PAD);
      out.push({
        x: x, y: y,
        w: Math.min(1 - x, (x1 - x0) / imgW + PAD * 2),
        h: Math.min(1 - y, (y1 - y0) / imgH + PAD * 2),
        by: 'ai'
      });
      i += hit;
    }
    return out;
  }
```

```js
/* ── 기계가 거들기 (설계서 5장) ──
   ⚠ 사진은 **밖으로 나가지 않는다.** 글자인식은 이 컴퓨터(브라우저) 안에서 돈다.
     받아 오는 것은 사진이 아니라 도구와 글자 사전이다.
   ⚠ 무거워서(사전까지 10MB 남짓) **처음 쓸 때** 받는다 — 판독을 안 쓰는 사람이
     미리 받을 이유가 없다. */
const OCR_SRC = 'https://cdn.jsdelivr.net/npm/tesseract.js@5.1.1/dist/tesseract.min.js';
let ocrLoading = null;

function loadOcr() {
  if (window.Tesseract) return Promise.resolve(window.Tesseract);
  if (ocrLoading) return ocrLoading;
  ocrLoading = new Promise((res, rej) => {
    const s = document.createElement('script');
    s.src = OCR_SRC;
    s.onload = () => (window.Tesseract ? res(window.Tesseract) : rej(new Error('글자인식 도구를 못 읽었습니다')));
    s.onerror = () => rej(new Error('글자인식 도구를 받지 못했습니다'));
    document.head.appendChild(s);
  });
  return ocrLoading;
}

/* 낱말과 그 자리를 돌려준다. 주민번호는 숫자와 하이픈뿐이라 영문 사전으로 넉넉하다.
   ⚠ 숫자만 읽으라고 묶어 두지(whitelist) 않는다 — 글자를 억지로 숫자로 우겨 넣어
   엉뚱한 곳을 주민번호로 잡는다. */
function ocrWords(dataUrl) {
  return loadOcr().then(T => T.recognize(dataUrl, 'eng')).then(r => {
    const words = (r && r.data && r.data.words) || [];
    return words.map(w => {
      const b = w.bbox || w;
      return { text: w.text, x0: b.x0, y0: b.y0, x1: b.x1, y1: b.y1 };
    });
  });
}

/* 찾아서 미리 칠한다. **아무것도 던지지 않는다** — 기계가 못 도는 것이
   판독을 막는 이유가 되면 안 된다(설계서 5장).
   ⚠ 사람이 기다리는 동안 그어 둔 사각형을 지우거나 덮지 않는다 — 뒤에 더한다.
   ⚠ 그 사이 다른 서류로 옮겨 갔으면 버린다 — 앞 사진의 자리가 이 사진에 얹히면
     엉뚱한 데가 가려지고 진짜 주민번호는 그대로 나간다. */
function maskAutoFind(dataUrl, forId) {
  const img = new Image();
  img.onload = () => {
    ocrWords(dataUrl).then(words => {
      if (App.viewerId !== forId || App.maskState.status !== 'ready') return;
      const found = PuRrnMask.boxesFromWords(words, img.naturalWidth, img.naturalHeight);
      App.maskState.boxes = App.maskState.boxes.concat(found);
      App.maskState.autoNote = found.length
        ? '기계가 ' + found.length + '곳을 찾아 미리 가렸습니다(빨간 칸).'
        : '기계가 찾은 것은 없습니다 — 직접 봐 주세요.';
      App.render();
    }).catch(() => {
      if (App.viewerId !== forId || App.maskState.status !== 'ready') return;
      App.maskState.autoNote = '기계 찾기를 못 했습니다 — 직접 봐 주세요.';
      App.render();
    });
  };
  img.onerror = () => { /* 사진을 못 읽어도 사람이 칠하는 길은 그대로 열려 있다 */ };
  img.src = dataUrl;
}
```
