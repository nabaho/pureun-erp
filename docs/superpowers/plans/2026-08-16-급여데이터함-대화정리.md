# 급여데이터함 카톡 대화 정리 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 카톡에서 내보낸 대화 `.txt` 를 사업장 서랍에 담아 말풍선으로 읽고, 달을 골라 판독해 「요약 · 할 일 · 값」으로 정리한다.

**Architecture:** 담기는 이미 된다(`acceptFile` 이 `.txt` 를 막지 않는다 — 코드로 확인). 새로 만드는 것은 ① 내보내기 꼴을 가르는 **순수 계산 파일** 하나 ② 공용 판독 층에 **글을 보내는 새 함수** 하나 ③ 화면. 값은 이미 있는 값 층(`buildValueRows`·`saveValues`)으로 그대로 흘려보낸다.

**Tech Stack:** 빌드 없는 단일 파일 HTML · Firebase RTDB/Storage · `node --test` · 공용 판독 층 `js/pu-doc-read.js`(Gemini)

설계서: `docs/superpowers/specs/2026-08-16-급여데이터함-대화정리-design.md`
목업: `docs/mockups/paydata-chat.html`

## Global Constraints

- **공용 판독 층(`js/pu-doc-read.js`)에서 다른 앱이 기대는 동작을 바꾸지 않는다.** 사진첩·명함첩·업체관리가 함께 쓴다. `read()` 와 `PROMPT_ALL` 은 **손대지 않는다.** 새 함수만 더한다.
- **한국어 주석·화면 문구.** 파일의 기존 목소리(왜 그런지를 적는다)를 따른다.
- **검사 판정은 종료코드로.** `node --test tests/*.test.js > /tmp_t.txt 2>&1; echo "EXIT:$?"` 가 `EXIT:0` 이어야 한다. 출력만 훑지 않는다.
- **커밋은 경로를 찍어서.** `git add -A` / `git add .` 금지 — 여러 세션이 같은 저장소를 쓴다.
- **빌드 없음.** 인라인 `<script>` 가 파싱되는지 확인한다.
- **CRSF 덫:** `core.autocrlf=true` 라 작업트리가 CRLF 다. 글자 바로 뒤에 `\n` 을 붙인 정규식은 안 걸린다. `[\s\S]*?` 를 앞에 두거나 `\r?\n` 을 쓴다.
- **잘라 쓰는 덫:** 검사가 HTML 에서 함수를 잘라 `vm` 에서 돌린다. 잘린 함수가 최상위 `const`(예: `WAGE_READ_ON`)를 보면 그 상수도 샌드박스에 넣어야 한다.
- **주민등록번호는 이번에 막지 않는다**(대표 결정 2026-08-16). 대신 판독 화면에 경고를 띄운다. 글을 `●` 로 바꾸는 것은 이 계획 범위 밖이다.
- **새 콘솔 규칙 없음.**

```js
/* 카톡 내보내기 글 가르기 — 순수 계산
   ═══════════════════════════════════════════════════════════════════
   「대화 내용 내보내기」가 만든 .txt 를 말줄 배열로 바꾼다.
   담지도 그리지도 않는다 — 값만 다룬다. 그래서 실물 없이도 검사할 수 있다.

   ⚠ 안드로이드와 아이폰의 꼴이 다르고 판이 올라가며 바뀐다. 알려진 두 꼴을
   모두 받고, **못 알아보면 글 그대로 돌려준다** — 알아보기 실패가 「대화를
   못 본다」가 되면 안 된다. 화면은 raw 를 그대로 보여주면 된다. */
(function (global) {
  'use strict';

  /* 안드로이드: 2026년 8월 12일 오후 2:05, 임대순 대표 : 메시지
     아이폰:     2026. 8. 12. 오후 2:05, 임대순 대표 : 메시지
     보낸 사람 이름에 콜론이 들어갈 수 있어 **처음 나오는 ' : ' 로만** 가른다. */
  var RE_AND = /^(\d{4})년 (\d{1,2})월 (\d{1,2})일 (오전|오후) (\d{1,2}):(\d{2}), (.*?) : ([\s\S]*)$/;
  var RE_IOS = /^(\d{4})\. (\d{1,2})\. (\d{1,2})\. (오전|오후) (\d{1,2}):(\d{2}), (.*?) : ([\s\S]*)$/;

  function pad2(n) { return (n < 10 ? '0' : '') + n; }

  /* 오전 12시는 0시, 오후 12시는 12시다. 이걸 뒤집으면 자정 말이 정오로 가고
     날짜 경계에서 하루가 밀린다. */
  function hour24(ampm, h) {
    h = Number(h);
    if (ampm === '오전') return h === 12 ? 0 : h;
    return h === 12 ? 12 : h + 12;
  }

  function oneLine(s) {
    var m = RE_AND.exec(s) || RE_IOS.exec(s);
    if (!m) return null;
    var y = Number(m[1]), mo = Number(m[2]), d = Number(m[3]);
    var hh = hour24(m[4], m[5]), mi = Number(m[6]);
    return {
      at: new Date(y, mo - 1, d, hh, mi, 0).getTime(),
      atText: y + '-' + pad2(mo) + '-' + pad2(d) + ' ' + pad2(hh) + ':' + pad2(mi),
      who: String(m[7] || '').trim(),
      text: String(m[8] || '')
    };
  }

  function parseKakao(text) {
    var raw = String(text == null ? '' : text);
    var rows = raw.split(/\r?\n/);
    var out = [], last = null;
    for (var i = 0; i < rows.length; i++) {
      var got = oneLine(rows[i]);
      if (got) { out.push(got); last = got; continue; }
      /* 시각이 없는 줄 — 엔터가 든 말의 이어진 부분이다. 앞 말에 붙인다.
         앞 말이 없으면 머리말·날짜 구분선이므로 버린다. */
      if (last && rows[i] !== '') last.text += '\n' + rows[i];
    }
    var seen = {}, months = [];
    out.forEach(function (l) {
      var mk = l.atText.slice(0, 7);
      if (!seen[mk]) { seen[mk] = 1; months.push(mk); }
    });
    months.sort().reverse();           // 최근 달이 앞
    return { ok: out.length > 0, lines: out, months: months, raw: raw };
  }

  /* 달을 안 주면 전부 — 화면의 「전체」가 이 길로 온다. */
  function sliceMonth(lines, ym) {
    var arr = lines || [];
    if (!ym) return arr.slice();
    return arr.filter(function (l) { return l && l.atText.slice(0, 7) === ym; });
  }

  /* 판독기에 보낼 꼴. 시각과 이름을 함께 보내야 AI 가 「누가 언제 한 말인지」를
     알고, 값의 출처를 그 시각으로 돌려줄 수 있다. */
  function toPlain(lines) {
    return (lines || []).map(function (l) {
      return '[' + l.atText + '] ' + l.who + ': ' + l.text;
    }).join('\n');
  }

  global.PuChatParse = { parseKakao: parseKakao, sliceMonth: sliceMonth, toPlain: toPlain };
})(typeof window !== 'undefined' ? window : globalThis);
```

`function startMask() {` **위**에 넣는다:

```js
/* 대화 정리 — 고른 달 구간만 글로 보낸다.
   창고 파일은 뷰어가 이미 받아 두었으므로(App.chatText) 다시 받지 않는다. */
function runChatRead() {
  const p = PuChatParse.parseKakao(App.chatText || '');
  const part = PuChatParse.sliceMonth(p.lines, App.chatMonth || (p.months[0] || ''));
  if (!part.length) {
    App.readState = { status: 'err', rows: [], err: '고른 구간에 대화가 없습니다.' };
    App.render();
    return;
  }
  App.readState = { status: 'reading', rows: [], err: '' };
  App.render();

  /* 판독 중에 다른 서류로 옮겨 갈 수 있다 — 늦게 온 답이 새 화면을 덮으면
     엉뚱한 원본이 출처로 붙는다. 사진 판독과 같은 보호를 건다. */
  const forId = App.viewerId;
  PuDocRead.readChatText(PuChatParse.toPlain(part)).then(r => {
    if (App.viewerId !== forId) return;
    if (!r.ok) throw new Error(r.error || '정리하지 못했습니다');
    App.chatOut = { summary: r.summary, todos: r.todos, rows: r.rows };
    App.readState = { status: 'done', rows: S.rowsFromRead('notice', r), err: '' };
    App.render();
  }).catch(e => {
    if (App.viewerId !== forId) return;
    App.chatOut = null;
    App.readState = { status: 'err', rows: [], err: (e && e.message) || String(e) };
    App.render();
  });
}
```

- [ ] **Step 3: 찾아가는 길을 만든다**

`function closeViewer()` **위**에 넣는다:

```js
/* 값에서 대화 그 자리로. **시각**으로 찾는다 — 대화방을 다시 내보내면 줄 번호는
   밀리지만 시각은 그대로다(설계서 5장). 못 찾으면 아무 줄도 짚지 않는다 —
   엉뚱한 줄을 노랗게 하면 그 표시를 못 믿게 된다. */
function openViewerAt(id, atText) {
  App.chatHitAt = String(atText || '');
  openViewer(id);
}
window.openViewerAt = openViewerAt;
```

`closeViewer` 를 바꾼다.

바꾸기 전:
```js
function closeViewer() { App.viewerId = ''; App.render(); }
```

바꾼 뒤:
```js
function closeViewer() { App.viewerId = ''; App.chatHitAt = ''; App.render(); }
```

> `openViewer` 에서는 `chatHitAt` 을 **비우지 않는다** — `openViewerAt` 이 먼저
> 세워 두고 부르기 때문이다. 닫을 때 비우는 것으로 충분하다.

```js
      p.cells[pr.item] = { value: pr.value, sourceId: r.sourceId || '',
```

```js
        const go = !c.sourceId ? ''
```
