# 자료함 격자 편집기 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 한글 서식을 세로 목록이 아니라 **원래 표 모양 그대로** 큰 팝업에 펼쳐 한 화면에서 고칠 수 있게 한다.

**Architecture:** `js/pu-hwp-edit.js` 에 순수 함수 `readGrid(doc)` 를 더한다 — 표의 행·열·합친 칸을 `getCellInfo` 에서 받아 격자를 되살리고, 고칠 수 있는 줄들은 기존 `readRows` 와 **같은 모양**으로 내준다. 그래야 이미 검사를 통과한 `changedRows()`/`applyRows()` 를 한 줄도 고치지 않고 그대로 쓴다. `pu-cards.html` 에는 큰 팝업(`.mged`)을 새로 만들어 그 격자를 HTML `<table>` 로 그린다.

**Tech Stack:** 빌드 없는 단일 HTML + 브라우저 표준 JS (ES2020). 검사는 `node:test` + `node:assert`. 한글 엔진은 `vendor/rhwp-core` (WASM) — 검사에서는 띄우지 않고 **가짜 문서**를 넣는다.

## Global Constraints

- **`readRows()` 를 지우거나 고치지 않는다.** 지금 화면(`heRenderRows`)이 쓰고 있고 `tests/hwp-edit.test.js` 가 검사한다. `readGrid()` 는 **옆에 새로 놓는다.**
- **`readGrid().units` 의 각 원소는 `readRows()` 가 내주던 줄과 같은 열쇠를 가진다** — `kind`(`'body'`|`'cell'`), `sec`, `para`, `ctrl`, `cell`, `cpara`, `text`, `len`, `no`. `changedRows()`/`applyRows()` 가 이 열쇠들을 쓴다.
- **행·열·합친 칸은 반드시 `getCellInfo` 에서 받는다.** `Math.floor(idx/cols)` 같은 짐작을 새로 쓰지 않는다.
- **`getStructure()` 를 부르지 않는다.** 실제로 `memory access out of bounds` 로 터진다.
- **`PureunHwp.renderPreview()` 에는 `_he.doc` 가 아니라 `bytes` 를 넘긴다.** 문서를 넘기면 그 문서가 죽는다.
- 파일은 UTF-8. 주석과 화면 글은 한국어. 이 저장소의 말투를 따른다 — 무엇을 하는지가 아니라 **왜 그렇게 했는지**를 적는다.
- 검사는 `node --test tests/*.test.js` 로 전부 돌려 **하나도 실패하지 않아야** 한다. 지금 1,607개가 통과한다.
- 커밋 메시지는 한국어. `feat(자료함): …` 꼴.

그리고 `cellPos` 함수 **바로 앞**에 넣는다.

```javascript
  /* ── 문서를 격자 그대로 읽기 ──
     readRows() 는 표 칸을 세로로 늘어놓는다. 서식은 거의 전부 표라서 그러면
     원래 모양이 사라진다 — 20행 × 3열 급여표가 60줄짜리 목록이 된다.
     여기서는 표를 **표로** 읽는다.

     units 는 readRows 가 내주던 줄과 **같은 모양**이다. 그래야 이미 검사를
     통과한 changedRows()/applyRows() 를 한 줄도 안 고치고 그대로 쓴다.
     blocks 는 화면에 그릴 차례와 모양만 담는다(글자는 units 에만 있다). */
  function readGrid(doc) {
    const units = [], blocks = [];
    const warn = { badCellInfo: 0, textBoxes: 0 };
    const secs = num(doc.getSectionCount());
    for (let s = 0; s < secs; s++) {
      const paras = num(doc.getParagraphCount(s));
      for (let p = 0; p < paras; p++) {
        let text = '';
        try { text = String(doc.getTextRange(s, p, 0, num(doc.getParagraphLength(s, p)))); } catch (_) { text = ''; }
        if (text.trim()) {
          blocks.push({ kind: 'body', unit: units.length });
          units.push({ kind: 'body', sec: s, para: p, text: text, len: text.length });
        }
        /* 글상자는 아직 못 읽는다. 세어서 화면에 알린다 —
           조용히 빠지면 「고쳤는데 안 바뀌었다」가 된다. */
        try {
          const tb = parseInt(doc.getTextBoxControlIndex(s, p), 10);
          if (isFinite(tb) && tb >= 0) warn.textBoxes++;
        } catch (_) {}
        pushTables(doc, units, blocks, warn, s, p);
      }
    }
    units.forEach(function (u, i) { u.no = i + 1; });
    return { units: units, blocks: blocks, warn: warn };
  }

  function pushTables(doc, units, blocks, warn, s, p) {
    for (let ctrl = 0; ctrl < CTRL_PROBE; ctrl++) {
      let dim = null;
      /* 표가 아니면 던진다 — 그림·글상자일 수 있으니 멈추지 말고 다음 것을 본다 */
      try { dim = JSON.parse(doc.getTableDimensions(s, p, ctrl)); } catch (_) { continue; }
      const total = num(dim && dim.cellCount);
      const cells = [];
      for (let c = 0; c < total; c++) {
        /* 행·열·합친 칸은 **반드시 엔진에서 받는다.** 칸 번호를 열 수로 나눠
           짐작하면 합친 칸이 하나만 있어도 그 뒤가 전부 어긋난다. */
        let inf = null;
        try { inf = JSON.parse(doc.getCellInfo(s, p, ctrl, c)); } catch (_) { inf = null; }
        if (!inf) warn.badCellInfo++;
        const idx = [];
        let cps = 0;
        try { cps = num(doc.getCellParagraphCount(s, p, ctrl, c)); } catch (_) { cps = 0; }
        for (let cp = 0; cp < cps; cp++) {
          let len = 0, text = '';
          try {
            len = num(doc.getCellParagraphLength(s, p, ctrl, c, cp));
            text = String(doc.getTextInCell(s, p, ctrl, c, cp, 0, len));
          } catch (_) { continue; }
          /* 칸의 첫 줄은 비어 있어도 남긴다 — 거기가 채울 자리다.
             둘째 줄부터의 빈 줄은 뺀다(줄 간격용이라 줄만 늘어난다). */
          if (cp > 0 && !text.trim()) continue;
          idx.push(units.length);
          units.push({ kind: 'cell', sec: s, para: p, ctrl: ctrl, cell: c, cpara: cp,
                       text: text, len: text.length });
        }
        cells.push({ cell: c,
                     row: inf ? int0(inf.row) : null,
                     col: inf ? int0(inf.col) : null,
                     rowSpan: num(inf && inf.rowSpan) || 1,
                     colSpan: num(inf && inf.colSpan) || 1,
                     units: idx });
      }
      blocks.push({ kind: 'table', sec: s, para: p, ctrl: ctrl,
                    rows: num(dim && dim.rowCount), cols: num(dim && dim.colCount),
                    cells: cells });
    }
  }

  /* num() 은 1 이상만 받는다(길이·개수용). 행·열은 0 부터라 따로 둔다. */
  function int0(v) { const n = parseInt(v, 10); return isFinite(n) ? n : 0; }
```

/* 표를 표로 그린다.
   ⚠ 자리는 getCellInfo 가 준 row·col 만 쓴다. 칸 번호를 열 수로 나눠 짐작하면
     합친 칸이 하나만 있어도 그 뒤가 전부 어긋난다(실제 공문에 55개 있었다).
   ⚠ 합친 칸이 덮는 자리는 미리 막아 둔다. 안 막으면 칸이 오른쪽으로 밀린다. */
function mgTableHtml(b){
  const rows=Math.max(1,b.rows), cols=Math.max(1,b.cols);
  const taken={};                                  /* 'r-c' → 이미 다른 칸이 덮었다 */
  const at={};                                     /* 'r-c' → 거기서 시작하는 칸 */
  const orphan=[];                                 /* 자리를 모르는 칸 */
  b.cells.forEach(c=>{
    if(c.row==null || c.col==null){ orphan.push(c); return; }
    at[c.row+'-'+c.col]=c;
  });
  let h='<table class="mgtbl">';
  for(let r=0;r<rows;r++){
    h+='<tr>';
    for(let c=0;c<cols;c++){
      if(taken[r+'-'+c]) continue;
      const cell=at[r+'-'+c];
      if(!cell){ h+='<td></td>'; continue; }
      const rs=Math.max(1,cell.rowSpan), cs=Math.max(1,cell.colSpan);
      for(let dr=0;dr<rs;dr++) for(let dc=0;dc<cs;dc++)
        if(dr||dc) taken[(r+dr)+'-'+(c+dc)]=1;
      h+='<td rowspan="'+rs+'" colspan="'+cs+'">'+cell.units.map(mgLineHtml).join('')+'</td>';
    }
    h+='</tr>';
  }
  h+='</table>';
  /* 자리를 못 읽은 칸도 고칠 수 있어야 한다. 조용히 빼면 영영 못 고친다. */

      +orphan.map(c=>c.units.map(mgLineHtml).join('')).join('')+'</div>';
  }
  return h;
}

  if(!ch.length) return {ok:0, failed:[]};
  const res = PuHwpEdit.applyRows(_mg.doc, ch);
  _mg.bytes = PuHwpEdit.exportBytes(_mg.doc, _mg.name);
  _mg.grid = PuHwpEdit.readGrid(_mg.doc);
  _mg.edited = {};
  return res;
}
/* 실패한 곳을 조용히 넘기면 「저장했다는데 안 바뀌었다」가 된다 */
function mgTellFailed(res){
  if(!res.failed.length) return;
  toast('넣지 못한 곳: '+res.failed.map(f=>f.no+'번('+f.why+')').join(', '), 9000);
}

async function mgSave(){
  if(!_mg || _mg.busy) return;
  const n = mgChanged();
  if(!n) return toast('고친 곳이 없습니다');
  if(!confirm('고친 '+n+'곳을 자료함의 「'+_mg.name+'」에 저장합니다.\n예전 내용은 남지 않습니다. 진행할까요?')) return;
  _mg.busy=true;
  try{
    const res = mgApply();
    mgTellFailed(res);
    const t = matType(_mg.name) || {mime:'application/octet-stream'};
    const file = new File([_mg.bytes], _mg.name, {type:t.mime});
    const cur = _matMeta[_mg.id] || {};
    await putMaterial(_mg.id, cur.name || _mg.name, file);   /* 갈래·설명·순서는 그대로 얹힌다 */
    toast('✅ 자료함에 저장했습니다');
    mgRender();
  }catch(e){
    toast('저장하지 못했습니다 — '+((e&&e.message)||''), 8000);
  }finally{ _mg.busy=false; }
}

function mgDownload(){
  if(!_mg || _mg.busy) return;
  try{
    const res = mgApply();
    mgTellFailed(res);
    PureunHwp.download(_mg.bytes, PuHwpEdit.editedName(_mg.name), PuHwpEdit.extOf(_mg.name));
    toast('📥 고친 문서를 내려받았습니다 — 자료함의 원본은 그대로입니다');
    mgRender();
  }catch(e){ toast('만들지 못했습니다 — '+((e&&e.message)||''), 8000); }
}

/* 원본 모습 — 한글로 인쇄한 그대로 그린다.
   ⚠ 반드시 _mg.bytes 를 넘긴다. renderPreview 는 받은 바이트로 제 문서를 열고
     끝나면 닫는다(pu-hwp-engine.js). _mg.doc 를 넘기면 그 문서가 죽어
     편집이 통째로 멈춘다. */
function mgPreview(){
  if(!_mg) return;
  const b=$('mgedBody'); if(!b) return;
  if(mgChanged() && !confirm('고친 내용을 아직 저장하지 않았습니다.\n버리고 원본 모습을 볼까요?')) return;
  _mg.edited={};
  b.innerHTML='<div class="mpmsg">모습을 그리는 중…</div>';
  PureunHwp.renderPreview(b, _mg.bytes, _mg.name).then(()=>{
    const back=document.createElement('div');
    back.style.cssText='text-align:center;padding:10px 0 18px';
    back.innerHTML='<button onclick="mgRender()" style="border:1px solid #cbd5e6;background:#fff;border-radius:8px;padding:7px 14px;font-size:12.5px;font-weight:700;cursor:pointer;font-family:inherit">← 고치기로 돌아가기</button>';
    b.appendChild(back);
  }).catch(e=>{
    b.innerHTML='<div class="mpmsg">모습을 그리지 못했습니다 — '+esc((e&&e.message)||'')
      +'<br><button onclick="mgRender()" style="margin-top:10px;border:1px solid #cbd5e6;background:#fff;border-radius:8px;padding:7px 14px;font-size:12.5px;cursor:pointer;font-family:inherit">← 고치기로 돌아가기</button></div>';
  });
}

## 이 계획이 다루지 않는 것

설계서의 나머지는 다음 계획으로 넘긴다. 여기서 손대면 과제가 커져 검사가 헐거워진다.

- **`[빈칸만]` 거르개** — 설계서 § 3 의 도구줄에 있다. 세로 목록에서는 거르기가 쉽지만 **표에서는 줄을 걸러 내면 표가 무너진다.** 표 모양을 지키면서 빈칸만 보이게 하려면 거르기가 아니라 **눈에 띄게 칠하기**로 가야 한다. 격자가 실제 서식에서 어떻게 보이는지 확인한 뒤 정한다.
- **채울 자리 지정과 명함첩 당겨오기** (`slots`, `mode`, `keep`) — 설계서 § 4
- **묶음에 채우기 잇기** — 설계서 § 6
- **`sendAs`(한글/PDF 고르기)** — 설계서 § 6
- **원본 덮어쓰기 전 이전본 남기기** — 설계서 § 5. `putMaterial` 을 건드려야 해 따로 뗀다
- **중첩표·글상자 읽기** — 이번엔 세어서 알리기만 한다
- **표 줄 추가·삭제**
