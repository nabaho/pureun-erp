# 푸른사진첩 B단계 구현 계획 — 사진 클라우드 저장 + 업로드 대기열

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 폰에서 고른 사진이 실시간DB에 연도별로 저장되고, 신호가 약해도 잃지 않고 자동 재시도되며, 폰과 PC 어디서든 격자로 보인다 (폰↔PC 사진 공유 완성).

**Architecture:** 저장은 `js/pu-photo-store.js`(저장 방식을 아는 유일한 파일)에만 더한다 — 확정된 실시간DB 모드로 메타/본문/미리보기를 세 경로에 갈라 담는다. 업로드 대기열은 새 파일 `js/pu-photo-queue.js` — 사진을 먼저 기기(IndexedDB)에 담고 올라간 뒤에만 지우는 층으로, 저장 함수를 주입받아 저장 방식을 모른다. 화면(`pu-photos.html`)은 2026-08-02 승인된 목업 그대로: 고르기/카메라 버튼 + 올리는 중 목록 + 날짜별 격자.

**Tech Stack:** Firebase compat SDK 10.12.0 (database) · IndexedDB · Canvas 축소 · `node --test`

## Global Constraints

- **설계서:** `docs/superpowers/specs/2026-08-02-푸른사진첩-design.md`. 어긋나면 설계서가 우선.
- **저장 방식은 실시간DB 확정**(2026-08-02 창고 점검 `storage/quota-exceeded`). `pu-photo-store.js`의 `var mode = 'rtdb'` 그대로. storage 모드 저장은 아직 안 만든다(YAGNI) — 호출되면 명확한 한국어 예외.
- **실시간DB 루트는 `puphotos`만.** 다른 루트(`pucards`, `data`, `scal_*` 등) 절대 접근 금지.
- **사진은 한 장씩 추가만.** 상위 노드를 통째로 `set` 하지 않는다 — 반드시 다중 경로 `update` (2026-07 실데이터 사고 재발 방지).
- **올릴 때 긴 변 1600px 축소(JPEG 품질 0.85), 격자용 미리보기 240px 별도.** 카메라 원본은 클라우드에 안 올라간다.
- **촬영 시각 우선순위: EXIF → 파일 날짜 → 업로드 시각.** 없다고 버리지 않고 `unknown` 연도에 담는다.
- 한국어 주석 · ES5 스타일(var/function, 화살표 함수 금지 — 기존 store 파일과 통일).
- 테스트는 `node --test tests/`. 파이어베이스·IndexedDB는 가짜(fake)를 주입 — **실서버에 절대 안 붙는다**.
- `git add .` 금지, `git stash pop` 금지, 커밋은 경로 지정(`git commit -m "..." -- <파일들>`), 커밋 직후 `git show --stat HEAD` 확인.
- HTML은 `[System.IO.File]::ReadAllText(path, UTF8)`로만 읽는다 (`Get-Content -Raw` 금지 — 한글 깨짐).
- 브랜치 `feat/pu-photos-b-stage`, 끝나면 PR (main 직접 push 금지).

## 데이터 모양 (실시간DB)

```
puphotos/items/{연도}/{id}  = { takenAt, upAt, by(uid), byName, w, h, size }   ← 목록용. 가볍다
puphotos/blobs/{연도}/{id}  = 'data:image/jpeg;base64,…'  (1600px 축소본)      ← 볼 때만 한 장씩
puphotos/thumbs/{연도}/{id} = 'data:image/jpeg;base64,…'  (240px 미리보기)     ← 격자용
```

}

```js
/* 새 사진 id — 파이어베이스 push 키(시간순 정렬됨). db가 없으면(테스트) 임시 키. */
function newId() {
  if (deps.db) return deps.db.ref(DB_ROOT + '/items').push().key;
  return 'p' + Date.now().toString(36) + Math.random().toString(36).slice(2, 8);
}

/* 사진 한 장 저장 — 메타·본문·미리보기를 다중 경로 update 한 번에.
   상위 노드를 set 하면 남의 사진이 지워진다(2026-07 사고) — 반드시 이 모양대로. */
function savePhoto(p) {
  if (mode === 'storage') return Promise.reject(new Error('파일 창고 저장은 아직 준비되지 않았습니다'));
  if (!deps.db) return Promise.reject(new Error('실시간DB가 연결되지 않았습니다'));
  var year = yearOf(p.takenAt);
  var u = {};
  u[metaPath(year, p.id)] = p.meta;
  u[blobPath(year, p.id)] = p.full;
  u[thumbPath(year, p.id)] = p.thumb;
  return deps.db.ref().update(u).then(function () { return { year: year, id: p.id }; });
}

function listYear(year) {
  if (!deps.db) return Promise.reject(new Error('실시간DB가 연결되지 않았습니다'));
  return deps.db.ref(DB_ROOT + '/items/' + year).once('value')
    .then(function (s) { return s.val() || {}; });
}
function loadThumb(year, id) { return readOnce(thumbPath(year, id)); }
function loadFull(year, id) { return readOnce(blobPath(year, id)); }
function readOnce(path) {
  if (!deps.db) return Promise.reject(new Error('실시간DB가 연결되지 않았습니다'));
  return deps.db.ref(path).once('value').then(function (s) { return s.val(); });
}
```
