# kcareer 실적 동기화 구현계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** pu-erp의 종료된 업무 4종을 담당노무사와 함께 kcareer 실적으로 자동 동기화하고, 수행기관 유무로 푸른 자체 실적과 외부기관 실적을 나누어 관리한다.

**Architecture:** 종료 판별·필드 매핑·병합 계획은 순수 모듈 `js/kcareer-pusync.js`(브라우저·Node 겸용)로 분리해 node 테스트로 검증한다. kcareer.html은 Firebase 읽기·미리보기 모달·저장·배제 UI·외부기관 탭만 담당한다. 새 스토어 없이 기존 `case`·`consult`·`fund`·`etc`에 `puRef`·`src`·`syncId`·`excluded` 꼬리표만 추가한다.

**Tech Stack:** 순수 ES5 JS(빌드 없음), Firebase RTDB compat 10.13.2(`data/*` 읽기 전용), `node:test` + `node:assert/strict`

**설계서:** `docs/superpowers/specs/2026-08-01-kcareer-실적동기화-design.md`

## Global Constraints

- **pu-erp `data/`는 읽기만.** 쓰기는 `kcareer/` 노드(기존 `set()` 경유)만.
- **동기화는 추가만 한다.** 기존 레코드를 덮어쓰거나 지우지 않는다(수동 수정 보존).
- **배제는 삭제가 아니라 `excluded:true`.** 삭제하면 재동기화 때 되살아난다.
- **종료 판별**: `closedDate`가 있거나 `status`가 `closed`/`done`/`완료`/`종료`일 때만. **`endDate`만 있으면 미종료**(예정일일 수 있음).
- 반복문 안에서 `set()` 금지 — 스토어별 단일 쓰기(기존 `fsCommitScan` 규칙, 정적 테스트 있음).
- **환경설정으로 안내하는 문구 금지** — 비관리자에게 숨겨져 막다른 길이 된다(회귀테스트 있음).
- `kcareer.html`·신규 파일 외 건드리지 않는다. 매 태스크 끝 즉시 커밋, push 전 `git pull --rebase origin main`.
- 한국어 주석. 커밋 메시지는 한 줄 또는 `git commit -F <파일>`.

## 코드 사실 (2026-08-01 확인)

- `CAREER_CFG`의 `case`(3529)·`consult`(3516)·`fund`(3535)·`etc`(3541)에는 `filter`가 없다. `renderCareer`(3568 부근)는 `if(cfg.filter) data=data.filter(cfg.filter)`를 이미 지원한다.
- ID 접두사(FORM_DEFS): case=`CS`, consult=`CN`, fund=`FD`, etc=`ET`. 기존 `nextId(prefix,store)`는 localStorage를 직접 보므로 묶음 저장 때는 버퍼 기준 생성기를 쓴다(`fsCommitScan`의 `_bufIdSeq`와 같은 이유).
- 주담당: `_puMainMgr(c)` = `managerMain` → `workers`의 `isPrimary` → 첫 번째. 이름 변환 `_puUserMap`(`await _puLoadUserMap()`).
- 로그인 훅: 4958행 부근 `if(u){ authGate(false); ... resolveMe() ... }` — 여기에 자동 동기화를 단다.
- `rowActions(id,store,label,page,rec)`는 이미 `rec`를 받는다(fs 원본 분기용).
- 모달 구조: `.modal-ov` › `.modal` › `.modal-h`/`.modal-b`/`.modal-foot` (`modalScan` 참조).

```js
'use strict';
// 푸른노무법인 경력관리 — pu-erp 실적 동기화 순수 모듈
// (브라우저 window.KcareerPuSync / Node module.exports 겸용, DOM·Firebase 미사용)
// 설계서: docs/superpowers/specs/2026-08-01-kcareer-실적동기화-design.md
(function (root) {

  /* ===== 종료 판별 =====
     pu-erp 상태값은 closed·done·완료가 혼재하고 UI 상태(active·saving)와 필드명이 같다.
     ⚠ endDate만 있는 건은 예정일일 수 있으므로 미종료로 본다(기존 화면의 "(예정)" 해석과 동일). */
  var CLOSED_STATUS = ['closed', 'done', '완료', '종료'];
  function isClosed(c) {
    if (!c) return false;
    if (c.closedDate) return true;
    var s = String(c.status || '').toLowerCase();
    return CLOSED_STATUS.indexOf(s) >= 0;
  }

  /* 주담당 sid: managerMain → workers의 isPrimary → 첫 번째 (kcareer._puMainMgr와 동일 규칙) */
  function mainSid(c) {
    var sid = c.managerMain || '';
    if (!sid && Array.isArray(c.workers)) {
      var w = c.workers.find(function (x) { return x && x.isPrimary; }) || c.workers[0];
      if (w) sid = w.sid || '';
    }
    return String(sid || '');
  }

  /* ===== 필드 매핑 (설계서 §4 표) ===== */
  var COLL_MAP = {
    cases:          { store: 'case',    type: ['caseType'],                        proj: ['title', 'caseNo'] },
    consultings:    { store: 'consult', type: ['consultingType', 'programName'],   proj: ['title', 'programName'] },
    funds:          { store: 'fund',    type: ['fundType', 'programName'],         proj: ['title'] },
    other_projects: { store: 'etc',     type: ['programName', 'projectType'],      proj: ['title'] }
  };
  function pick(c, keys) { for (var i = 0; i < keys.length; i++) { if (c[keys[i]]) return c[keys[i]]; } return ''; }

  function mapRecord(coll, key, c, userMap) {
    var m = COLL_MAP[coll];
    if (!m || !c) return null;
    var sid = mainSid(c);
    var dateRaw = c.closedDate || c.endDate || '';
    return {
      store: m.store,
      rec: {
        type: pick(c, m.type),
        org: c.companyName || c.payee || '',
        project: pick(c, m.proj),
        year: String(dateRaw).slice(0, 4),
        main: (userMap && userMap[sid]) || sid,
        status: '완료',
        puRef: coll + '/' + key
      }
    };
  }

  var api = { isClosed: isClosed, mapRecord: mapRecord };
  if (typeof module !== 'undefined' && module.exports) module.exports = api;
  else root.KcareerPuSync = api;
})(typeof globalThis !== 'undefined' ? globalThis : window);
```

```js
  /* ===== 병합 계획 =====
     추가만 계획한다. 기존 레코드는 건드리지 않고(수동 수정 보존),
     existingRefs에 있는 puRef는 배제된 것이라도 다시 들어오지 않는다. */
  function buildSyncPlan(collData, existingRefs, userMap) {
    var known = (existingRefs instanceof Set) ? existingRefs : new Set(existingRefs || []);
    var plan = { adds: [], counts: { case: 0, consult: 0, fund: 0, etc: 0 }, skippedOpen: 0, skippedKnown: 0 };
    Object.keys(COLL_MAP).forEach(function (coll) {
      var v = collData ? collData[coll] : null;
      if (!v) return;
      Object.keys(v).forEach(function (key) {
        var c = v[key];
        if (!c) return;                                       /* Firebase 배열형의 null 구멍 */
        if (!isClosed(c)) { plan.skippedOpen++; return; }
        var ref = coll + '/' + key;
        if (known.has(ref)) { plan.skippedKnown++; return; }
        var m = mapRecord(coll, key, c, userMap);
        if (!m) return;
        plan.adds.push(m);
        plan.counts[m.store]++;
      });
    });
    return plan;
  }
```

function puSyncCommit(){
  if(!_puSyncCtx){ toast('동기화 결과가 없습니다'); return; }
  var plan = _puSyncCtx.plan, syncId = _puSyncCtx.syncId, n = 0;
  /* 스토어별로 한 번만 읽고 한 번만 쓴다. buf는 리터럴로 초기화한다 —
     스토어 목록을 도는 반복문은 이 함수에서 맨 끝의 저장 한 곳뿐이어야 한다(정적 테스트가 지킴).
     ⚠ 주석에도 그 반복문 이름을 쓰지 말 것 — 문자열 검색 기반 테스트에 걸린다. */
  var buf = { case: get('case'), consult: get('consult'), fund: get('fund'), etc: get('etc') };
  var PREFIX = { case:'CS', consult:'CN', fund:'FD', etc:'ET' };
  function bufId(store){
    var k = 1, mk = function(){ return PREFIX[store] + String(k).padStart(4,'0'); };
    while(buf[store].some(function(x){ return x.id === mk(); })) k++;
    return mk();
  }
  plan.adds.forEach(function(a){
    var rec = Object.assign({}, a.rec, {
      id: bufId(a.store), src: 'pu', syncId: syncId, excluded: false,
      savedAt: new Date().toISOString()
    });
    buf[a.store].unshift(rec); n++;
  });
  PU_SYNC_STORES.forEach(function(k){ set(k, buf[k]); });
  LS.set(NS + 'pu_sync_last', new Date().toISOString());
  LS.set(NS + 'pu_sync_last_id', syncId);
  closePuSync();
  PU_SYNC_STORES.forEach(function(k){ try{ if(CAREER_CFG[k]) renderCareer(k); }catch(e){} });
  toast('✅ 실적 ' + n + '건 들어옴 — 불필요한 건은 행의 배제 버튼으로 정리하세요');
}

/* ===== 동기화 되돌리기 — 그 동기화가 만든 레코드만(배제된 것 포함) 삭제 ===== */
function puUndoSync(syncId){
  if(!syncId) return;
  var total = 0;
  PU_SYNC_STORES.forEach(function(k){
    var db = get(k), left = db.filter(function(r){ return r.syncId !== syncId; });
    total += db.length - left.length;
    if(left.length !== db.length) set(k, left);
  });
  toast(total + '건을 되돌렸습니다 — 다음 동기화 때 다시 들어옵니다');
  PU_SYNC_STORES.forEach(function(k){ try{ if(CAREER_CFG[k]) renderCareer(k); }catch(e){} });
}
function puUndoLastSync(){
  var sid = LS.get(NS + 'pu_sync_last_id') || '';
  if(!sid){ toast('되돌릴 동기화 기록이 없습니다'); return; }
  if(confirm('이번 동기화로 들어온 실적을 모두 지웁니다.\n(' + sid + ')\n배제해 둔 것도 함께 지워지고, 다음 동기화 때 다시 들어옵니다.\n\n계속할까요?')) puUndoSync(sid);
}

/* ===== 외부기관 실적 — agency별 그룹 + 그 기관이 발급한 증명서(certdoc) 자동 연결 ===== */
function _agencyNorm(s){ return String(s||'').replace(/[\s\(\)（）\-·]/g,'').toLowerCase(); }
function renderPuAgency(){
  var box = $('puagBody'); if(!box) return;
  var q = _agencyNorm(($('puagQ')||{}).value||'');
  var LABEL = { case:'사건', consult:'컨설팅', fund:'기금', etc:'기타' };
  var groups = {};                                          /* 정규화 기관명 → {name, rows} */
  PU_SYNC_STORES.forEach(function(k){
    get(k).forEach(function(r){
      if(!r || !r.agency || r.excluded) return;
      var key = _agencyNorm(r.agency);
      if(!groups[key]) groups[key] = { name: r.agency, rows: [] };
      groups[key].rows.push(Object.assign({ _store: k, _label: LABEL[k] }, r));
    });
  });
  var certs = get('certdoc');
  var keys = Object.keys(groups).sort(function(a,b){ return groups[b].rows.length - groups[a].rows.length; });
  if(q) keys = keys.filter(function(key){
    var g = groups[key];
    return key.indexOf(q) >= 0 || g.rows.some(function(r){ return _agencyNorm((r.org||'')+(r.project||'')).indexOf(q) >= 0; });
  });
  var total = keys.reduce(function(s,k){ return s + groups[k].rows.length; }, 0);
  var cnt = $('puagCnt'); if(cnt) cnt.textContent = keys.length + '개 기관 · ' + total + '건';
  if(!keys.length){ box.innerHTML = '<div style="font-size:12px;color:var(--text-mute);padding:20px;text-align:center">외부기관 실적이 없습니다 — 실적 행을 열어 수행기관을 채우면 여기로 모입니다</div>'; return; }
  box.innerHTML = keys.map(function(key){
    var g = groups[key];
    var years = g.rows.map(function(r){ return r.year; }).filter(Boolean).sort();
    var yr = years.length ? (years[0] === years[years.length-1] ? years[0] : years[0] + '~' + years[years.length-1]) : '';
    /* 이 기관이 발급한 증명서: certdoc의 발급기관(org) 부분일치 + 손으로 연결한 것(agencyKey) */
    var myCerts = certs.filter(function(c){
      if(_agencyNorm(c.agencyKey) === key) return true;
      var a = _agencyNorm(c.org), b = key;
      return a && (a.indexOf(b.slice(0,6)) >= 0 || b.indexOf(a.slice(0,6)) >= 0);
    });
    return '<div class="card" style="margin-bottom:12px">'
      + '<div style="display:flex;align-items:center;gap:8px;margin-bottom:8px"><strong style="font-size:14px">🏛 ' + escapeHtml(g.name) + '</strong>'
      + '<span style="font-size:11px;color:var(--text-mute)">' + g.rows.length + '건' + (yr ? ' · ' + yr : '') + '</span></div>'
      + g.rows.map(function(r){
          return '<div style="display:flex;gap:6px;align-items:center;font-size:12px;padding:5px 0;border-top:1px solid var(--border-soft);flex-wrap:wrap">'
            + '<span class="tag navy">' + r._label + '</span>'
            + '<span style="white-space:nowrap">' + escapeHtml(r.year||'-') + '</span>'
            + '<strong style="min-width:90px">' + escapeHtml(r.org||'-') + '</strong>'
            + '<span style="flex:1;min-width:120px;overflow:hidden;text-overflow:ellipsis;white-space:nowrap">' + escapeHtml(r.project||r.type||'') + '</span>'
            + '<span style="color:var(--text-mute);white-space:nowrap">' + escapeHtml(r.main||'-') + '</span>'
            + (r.src==='pu' ? '<span class="tag" style="font-size:10px">pu</span>' : '')
            + '</div>';
        }).join('')
      + '<div style="margin-top:8px;padding-top:8px;border-top:1px dashed var(--border);font-size:12px">'
      + '<span style="font-weight:600;color:var(--teal)">📜 이 기관이 발급한 증명서 ' + myCerts.length + '건</span> '
      + '<button class="btn sm" onclick="openCertLink(\'' + _jsAttr(g.name) + '\')">➕ 증명서 연결</button>'
      + myCerts.map(function(c){
          return '<div style="display:flex;gap:6px;align-items:center;padding:4px 0">'
            + '<span style="flex:1">' + escapeHtml(c.title||c.fname||c.id) + ' <span style="color:var(--text-mute)">(' + escapeHtml(formatDate(c.date)||'-') + ')</span></span>'
            + (hasOriginal(c) ? '<button class="btn sm" onclick=\'openOriginal(' + JSON.stringify({id:c.id,src:c.src||"",relPath:c.relPath||""}).replace(/'/g,"&#39;") + ')\'>📄 원본</button>' : '')
            + '</div>';
        }).join('') + '</div>'
      + '</div>';
  }).join('');
}

/* 자동 매칭이 놓친 증명서를 손으로 연결 — certdoc.agencyKey에 기관명을 붙인다(설계서 §7) */
var _certLinkAgency = '';
function openCertLink(agencyName){
  _certLinkAgency = agencyName;
  var key = _agencyNorm(agencyName);
  var list = get('certdoc').filter(function(c){ return _agencyNorm(c.agencyKey) !== key; });
  $('certLinkBody').innerHTML = '<div style="font-size:12px;color:var(--text-mute);margin-bottom:8px">'
    + escapeHtml(agencyName) + ' 그룹에 연결할 증명서를 고르세요</div>'
    + (list.length ? list.map(function(c){
        return '<div style="display:flex;gap:6px;align-items:center;font-size:12px;padding:5px 0;border-bottom:1px solid var(--border-soft)">'
          + '<span style="flex:1">' + escapeHtml(c.title||c.fname||c.id) + ' <span style="color:var(--text-mute)">' + escapeHtml(c.org||'') + '</span></span>'
          + '<button class="btn sm primary" onclick="linkCert(\'' + _jsAttr(c.id) + '\')">연결</button></div>';
      }).join('') : '<div style="font-size:12px;color:var(--text-mute)">연결할 증명서가 없습니다</div>');
  $('modalCertLink').classList.add('open');
}
function linkCert(certId){
  var db = get('certdoc'), c = db.find(function(x){ return x.id === certId; });
  if(!c){ toast('증명서를 찾을 수 없습니다'); return; }
  c.agencyKey = _certLinkAgency; set('certdoc', db);
  $('modalCertLink').classList.remove('open');
  renderPuAgency();
  toast('✅ 연결했습니다');
}
function closeCertLink(){ $('modalCertLink').classList.remove('open'); }
