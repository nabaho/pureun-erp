# 폰에서 기업 상세 쓰기 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 폰(좁은 화면)에서도 기업 상세(회사 목록·상세·폴더·태그·이알피 가져오기)를 PC와 같은 기능으로 쓸 수 있게 한다.

**Architecture:** `pu-cards.html`은 이미 PC(`#pcRoot`, `IS_PC`)와 폰(`#tabs`/`#list`, `renderMobile`) 두 갈래로 나뉘어 있다. 폴더·태그·이알피 가져오기의 실제 로직(`_coFolders`, `coMoveToFolder`, `openCoFolderDialog` 등)은 이미 이 갈래 밖의 공용 자리에 있으므로 그대로 재사용한다. 새로 만드는 것은 (1) 상단 탭에 세 번째 버튼, (2) 카드 목록을 그리는 폰 전용 함수, (3) 상세 패널을 폰 너비에서 전체화면으로 보이게 하는 CSS, (4) 폴더/태그를 고르는 바텀시트, (5) 여러 곳 골라 옮기기 뿐이다. 저장 후 다시 그리는 지점들은 PC/폰을 자동으로 가리는 `render()`를 통하도록 통일한다.

**Tech Stack:** 순수 JS(빌드 없음), Firebase Realtime Database, `node:test`+`node:vm` 기반 테스트(소스에서 함수를 잘라 실제 실행).

## Global Constraints

- 설계서: `docs/superpowers/specs/2026-08-15-폰-기업상세-design.md` — 모든 과제는 이 설계서의 요구를 벗어나지 않는다.
- PC 관리자 화면(`#pcRoot`, `renderPC()`, `renderCoPage()` 등)은 **한 글자도 안 바꾼다** — 이번 범위는 폰뿐이다.
- 표 정렬·열 깔때기(`coSortBy`, `coApplyColFilter`, `openCoColFilter`)는 이번 범위 밖이다 — 손대지 않는다.
- 회사를 폰에서 손으로 만들거나 지우지 않는다(설계서·이전 설계서 모두 동일 원칙).
- 커밋 전 항상 `node --test tests/*.test.js` 전체 실행, 뮤테이션 테스트로 새 검사가 실제로 잡아내는지 확인.
- 파일 수정은 Edit/Write 도구만 쓴다 — PowerShell `Set-Content`/`Out-File` 왕복은 UTF-8 파일을 깨뜨린 전례가 있다(STATUS.md 2026-08-11 교훈).

```javascript
const test = require('node:test');

const path = require('node:path');
```

```javascript
const source = fs.readFileSync(path.join(__dirname, '..', 'pu-cards.html'), 'utf8');

function loadBlock(list){
  const at = source.indexOf('function renderCoMobileList');
  const end = source.indexOf('\nfunction ', at + 10);
  assert.ok(at > 0, 'renderCoMobileList 를 찾지 못했습니다');
  const calls = { html:'' };
  const ctx = {
    esc: s => String(s ?? '').replace(/[&<>"']/g, c=>({'&':'&amp;','<':'&lt;','>':'&gt;','"':'&quot;',"'":'&#39;'}[c])),

  };
  vm.createContext(ctx);
  vm.runInContext(source.slice(at, end), ctx);
  ctx._calls = calls;
  return ctx;
}
```

Task 1에서 만든 뼈대를 지운다:


다음으로 바꾼다:

```javascript
/* 폰 기업 상세 카드 목록 — 명함 목록(renderList)과 같은 .row/.rowmain/.nm/.l1/.l2
   클래스를 그대로 쓴다(대표가 고른 A안: 카드 목록 + 전체화면 상세, 2026-08-15).
   담는 자료는 PC 표(coListHtml)와 똑같이 coVisible() 을 쓴다 — 회사 목록 계산을
   두 벌로 두면 한쪽만 고쳤을 때 어긋난다(기업정보 폴더 설계서의 교훈과 같다). */
function renderCoMobileList(){
  const el = $('list'); if(!el) return;
  const list = coVisible();
  if(!list.length){
    el.innerHTML = `<div class="empty">회사를 찾지 못했습니다.</div>`;
    return;
  }
  el.innerHTML = list.map(o=>{
    const folder = o.folder ? _coFolders[o.folder] : null;
    const tags = coTagsOf(o);
    const click = state.selMode ? `coToggle('${esc(o.key)}')` : `pickCo('${esc(o.key)}')`;
    const badges = [
      o.erp && o.erp.type ? `<span class="tg">${esc(o.erp.type)}</span>` : '',
      folder ? `<span class="tg">📁 ${esc(folder.name)}</span>` : '',
      ...tags.map(t=>`<span class="tg">${esc(t)}</span>`)
    ].join('');
    const l1 = [o.bizno||'', o.erp && o.erp.main ? '담당 '+o.erp.main : ''].filter(Boolean).join(' · ');
    return `<div class="row" onclick="${click}">
      ${state.selMode?`<div class="selmark">${state.coSel[o.key]?'✅':'⚪'}</div>`:''}
      <div class="rowmain"><div class="nm">${esc(o.name)}</div>
        ${l1?`<div class="l1">${esc(l1)}</div>`:''}
        ${badges?`<div class="l2">${badges}</div>`:''}
      </div>
    </div>`;
  }).join('');
}
```

```javascript
   써지는" 것과 같은 종류의 사고 — "PC 화면인데 폰 함수가 돌거나, 그 반대" — 를 막는다. */
const test = require('node:test');
const assert = require('node:assert/strict');
const fs = require('node:fs');
const path = require('node:path');
const vm = require('node:vm');

const source = fs.readFileSync(path.join(__dirname, '..', 'pu-cards.html'), 'utf8');

function loadRenderAny(){
  const at = source.indexOf('function renderCoAny');
  const end = source.indexOf('\n}', at) + 2;
  const calls = { mobile:0, pc:0 };
  const ctx = {
    state: { tab:'card', view:'list' },
    renderCoMobileList: () => calls.mobile++,
    renderPC: () => calls.pc++
  };
  vm.createContext(ctx);
  vm.runInContext(source.slice(at, end), ctx);
  ctx._calls = calls;
  return ctx;
}

test('폰에서 기업 상세 탭을 보고 있으면 renderCoMobileList 만 부른다', () => {
  const c = loadRenderAny();
  c.state.tab = 'co'; c.state.view = 'list';
  c.renderCoAny();
  assert.equal(c._calls.mobile, 1);
  assert.equal(c._calls.pc, 0);
});

test('PC에서 기업 상세 화면을 보고 있으면 renderPC 만 부른다', () => {
  const c = loadRenderAny();
  c.state.tab = 'card'; c.state.view = 'co';
  c.renderCoAny();
  assert.equal(c._calls.mobile, 0);
  assert.equal(c._calls.pc, 1);
});

test('둘 다 아니면(다른 화면을 보는 중) 아무 것도 안 부른다', () => {
  const c = loadRenderAny();
  c.state.tab = 'card'; c.state.view = 'list';
  c.renderCoAny();
  assert.equal(c._calls.mobile, 0);
  assert.equal(c._calls.pc, 0);
});

const SITES = [
  { fn: 'pickCoTag', desc: '태그 고르기' },
  { fn: 'hideCoTag', desc: '태그 숨기기' },
  { fn: 'deleteCoFolder', desc: '폴더 삭제' },
  { fn: 'toggleCoErpOnly', desc: '거래처만 보기' },
  { fn: 'coToggle', desc: '체크 토글' },
  { fn: 'coMoveSelTo', desc: '폴더 이동' },
  { fn: 'coApplyTag', desc: '태그 담기' },
  { fn: 'coSelAll', desc: '전체 선택' },
  { fn: 'coImportFolderFromType', desc: '이알피 가져오기' },
];

for (const { fn, desc } of SITES){
  test(`${fn}(${desc}) 은 renderPC 를 직접 안 부르고 renderCoAny 를 부른다`, () => {
    const at = source.indexOf(`function ${fn}(`);
    assert.ok(at > 0, `${fn} 을 찾지 못했습니다`);
    const end = source.indexOf('\nfunction ', at + 10);
    const body = source.slice(at, end);
    assert.doesNotMatch(body, /\brenderPC\(\)/, `${fn} 이 아직 renderPC() 를 직접 부릅니다`);
    assert.doesNotMatch(body, /\brenderCoPage\(\)/, `${fn} 이 아직 renderCoPage() 를 직접 부릅니다`);
    assert.match(body, /\brenderCoAny\(\)/, `${fn} 이 renderCoAny() 를 불러야 합니다`);
  });
}

test('_coInfo/_coTagHidden/_coFolders 구독 콜백도 renderCoAny 를 쓴다', () => {
  ['coInfo','coTagHidden','coFolders'].forEach(k=>{

  });
```

```javascript
/* 기업 상세는 PC(표)·폰(카드 목록) 두 갈래로 그려진다. 저장 후 다시 그릴 때
   "지금 보고 있는 쪽"만 정확히 다시 그리려면 이 함수 하나를 거쳐야 한다 —

  if(state.view==='co') renderPC();
}
```
