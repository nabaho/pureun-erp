# 급여데이터함 값 층 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 급여데이터함에 담긴 서류를 사람이 「판독하기」로 읽어 사람별 값으로 정리하고, 월별 값 표에서 엑셀·복사로 바깥 급여프로그램에 넘길 수 있게 한다.

**Architecture:** 부품은 대부분 이미 있다(`buildValueRows`·`saveValues`·`findDuplicateValue`·`readWageTable`·`fileToDataUrl`). 이 계획은 **배선과 화면**을 만든다. 판독 결과 세 가지 모양을 `{name, pairs:[{item,value}]}` 하나로 맞추는 정규화 함수를 새로 두고, 그 뒤는 이미 있는 저장 부품에 그대로 흘려보낸다.

**Tech Stack:** 단일 파일 HTML(빌드 없음) · Firebase RTDB/Storage · `node --test` · 공용 판독 층 `js/pu-doc-read.js`(Gemini)

설계서: `docs/superpowers/specs/2026-08-15-급여데이터함-값층-design.md`
목업: `docs/mockups/paydata-read-value.html` · `docs/mockups/paydata-value-table.html`

## Global Constraints

- **공용 판독 층(`js/pu-doc-read.js`)에서 다른 앱이 기대는 동작을 바꾸지 않는다.** 사진첩·명함첩·업체관리가 함께 쓴다.
  - `read()` 와 `PROMPT_ALL`(그 안의 모든 kind) 은 **손대지 않는다** — 저 셋이 실제로 부르는 것이다.
  - `readWageTable`·`readChangeNotice` 는 급여데이터함만 쓴다. **겉모양(이름·인자·돌려주는 꼴)이 그대로면 속을 함께 쓰도록 묶어도 된다** — Task 2 가 그렇게 한다. 짝 검사(`tests/paydata-wage-read.test.js`)가 겉모양을 지킨다.
- **검사 판정은 종료코드로.** `node --test tests/*.test.js` 를 돌리고 `echo "EXIT:$?"` 가 `EXIT:0` 인지 본다. 출력만 골라 읽지 않는다.
- **커밋은 경로를 찍어서.** `git add -A` / `git add .` 금지 — 여러 세션이 같은 작업트리를 쓴다.
- **한국어 주석.** 화면 문구도 한국어. 영어 내부 용어를 사람에게 노출하지 않는다.
- **새 콘솔 규칙 없음.** `paydata/u/$owner/values/{slot}/{rowId}` 는 이미 열려 있다.
- **급여대장 판독은 만들되 꺼 둔다** — 처리위탁 근거 정리 전까지(설계서 9장). 상수 하나로 끈다.
- vm 샌드박스 안에서 만든 배열은 밖의 배열과 종류가 달라 `assert.deepEqual` 이 튕긴다. `.length` 나 `.join(',')` 로 견준다.

### Task 1: 판독 결과를 값 줄 하나의 모양으로 맞춘다

세 가지 판독 결과(근태·급여대장·알림)가 모양이 다르다. `buildValueRows` 가 받는
`{name, pairs:[{item,value}]}` 로 맞추는 **순수 함수**를 저장 층에 둔다.
근태만 모양이 다르고(`paid`·`off` 날짜 배열), 나머지 둘은 이미 맞는 모양이다.

**Files:**
- Modify: `js/pu-paydata-store.js` (`buildValueRows` 바로 위)
- Test: `tests/paydata-read-rows.test.js`

**Interfaces:**
- Produces:
  - `S.readKindFor(kind)` → `'timesheet' | 'wage' | 'notice' | null` — 서랍 종류 키를 받아 판독 방식을 돌려준다. `null` 이면 판독 단추를 그리지 않는다.
  - `S.rowsFromRead(readKind, parsed)` → `[{name, pairs:[{item,value}]}]`

`js/pu-paydata-store.js` 에서 `function buildValueRows(` 바로 **위**에 넣는다:

```js
  /* ══════ 판독 결과 → 값 줄 (2026-08-15) ══════
     판독 결과가 서류마다 모양이 다르다. buildValueRows 가 받는
     {name, pairs:[{item,value}]} 하나로 맞춘다. 근태만 모양이 다르고
     (paid·off 가 날짜 배열) 나머지 둘은 이미 맞는 모양이라 그대로 흘린다. */

  /* 서랍 종류 → 판독 방식. null 이면 그 탭에는 판독 단추를 그리지 않는다.
     근로계약서는 값을 뽑을 것이 아니고, 우리 산출물은 우리가 만든 것이라
     다시 읽을 이유가 없다. */
  function readKindFor(kind) {
    if (kind === 'attend') return 'timesheet';
    if (kind === 'ledger') return 'wage';
    if (kind === 'etc') return 'notice';
    return null;
  }

  /* 값이 비면 그 항목을 아예 만들지 않는다 — 0 과 「없음」은 다르다.
     (월별 값 표에서 없는 항목은 0 이 아니라 「－」로 보여야 한다) */
  function pushPair(pairs, item, value) {
    var v = String(value == null ? '' : value).trim();
    if (v) pairs.push({ item: item, value: v });
  }

  function rowsFromRead(readKind, parsed) {
    var src = (parsed && parsed.rows) || [];
    var out = [];
    src.forEach(function (r) {
      var name = String((r && r.name) || '').trim();
      if (!name) return;
      var pairs = [];
      if (readKind === 'timesheet') {
        var paid = Array.isArray(r.paid) ? r.paid : [];
        var off = Array.isArray(r.off) ? r.off : [];
        if (paid.length) pushPair(pairs, '유급일수', paid.length + '일');
        if (off.length) pushPair(pairs, '휴무일수', off.length + '일');
        pushPair(pairs, '가감', r.adj);
        pushPair(pairs, '비고', r.note);
      } else if (readKind === 'wage' || readKind === 'notice') {
        (Array.isArray(r.pairs) ? r.pairs : []).forEach(function (p) {
          var item = String((p && p.item) || '').trim();
          if (item) pushPair(pairs, item, p && p.value);
        });
      } else {
        return;                       // 모르는 방식은 아무것도 만들지 않는다
      }
      if (!pairs.length) return;      // 항목이 하나도 없으면 값 줄이 아니다
      out.push({ name: name, pairs: pairs });
    });
    return out;
  }
```

내보내는 목록(`global.PuPaydataStore = {`)의 `buildValueRows: buildValueRows,` 바로 위에 넣는다:

```js
    readKindFor: readKindFor,
    rowsFromRead: rowsFromRead,
```

```js
/* 급여대장 판독은 만들어 두되 켜지 않는다 — 근로자 성명·임금액이 구글로 나가는

const WAGE_READ_ON = false;

/* 오른쪽 절반 — 판독 전에는 단추, 판독 뒤에는 값 표. */
function readPanelHtml() {
  const rk = S.readKindFor(App.kind);
  const st = App.readState || { status: 'idle', rows: [], err: '' };
  let body;

  if (rk === 'wage' && !WAGE_READ_ON) {
    body = '<div class="pre"><div class="big">🔒</div><p><b>급여대장 판독은 준비 중입니다.</b><br>'
      + '근로자 성명·임금액이 밖으로 나가는 문제를 먼저 정리한 뒤 켭니다.</p></div>';
  } else if (!rk || !canWrite()) {
    body = '<div class="pre"><div class="big">📄</div><p>'
      + (!rk ? '이 종류는 값을 뽑지 않습니다.' : '남의 자리에서는 판독할 수 없습니다.')
      + '</p></div>';
  } else if (st.status === 'reading') {
    body = '<div class="pre"><div class="big">⏳</div><p>읽는 중입니다…</p></div>';
  } else if (st.status === 'err') {
    body = '<div class="pre"><div class="big">⚠</div><p>' + esc(st.err) + '</p>'
      + '<button class="btn pri" onclick="doRead()">🔍 다시 판독</button></div>';
  } else {
    body = '<div class="pre"><div class="big">🔍</div><p>아직 읽지 않았습니다.<br>'
      + '누르면 AI가 이 서류를 읽어 <b>사람별 표</b>로 만듭니다.<br>'
      + '읽은 뒤 확인하고 저장해야 값으로 남습니다.</p>'
      + '<button class="btn pri" onclick="doRead()">🔍 판독하기</button></div>';
  }
  return '<div id="readPanel"><div class="ph"><b>판독 결과</b></div>'
    + '<div class="pbody">' + body + '</div></div>';
}
```

```js
   사람이 한 줄, 항목이 가로. 바깥 급여프로그램에 넣기 좋은 모양이다. */
function valueGridModel(valueRows) {
  const box = valueRows || {};
  const items = [], seenItem = {};
  const people = [], byName = {};
  Object.keys(box).forEach(id => {
    const r = box[id];
    if (!r || !r.name) return;
    let p = byName[r.name];
    if (!p) { p = byName[r.name] = { name: r.name, cells: {} }; people.push(p); }
    (r.pairs || []).forEach(pr => {
      if (!pr || !pr.item) return;
      if (!seenItem[pr.item]) { seenItem[pr.item] = 1; items.push(pr.item); }
      p.cells[pr.item] = { value: pr.value, sourceId: r.sourceId || '', confirmed: !!r.confirmed };
    });
  });
  return { items: items, people: people };
}

function ensureValues() {
  const slot = S.monthKey(App.month) || S.KEEP;
  return S.listValues(slot, App.viewingUid).then(v => {
    /* 이 사업장 것만 남긴다 — 값 칸은 그 달 전체가 한 자리에 있다. */
    const mine = {};
    Object.keys(v || {}).forEach(id => {
      if (v[id] && v[id].companyId === App.companyId) mine[id] = v[id];
    });
    App.values = mine; App.render();
  }).catch(e => { console.warn('[값]', e && e.code); App.values = {}; App.render(); });
}

function screenValues() {
  const g = valueGridModel(App.values);
  const iffy = g.people.reduce((n, p) =>
    n + Object.keys(p.cells).filter(k => !p.cells[k].confirmed).length, 0);

  let h = '<div style="margin-bottom:10px"><button class="btn" onclick="App.go(\'drawer\')">← 서랍으로</button></div>'
    + '<h1>' + esc(App.companyName || App.companyId) + ' — ' + esc(App.month) + ' 값</h1>'
    + '<div class="sub">근로자 ' + g.people.length + '명 · 항목 ' + g.items.length + '가지</div>';

  if (!g.people.length) {
    return h + '<div class="card"><div class="empty">아직 정리된 값이 없습니다.<br>'
      + '서랍에서 서류를 열고 「판독하기」를 눌러 주세요.</div></div>';
  }

  if (iffy) {
    h += '<div class="warnline" style="margin-bottom:12px">⚠ <b>확인 안 된 값이 ' + iffy
      + '개</b> 있습니다. 노란 칸을 눌러 원본과 견주어 주세요.</div>';
  }

  h += '<div class="bar" style="display:flex;gap:8px;margin-bottom:12px">'
    + '<button class="btn" onclick="valuesCsv()">⬇ 엑셀로 내려받기</button>'
    + '<button class="btn" onclick="valuesCopy()">📋 표 복사</button></div>';

  h += '<div class="card" style="overflow-x:auto"><table class="grid">'
    + '<tr><th>근로자</th>' + g.items.map(i => '<th>' + esc(i) + '</th>').join('') + '</tr>';
  g.people.forEach(p => {
    h += '<tr><td class="who">' + esc(p.name) + '</td>'
      + g.items.map(i => {
        const c = p.cells[i];
        if (!c) return '<td class="num">－</td>';
        return '<td class="num src' + (c.confirmed ? '' : ' iffy') + '"'
          + (c.sourceId ? ' onclick="openViewer(\'' + esc(c.sourceId) + '\')"' : '')
          + '>' + esc(c.value) + '</td>';
      }).join('') + '</tr>';
  });
  h += '</table></div>';
  return h;
}
```

```js
function csvEsc(v) {
  const s = String(v == null ? '' : v);
  return /[",\n]/.test(s) ? '"' + s.replace(/"/g, '""') + '"' : s;
}

/* 내보낼 표 한 벌 — 내려받기와 복사가 같은 것을 쓴다(두 벌로 두면 어긋난다). */
function valuesTable() {
  const g = valueGridModel(App.values);
  return {
    title: [App.companyName + ' ' + App.month + ' 값'],
    head: ['근로자'].concat(g.items),
    body: g.people.map(p => [p.name].concat(g.items.map(i => (p.cells[i] ? p.cells[i].value : ''))))
  };
}

function valuesCsv() {
  const t = valuesTable();
  const lines = [t.title.join('')].concat([t.head.join(',')])
    .concat(t.body.map(r => r.map(csvEsc).join(',')));
  const name = ('값_' + App.companyName + '_' + App.month).replace(/[\\/:*?"<>|\s]+/g, '_');
  /* ﻿ 는 BOM — 없으면 엑셀이 한글을 깨뜨린다 */
  saveBlob(new Blob(['﻿' + lines.join('\r\n')], { type: 'text/csv;charset=utf-8' }), name + '.csv');
}

function valuesCopy() {
  const t = valuesTable();
  const tsv = [t.head.join('\t')].concat(t.body.map(r => r.join('\t'))).join('\n');
  navigator.clipboard.writeText(tsv).then(
    () => alert('표를 복사했습니다 — 엑셀이나 급여프로그램에 붙여넣으세요.'),
    () => alert(tsv));
}
```
