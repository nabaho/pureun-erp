# kcareer 증명서 판정 확장 구현계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 증명서 판정을 "이름 어느 자리에든"으로 확장해 누락된 190건을 살리고, 외부기관 발급 실적증명 67건을 발급기관까지 채워 등록한다.

**Architecture:** `js/kcareer-scan.js`의 `RESULT_END`에서 증명서 낱말을 떼어 새 `CERT_ANY`로 옮긴다. 위촉장·표창·자격증은 "이름 끝" 규칙 그대로다. `classify`는 certdoc일 때 `certKind`(`ext`/`own`)를 함께 돌려주고, `kcareer.html`의 증명서 스캔이 그 값으로 두 묶음을 갈라 미리보기에 세고, 발급기관은 폴더 경로에서 추정한다.

**Tech Stack:** 순수 ES5 스타일 JS(빌드 없음), `node:test` + `node:assert/strict`

**설계서:** `docs/superpowers/specs/2026-08-06-kcareer-증명서판정확장-design.md`

## Global Constraints

- **위촉장·표창·자격증·수료증·협약서 판정은 바뀌면 안 된다.** 회귀테스트(상공회의소 위촉장, 위촉장 목록·위촉식 시나리오)를 유지하고 통과해야 한다.
- **`NEGATIVE` 부정어와 `ORIG_EXT` 확장자 제한은 증명서에도 그대로 적용.** 실측으로 검증됨 — 부정어가 막은 3건은 전부 신청서 묶음·빈 양식이었다.
- ⚠ **부정어에 `회의`를 넣지 말 것** — `상공회의소 위촉장`이 오탐된다.
- **이번 스캔은 외부기관(`ext`)만 기본 체크.** 본인 경력·재직증명(`own`) 146건은 사용자가 체크를 켜야 들어온다.
- **기관 후보 사전을 새로 만들지 않는다** — pu-erp 유형 코드표의 `agency`, 기존 실적의 `agency`, 기존 `certdoc`의 `issuer`에서만 모은다.
- **`made`(직접 만든 증명서)는 스캔이 건드리지 않는다.**
- 원본은 복사하지 않고 경로 참조(`src:'fs'`, `relPath`). 미리보기 → [등록], `scanId` 되돌리기, 등록된 `relPath`는 건너뛴다.
- 반복문 안에서 `set()` 금지 — 스토어 단일 쓰기.
- 작업 폴더는 `C:\Users\fair0\Documents\pureunall-kcareer` (main 고정). 매 태스크 끝 즉시 커밋, push 전 `git pull --rebase origin main`.

`KIND_MAP`의 마지막 항목(증명서)을 **지운다**. 증명서는 `CERT_ANY`로 따로 처리한다:

```js
  // 이름 끝 단어 → 어느 목록으로 갈지 (증명서는 CERT_ANY로 따로 판정한다)
  var KIND_MAP = [
    { re: /(위촉장|위촉계약서|재위촉|위촉서)$/,                  store: 'wiccok',  type: '위촉장', titleHint: '' },
    { re: /협약서$/,                                          store: 'wiccok',  type: '협약서', titleHint: '' },
    { re: /(표창장|표창|포상|상장)$/,                           store: 'wiccok',  type: '표창',   titleHint: '' },
    { re: /자격증$/,                                          store: 'cert',    type: '',       titleHint: '자격' },
    { re: /(수료증|이수증)$/,                                  store: 'cert',    type: '',       titleHint: '수료' }
  ];
```

`mapKind` 아래에 추가:

```js
  /* 증명서 성격 — 기관이 내 실적을 증명한 것(ext)과 푸른이 본인 경력을 증명한 것(own).
     외부기관 실적 탭 기관 묶음에는 ext만 붙어야 한다(설계서 5). */
  var CERT_EXT = /실적\s*증명|수행실적\s*증명|참여확인서|수행확인서|용역수행|수행\s*확인/;
  var CERT_OWN = /경력증명|재직증명/;
  function certKindOf(core) {
    var s = String(core || '');
    if (CERT_EXT.test(s)) return 'ext';
    if (CERT_OWN.test(s)) return 'own';
    return '';
  }
```

`classify`를 이렇게 바꾼다 — **증명서를 위촉장 계열보다 먼저** 본다(둘 다 걸리는 이름이 없으므로 순서 자체는 무해하지만, 증명서 판정이 `RESULT_END`에 의존하지 않음을 코드로 분명히 한다):

```js
  function classify(name) {
    if (isIgnoredFile(name)) return { level: 'ignore' };
    var core = cleanCore(name);
    var neg = NEGATIVE.test(core);
    var isOrig = ORIG_EXT.test(String(name));
    if (isOrig && !neg) {
      /* 증명서 — 이름 어느 자리에든 */
      if (CERT_ANY.test(core)) {
        var ck = certKindOf(core);
        if (ck) return { level: 'sure', store: 'certdoc', type: '', titleHint: '', certKind: ck };
      }
      /* 위촉장·표창·자격증 계열 — 이름 끝만 */
      if (RESULT_END.test(core)) {
        var k = mapKind(core);
        if (k) return { level: 'sure', store: k.store, type: k.type, titleHint: k.titleHint };
      }
    }
    if (RESULT_ANY.test(core) && !neg) return { level: 'maybe' };
    return { level: 'submission' };
  }
```

/* 기관 후보 — 새 사전을 만들지 않는다. 시스템이 이미 아는 이름만 모은다(설계서 6). */
function _cdAgencyNames(){
  var set = {};
  function add(s){ s = String(s || '').trim(); if(s) set[s] = 1; }
  _puTypeAgencies().forEach(add);
  PU_SYNC_STORES.forEach(function(k){ get(k).forEach(function(r){ if(r) add(r.agency); }); });
  get('certdoc').forEach(function(r){ if(r) add(r.issuer); });

  return Object.keys(set).sort(function(a,b){ return b.length - a.length; });
}

function _cdGuessIssuer(f){
  var names = _cdAgencyNames();
  if(!names.length) return '';
  var dir = String(f.relPath || '');
  var i = dir.lastIndexOf('/');
  dir = i >= 0 ? dir.slice(0, i) : '';           /* 파일명을 뺀 경로만 */
  var hayDir = _agencyNorm(dir), hayName = _agencyNorm(f.name || '');
  for(var n = 0; n < names.length; n++){
    if(hayDir.indexOf(_agencyNorm(names[n])) >= 0) return names[n];
  }
  for(var m = 0; m < names.length; m++){
    if(hayName.indexOf(_agencyNorm(names[m])) >= 0) return names[m];
  }
  return '';
}
