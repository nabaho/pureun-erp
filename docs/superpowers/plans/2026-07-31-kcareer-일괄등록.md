# kcareer 서류 일괄등록 구현계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 권형하 대표의 실제 서류 3,979개를 원본 복사 없이(경로 참조) kcareer 앱에 전량 등록한다.

**Architecture:** 판정 규칙은 브라우저·Node 겸용 순수 모듈 `js/kcareer-scan.js`로 분리해 Node 단위테스트로 검증한다. 브라우저 부분(`kcareer.html`)은 File System Access API로 폴더 핸들을 한 번 받아 IndexedDB `kcareer_fs`에 보관하고, 스캔은 이름·크기·수정일만 읽어 미리보기를 만든 뒤 사용자가 "등록"을 눌렀을 때만 저장한다. 원본은 열람 시점에만 디스크에서 읽는다.

**Tech Stack:** 순수 ES5 스타일 JS(빌드 없음), File System Access API, IndexedDB, Firebase RTDB compat 10.13.2, `node:test` + `node:assert/strict`

**설계서:** `docs/superpowers/specs/2026-07-31-kcareer-일괄등록-design.md`

## Global Constraints

- **원본 폴더는 읽기 전용.** 서류 파일을 이동·개명·삭제하지 않는다. `showDirectoryPicker`·`queryPermission`·`requestPermission`은 **항상 `mode:'read'`**. `'readwrite'`를 쓰면 안 된다.
- **원본을 클라우드로 보내지 않는다.** Firebase Storage 업로드 금지. RTDB에는 메타데이터만.
- **데이터는 `kcareer/` 노드에만** 저장한다. pu-erp `data/`는 읽기 참조만.
- **기존 레코드·기존 base64 첨부를 변경하지 않는다.** 신규 필드(`src`,`relPath`,`fileSize`,`fileMtime`,`scanId`,`fromCase`,`promoted`)만 추가한다. `src`가 없는 기존 레코드는 `'idb'`로 간주한다.
- **자동 OCR 금지.** 스캔·등록 과정에서 OCR API를 호출하지 않는다.
- **`kcareer.html` 외 기존 파일을 건드리지 않는다.** `main`은 타 세션(급여·규정·명함첩·기금)과 공유되는 라이브 브랜치다. 신규 파일(`js/kcareer-scan.js`, `tests/kcareer-scan.test.js`, `tools/kcareer-scan-report.js`)은 충돌 없으므로 생성 가능.
- **매 태스크 끝에 즉시 커밋.** push는 사용자 승인 후에만, `git pull --rebase origin main` 먼저.
- 주석은 한국어. 노무 도메인 용어 준수(급여→임금, 직원→근로자).
- 대상 브라우저는 Chrome·Edge 데스크톱. 미지원 브라우저에서는 폴더 연결 UI를 숨긴다.
- PowerShell에서 한글 여러 줄 커밋 메시지는 인용부호가 깨진다. **커밋 메시지는 한 줄, 따옴표·괄호 없이** 쓰거나 `git commit -F <파일>`을 쓴다.

```js
'use strict';
// 푸른노무법인 경력관리 — 서류 폴더 스캔·판정 모듈
// (브라우저 window.KcareerScan / Node module.exports 겸용, DOM·브라우저 API 미사용)
// 설계서: docs/superpowers/specs/2026-07-31-kcareer-일괄등록-design.md
(function (root) {

  /* ===== 읽지 않는 파일 ===== */
  var IGNORE_PREFIX = /^(\.~lock\.|~\$)/;   // 엑셀·한글 임시·잠금 파일
  var IGNORE_EXACT = ['4NZFL.DOCX'];        // OneDrive 부산물(0바이트, 모든 폴더에 존재)
  var IGNORE_EXT = ['md'];                  // 작업 문서는 서류가 아니다

  function extOf(name) {
    var s = String(name == null ? '' : name);
    var dot = s.lastIndexOf('.');
    if (dot <= 0) return '';
    return s.slice(dot + 1).toLowerCase();
  }

  function isIgnoredFile(name) {
    var s = String(name == null ? '' : name);
    if (!s) return true;
    if (IGNORE_PREFIX.test(s)) return true;
    if (IGNORE_EXACT.indexOf(s) >= 0) return true;
    var ext = extOf(s);
    if (!ext) return true;                       // 확장자 없는 부산물(test_write 등)
    if (IGNORE_EXT.indexOf(ext) >= 0) return true;
    return false;
  }

  /* ===== 이름 정리 =====
     발급일 괄호와 사본 연번을 떼어, 뒤에서 '이름 끝 단어'를 정확히 볼 수 있게 만든다. */
  function cleanCore(name) {
    return String(name == null ? '' : name)
      .replace(/\.[^.]+$/, '')                                        // 확장자
      .replace(/\(\s*20\d{2}[.\-]\d{1,2}[.\-]\d{1,2}\s*\)/g, '')      // (2015.05.07)
      .replace(/\s*\(\d+\)\s*$/, '')                                  // (1) (2) 사본 연번
      .replace(/[\s_\-]+$/, '')
      .trim();
  }

  var api = {
    extOf: extOf,
    isIgnoredFile: isIgnoredFile,
    cleanCore: cleanCore
  };
  if (typeof module !== 'undefined' && module.exports) module.exports = api;
  else root.KcareerScan = api;
})(typeof globalThis !== 'undefined' ? globalThis : window);
```

```js
  /* ===== 3단계 판정 =====
     핵심 규칙: "이름 끝이 결과물 단어인가". 중간에 있으면 결과물이 아니다.
     예) '…위촉장' = 위촉장 / '위촉장 목록' = 목록표 / '위촉식 시나리오' = 행사 진행표 */
  var ORIG_EXT = /\.(pdf|jpg|jpeg|png|hwp|hwpx)$/i;
  var RESULT_END = /(위촉장|위촉계약서|재위촉|위촉서|표창장|표창|포상|상장|자격증|수료증|이수증|협약서|경력증명서|실적증명서|참여확인서|수행확인서)$/;
  var RESULT_ANY = /위촉장|위촉계약|재위촉|표창|포상|상장|자격증|수료증|이수증|협약서|경력증명|실적증명|참여확인|수행확인/;
  // ⚠ 부정어에 '회의'를 넣지 말 것 — '상공회의소 위촉장'이 오탐된다(설계서 7.3).
  var NEGATIVE = /동의서|신청서|제출|공고|양식|서식|명단|시나리오|좌석|추천\s*계획|모집|목록|초안|회의록|회의자료|교재|자료집|매뉴얼/;

  // 이름 끝 단어 → 어느 목록으로 갈지
  var KIND_MAP = [
    { re: /(위촉장|위촉계약서|재위촉|위촉서)$/,                 store: 'wiccok',  type: '위촉장', titleHint: '' },
    { re: /협약서$/,                                          store: 'wiccok',  type: '협약서', titleHint: '' },
    { re: /(표창장|표창|포상|상장)$/,                           store: 'wiccok',  type: '표창',   titleHint: '' },
    { re: /자격증$/,                                          store: 'cert',    type: '',       titleHint: '자격' },
    { re: /(수료증|이수증)$/,                                  store: 'cert',    type: '',       titleHint: '수료' },
    { re: /(경력증명서|실적증명서|참여확인서|수행확인서)$/,        store: 'certdoc', type: '',       titleHint: '' }
  ];

  function mapKind(core) {
    for (var i = 0; i < KIND_MAP.length; i++) {
      if (KIND_MAP[i].re.test(core)) return KIND_MAP[i];
    }
    return null;
  }

  function classify(name) {
    if (isIgnoredFile(name)) return { level: 'ignore' };
    var core = cleanCore(name);
    var neg = NEGATIVE.test(core);
    if (ORIG_EXT.test(String(name)) && RESULT_END.test(core) && !neg) {
      var k = mapKind(core);
      if (k) return { level: 'sure', store: k.store, type: k.type, titleHint: k.titleHint };
    }
    if (RESULT_ANY.test(core) && !neg) return { level: 'maybe' };
    return { level: 'submission' };
  }
```

```js
  /* ===== 레코드 조립 =====
     3,691개를 파일 단위로 넣으면 목록이 못 쓰게 되므로 7번은 건 폴더 단위로 묶는다.
     승격된 파일은 건의 첨부 목록에도 그대로 남긴다(경로 참조라 복제가 아니다). */
  function buildRecords(files, opts) {
    opts = opts || {};
    var scanId = opts.scanId || 'S0';
    var out = { promotions: [], maybes: [], submissions: [], copies: [], ignored: 0 };
    var copySeen = {};       // name|size → 최초 relPath
    var caseMap = {};        // caseKey → 건 레코드
    var caseOrder = [];

    (files || []).forEach(function (f) {
      if (isIgnoredFile(f.name)) { out.ignored++; return; }

      var ck = f.name + '|' + f.size;
      if (copySeen[ck]) { out.copies.push({ name: f.name, relPath: f.relPath, sameAs: copySeen[ck] }); return; }
      copySeen[ck] = f.relPath;

      var caseKey = caseKeyOf(f.relPath);
      var y = pickYear(f.name, f.relPath, f.mtime);
      var org = caseKey ? orgFromCaseDir(caseKey.split('/')[2]) : '';
      var c = classify(f.name);

      if (caseKey) {
        if (!caseMap[caseKey]) {
          caseMap[caseKey] = {
            caseDir: caseKey, year: y.year, org: org, title: caseKey.split('/')[2],
            files: [], promoted: [], fileCount: 0, src: 'fs', scanId: scanId
          };
          caseOrder.push(caseKey);
        }
        caseMap[caseKey].files.push({
          name: f.name, relPath: f.relPath, size: f.size, mtime: f.mtime, ext: extOf(f.name)
        });
      }

      if (c.level === 'sure') {
        out.promotions.push({
          store: c.store, type: c.type, titleHint: c.titleHint,
          name: f.name, relPath: f.relPath, fileSize: f.size, fileMtime: f.mtime,
          year: y.year, yearFrom: y.from, needCheck: y.needCheck,
          org: org, fromCase: caseKey || '', src: 'fs', scanId: scanId
        });
        if (caseKey) caseMap[caseKey].promoted.push(f.relPath);
      } else if (c.level === 'maybe') {
        out.maybes.push({
          name: f.name, relPath: f.relPath, fileSize: f.size, fileMtime: f.mtime,
          year: y.year, org: org, fromCase: caseKey || '', src: 'fs', scanId: scanId
        });
      } else if (!caseKey) {
        out.submissions.push({
          caseDir: '', year: y.year, org: '', title: cleanCore(f.name),
          files: [{ name: f.name, relPath: f.relPath, size: f.size, mtime: f.mtime, ext: extOf(f.name) }],
          fileCount: 1, promoted: [], src: 'fs', scanId: scanId
        });
      }
    });

    caseOrder.forEach(function (k) {
      var c = caseMap[k];
      c.fileCount = c.files.length;
      out.submissions.push(c);
    });
    return out;
  }
```

```js
// 폴더를 훑어 이름·크기·수정일만 읽는다(내용은 읽지 않는다)
function walk(dir, prefix, acc) {
  for (const e of fs.readdirSync(dir, { withFileTypes: true })) {
    const rel = prefix ? prefix + '/' + e.name : e.name;
    const full = path.join(dir, e.name);
    if (e.isDirectory()) { walk(full, rel, acc); continue; }
```

```js
/* ===== 서류 폴더 연결 (File System Access API) =====
   원본을 복사하지 않고 경로만 참조한다. 폴더는 항상 읽기(read) 전용으로만 연다. */
var _fsRoot = null;                       // FileSystemDirectoryHandle (이 기기 한정)

function fsSupported(){ return typeof window.showDirectoryPicker === 'function'; }

function _openFsDB(){ return new Promise(function(res, rej){
  var req = indexedDB.open('kcareer_fs', 1);
  req.onupgradeneeded = function(e){ e.target.result.createObjectStore('handles', {keyPath:'key'}); };
  req.onsuccess = function(e){ res(e.target.result); };
  req.onerror = function(){ rej(req.error); };
}); }

async function fsSaveRoot(handle){
  try{ var db = await _openFsDB();
    return new Promise(function(res){
      var tx = db.transaction('handles','readwrite');   /* IndexedDB 쓰기 — 원본 폴더가 아니다 */
      tx.objectStore('handles').put({key:'rootDir', handle:handle});
      tx.oncomplete = function(){ res(true); }; tx.onerror = function(){ res(false); };
    });
  }catch(e){ console.error('fsSaveRoot',e); return false; }
}

async function fsLoadRoot(){
  try{ var db = await _openFsDB();
    return new Promise(function(res){
      var req = db.transaction('handles','readonly').objectStore('handles').get('rootDir');
      req.onsuccess = function(){ res(req.result ? req.result.handle : null); };
      req.onerror = function(){ res(null); };
    });
  }catch(e){ return null; }
}

/* 권한 확인 — 읽기만. 'prompt'면 사용자 클릭(제스처) 안에서 호출돼야 승인창이 뜬다. */
async function fsEnsurePermission(handle){
  if(!handle) return false;
  var opt = {mode:'read'};
  try{
    if(await handle.queryPermission(opt) === 'granted') return true;
    return (await handle.requestPermission(opt)) === 'granted';
  }catch(e){ return false; }
}

async function fsConnectFolder(){
  if(!fsSupported()){ toast('이 브라우저는 폴더 연결을 지원하지 않습니다 — Chrome 또는 Edge에서 열어주세요'); return null; }
  try{
    var h = await window.showDirectoryPicker({id:'kcareer-docs', mode:'read'});
    _fsRoot = h; await fsSaveRoot(h);
    toast('✅ 서류 폴더 연결됨: ' + h.name);
    return h;
  }catch(e){
    if(e && e.name === 'AbortError') return null;      /* 사용자가 취소 */
    toast('폴더 연결 실패: ' + e.message); return null;
  }
}

async function fsRoot(){
  if(_fsRoot && await fsEnsurePermission(_fsRoot)) return _fsRoot;
  var h = await fsLoadRoot();
  if(h && await fsEnsurePermission(h)){ _fsRoot = h; return h; }
  return null;
}
```

```js
/* ===== 폴더 스캔 =====
   이름·크기·수정일만 읽는다. 내용(arrayBuffer)을 읽으면 OneDrive 클라우드 파일이 전부 내려온다. */
async function fsScanAll(onProgress){
  var root = await fsRoot();
  if(!root){ toast('먼저 환경설정에서 서류 폴더를 연결하세요'); return null; }
  var files = [], n = 0;
  async function walk(dir, prefix){
    for await (var ent of dir.entries()){
      var name = ent[0], h = ent[1];
      if(h.kind === 'directory'){ await walk(h, prefix ? prefix + '/' + name : name); continue; }
      try{
        var f = await h.getFile();     /* 메타데이터만 사용 — 내용은 읽지 않는다 */
        files.push({ name:name, relPath:(prefix ? prefix + '/' : '') + name,
                     size:f.size, mtime:new Date(f.lastModified).toISOString() });
      }catch(e){ console.warn('스캔 건너뜀', prefix, name, e); }
      if((++n % 200) === 0 && onProgress) onProgress(n);
    }
  }
  await walk(root, '');
  if(onProgress) onProgress(n);
  return files;
}

/* 이미 등록된 파일 건너뛰기 — 경로+크기+수정일이 같으면 같은 파일로 본다 */
function fsKnownKeys(){
  var map = {};
  function add(r){
    if(r && r.src === 'fs' && r.relPath) map[r.relPath + '|' + r.fileSize + '|' + r.fileMtime] = true;
    if(r && r.files) r.files.forEach(function(f){ map[f.relPath + '|' + f.size + '|' + f.mtime] = true; });
  }
  ['wiccok','cert','certdoc','submission'].forEach(function(k){ get(k).forEach(add); });
  return map;
}

/* ===== 미리보기 — 저장하지 않는다 ===== */
var _scanCtx = null;

async function openScanPreview(){
  var files = await fsScanAll(function(n){ toast('스캔 중… ' + n + '개'); });
  if(!files) return;
  var scanId = 'S' + new Date().toISOString().slice(0,10).replace(/-/g,'') + '-' + String(Date.now()).slice(-4);
  var known = fsKnownKeys();
  var fresh = files.filter(function(f){ return !known[f.relPath + '|' + f.size + '|' + f.mtime]; });
  var r = KcareerScan.buildRecords(fresh, {scanId: scanId});
  _scanCtx = { scanId:scanId, all:files, fresh:fresh, r:r, pickMaybe:{} };
  renderScanPreview();
  $('modalScan').classList.add('open');
}
```

```js
function fsCommitScan(){
  if(!_scanCtx){ toast('스캔 결과가 없습니다'); return; }
  var r = _scanCtx.r, scanId = _scanCtx.scanId, n = 0;
  var picked = r.maybes.filter(function(m, i){ return !!_scanCtx.pickMaybe[i]; });

     레코드마다 get/set을 부르면 수백 번 JSON 파싱·직렬화 + Firebase 재푸시가 일어난다. */
  var buf = { wiccok: get('wiccok'), cert: get('cert'), certdoc: get('certdoc'), submission: get('submission') };

     기존 wiccokId/nextId는 localStorage를 직접 보므로, 묶어 쓰는 동안에는 같은 ID가 계속 나온다. */
  function _bufIdWiccok(type, year){
    var pre = type + (year || '') + '-', n2 = 1;
    while(buf.wiccok.some(function(x){ return x.id === pre + String(n2).padStart(3,'0'); })) n2++;
    return pre + String(n2).padStart(3,'0');
  }
  function _bufIdSeq(prefix, store){
    var n2 = 1, mk = function(){ return prefix + String(n2).padStart(4,'0'); };
    while(buf[store].some(function(x){ return x.id === mk(); })) n2++;
    return mk();
  }

  /* 1) 🟢 승격 → 기존 목록 */
  r.promotions.forEach(function(p){
    var rec;
    if(p.store === 'wiccok'){
      rec = { id: _bufIdWiccok(p.type || '위촉장', p.year || ''), type: p.type || '위촉장',
              org: p.org || '', titleVal: KcareerScan.cleanCore(p.name), issuer: '',
              issueDate: '', period: '', year: p.year || '', note: '' };
    } else if(p.store === 'cert'){
      rec = { id: _bufIdSeq('C','cert'), title: _fsTitleFor(p), org: p.org || '', date: '', num: '', note: '' };
    } else {
      rec = { id: _bufIdSeq('CD','certdoc'), title: KcareerScan.cleanCore(p.name), org: p.org || '', date: '', note: '' };
    }
    rec.fname = p.name; rec.src = 'fs'; rec.relPath = p.relPath;
    rec.fileSize = p.fileSize; rec.fileMtime = p.fileMtime;
    rec.fromCase = p.fromCase || ''; rec.needCheck = !!p.needCheck;
    rec.scanId = scanId; rec.savedAt = new Date().toISOString();
    buf[p.store].unshift(rec); n++;
  });

  /* 체크된 🟡는 위촉장으로 올린다 — 종류를 모르므로 사람이 나중에 편집창에서 고친다 */
  picked.forEach(function(m){

      titleVal: KcareerScan.cleanCore(m.name), issuer:'', issueDate:'', period:'',

      title: s.title || '', caseDir: s.caseDir || '', files: s.files, fileCount: s.fileCount,
      promoted: s.promoted || [], src:'fs', scanId: scanId, savedAt: new Date().toISOString() });
    n++;
  });

  /* 3) 스토어별 단일 저장 — set()이 Firebase 자동 푸시를 예약한다(2.5초 디바운스) */
  ['wiccok','cert','certdoc','submission'].forEach(function(k){ set(k, buf[k]); });

  LS.set(NS + 'last_scan_id', scanId);
  closeScan();
  ['wiccok','license','complete','certdoc','submission'].forEach(function(p){
```

```js
/* 원본 존재 판정 — fs 레코드는 경로, 기존 레코드는 IndexedDB base64 */
function hasOriginal(r){
  if(!r) return false;
  if(r.src === 'fs') return !!r.relPath;
  return fileExists(r.id);
}
```

**3-2.** `openLocalOriginal`을 `fsRoot()` 아래에 추가:

```js
/* 로컬 폴더에서 원본을 그때 읽어 새 탭에 띄운다. 이 시점에만 OneDrive에서 내려온다. */
async function openLocalOriginal(relPath){
  var root = await fsRoot();
  if(!root){ toast('이 기기에는 서류 폴더가 연결돼 있지 않습니다 — 환경설정 › 서류 폴더 연결'); return; }
  try{
    var segs = String(relPath).split('/'), dir = root;
    for(var i = 0; i < segs.length - 1; i++) dir = await dir.getDirectoryHandle(segs[i]);
    var fh = await dir.getFileHandle(segs[segs.length - 1]);
    var f = await fh.getFile();
    var url = URL.createObjectURL(f);
    window.open(url, '_blank');
    setTimeout(function(){ URL.revokeObjectURL(url); }, 60000);
  }catch(e){
    console.warn('openLocalOriginal', relPath, e);
    toast('원본을 못 찾았습니다 — 파일이 이동·삭제되었을 수 있습니다. 다시 스캔하세요');
  }
}

/* 레코드 하나로 두 보관방식을 모두 처리하는 단일 입구 */
async function openOriginal(r){
  if(!r){ return; }
  if(r.src === 'fs'){ await openLocalOriginal(r.relPath); return; }
  var f = await getFileAsync(r.id);
  if(!f || !f.base64){ toast('첨부 원본이 없습니다'); return; }
  var url = URL.createObjectURL(new Blob([b64ToAb(f.base64)], {type:'application/octet-stream'}));
  window.open(url, '_blank');
  setTimeout(function(){ URL.revokeObjectURL(url); }, 60000);
}
```
