# 기업정보 상세 팝업 · 이알피 연동 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 기업정보 회사 상세를 화면 전환 대신 오른쪽 팝업(`#pcDetail` 재사용)으로 바꾸고, 그 팝업에 푸른이알피(`pu-erp.html`)의 컨설팅·사건 이력을 사업자번호로 매칭해 읽기 전용으로 보여주며, 새 폴더를 이알피 사업 유형에서 골라 한꺼번에 만드는 기능을 더한다.

**Architecture:** `pu-cards.html`은 이알피의 Firebase 데이터(`data/cases/v/*`, `data/consultings/v/*`, `data/biz_cons_types`)를 읽기 전용으로 소비한다. 기업정보 폴더는 이알피 원본을 참조만 하고 손대지 않는다 — 회사 열쇠(사업자번호 10자리)로 이어 붙인다. 명함 상세에서 이미 쓰는 "PC 오른쪽 상세 패널" 패턴(`#pcDetail`/`#pcDetailOverlay`/`closeDetail()`/`closePcDetail()`)을 그대로 재사용한다.

**Tech Stack:** 빌드 없는 단일 HTML(`pu-cards.html`) + Firebase Realtime Database. 검사는 `node:test` + `node:assert/strict`, 순수 함수·렌더 함수는 `node:vm`으로 `pu-cards.html`에서 코드 조각을 뽑아 실제로 실행해 증명한다(정적 규칙 검사가 아니다 — 이 세션에서 확립된 필수 관례).

## Global Constraints

- 이알피 원본(`data/cases`, `data/consultings`, `data/biz_cons_types`)을 기업정보 쪽에서 절대 쓰지 않는다 — 읽기만 한다.
- 새 `kind`나 `state.tab` 값을 만들지 않는다.
- 폴더-이알피 실시간 연동을 하지 않는다 — "가져오기"는 그 순간의 스냅샷만 담고, 이후 자동으로 안 따라간다(조용한 배경 쓰기 금지 원칙과 같다).
- 회사 매칭은 `digits(bizno)` 10자리 기준 — `coKeyOf`와 같은 규칙.
- 매칭 안 된 회사는 침묵하지 않는다 — 몇 곳을 건너뛰었는지 안내한다.
- Firebase 다중 경로 쓰기는 `Store.db.ref(DB_ROOT).update(upd)` 하나로 모은다. 여섯 개 기존 쓰기 함수(`putCoFolder` 등)가 이미 하는 것처럼 실패하면 `.catch(e=>toast('...실패: '+((e&&e.message)||'')))`로 안내한다.
- 파일은 UTF-8. 주석과 화면 글은 한국어, 이 저장소 말투(왜 이렇게 했는지)를 따른다.
- 커밋 메시지는 한국어, `feat(기업정보): …` 또는 `test(기업정보): …` 꼴. 특수문자·여러 줄이 있으면 BOM 없는 UTF-8 임시 파일로 만들어 `git commit -F <파일>`을 쓴다.
- 모든 과제 끝에 `node --test tests/*.test.js` 가 `fail 0` 이어야 한다.
- 이 계획서가 다루는 파일은 `pu-cards.html`뿐이다 — `pu-erp.html`은 손대지 않는다(읽기 전용 소비자로만 참여).

function loadPanelBlock(items){
  const pickAt = source.indexOf('function pickCo(');
  const closeAt = source.indexOf('function closePcDetail');
  const closeEnd = source.indexOf('\n', closeAt);
  const panelAt = source.indexOf('function coDetailPanelHtml');
  assert.ok(panelAt > 0, 'coDetailPanelHtml 을 찾지 못했습니다');
  const openAt = source.indexOf('function openCoDetailPanel');
  assert.ok(openAt > panelAt, 'openCoDetailPanel 을 찾지 못했습니다');
  const openEnd = source.indexOf('\nfunction ', openAt + 10);
  const pickEnd = source.indexOf('\n', pickAt);

  const calls = { panelHtml:'', panelOpen:false, overlayOn:false, detailClosed:0 };
  const ctx = {
    esc: s => String(s ?? '').replace(/[&<>"']/g, c=>({'&':'&amp;','<':'&lt;','>':'&gt;','"':'&quot;',"'":'&#39;'}[c])),
    state: { coPick:'' },
    _coFolders: {},
    coList: () => items.slice(),
    coDocsHtml: () => '',
    CO_FIELDS: [['bizno','사업자번호'],['ceo','대표자']],
    closeDetail: () => { calls.detailClosed++; },
    loadErpCaseCons: cb => cb && cb(null),
    $: id => {
      if(id==='pcDetail') return { set innerHTML(v){ calls.panelHtml=v; }, get innerHTML(){ return calls.panelHtml; },
        classList: { add(){ calls.panelOpen=true; }, remove(){ calls.panelOpen=false; } } };
      if(id==='pcDetailOverlay') return { style:{ set display(v){ calls.overlayOn = (v==='block'); } } };
      return null;
    }
  };
  const code = source.slice(panelAt, openEnd) + '\n' + source.slice(pickAt, pickEnd) + '\n' + source.slice(closeAt, closeEnd);
  vm.createContext(ctx);
  vm.runInContext(code, ctx);
  ctx._calls = calls;
  return ctx;
}

   ⚠ 사건관리는 레코드마다 typeName 이 이미 박혀 있지만, 컨설팅관리는 typeCode 만

     자리가 아니다)에서 찾아야 한다. */
let _erpCaseCons = null;
let _erpCaseConsLoading = false;
let _erpConsTypes = null;
function loadErpCaseCons(cb){
  if(_erpCaseCons || _erpCaseConsLoading){ cb && cb(_erpCaseCons); return; }
  if(Store.mode!=='firebase' || typeof firebase==='undefined' || !firebase.database){ cb && cb(null); return; }
  _erpCaseConsLoading = true;
  Promise.all([
    firebase.database().ref('data/cases/v').once('value'),
    firebase.database().ref('data/consultings/v').once('value'),
    firebase.database().ref('data/biz_cons_types').once('value'),
  ]).then(([cs, ks, ts])=>{
    const byBiz = {};
    const push = (rec, kind) => {
      const b = digits(rec.bizNo||''); if(b.length<10) return;
      (byBiz[b] = byBiz[b]||[]).push(Object.assign({}, rec, { _kind: kind }));
    };
    Object.values(cs.val()||{}).forEach(r=>push(r,'case'));
    Object.values(ks.val()||{}).forEach(r=>push(r,'consulting'));
    _erpConsTypes = Array.isArray(ts.val()) ? ts.val() : Object.values(ts.val()||{});
    _erpCaseCons = { byBiz };
    _erpCaseConsLoading = false;
    cb && cb(_erpCaseCons);
  }).catch(e=>{
    _erpCaseConsLoading = false;
    console.warn('[erpCaseCons]', e&&e.message);
    cb && cb(null);
  });
}
function erpConsTypeName(typeCode){
  const t = (_erpConsTypes||[]).find(x=>x && x.code===typeCode);
  return t ? (t.name||typeCode) : typeCode;
}

function coErpFolderCandidates(cb){
  loadErpCaseCons(data=>{
    if(!data){ cb([]); return; }
    const byType = {};
    Object.values(data.byBiz).forEach(recs=>recs.forEach(rec=>{
      const label = (rec._kind==='case' ? '사건·' : '컨설팅·') +
        (rec._kind==='case' ? (rec.typeName||'(이름 없음)') : erpConsTypeName(rec.typeCode||'(이름 없음)'));
      (byType[label] = byType[label]||[]).push(rec);
    }));
    const list = Object.keys(byType).map(label=>({
      label, kind: byType[label][0]._kind, n: byType[label].length, recs: byType[label]
    })).sort((a,b)=>b.n-a.n);
    cb(list);
  });
}
async function coImportFolderFromType(label, recs){
  const name = label.replace(/^(사건·|컨설팅·)/,'');
  const existing = Object.values(_coFolders).find(f=>f.name===name);
  const folderId = existing ? existing.id : uid();

    let by=''; try{ by=(firebase.auth().currentUser||{}).email||''; }catch(_){}
    putCoFolder({ id:folderId, name, order:Date.now(), at:Date.now(), by });
  }

  const byKey = {}; coList().forEach(o=>{ const b=digits(o.bizno||''); if(b.length>=10) byKey[b]=o; });

    if(!co){ skipped++; return; }
    matched++;
