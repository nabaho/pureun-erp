# 사진첩 계약서 → 이알피 계약추가 가져오기 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** pu-erp.html 계약추가 창에서, 로그인한 사람이 사진첩에 올려둔 OCR 계약서 중 이름이 비슷한 것을 찾아 계약금·부가세(착수금/계약금 쪽)·계약일·계약기간·업무요약을 한 번에 채워 넣는다.

**Architecture:** pu-photos.html이 이미 쓰는 공용 저장 층 `js/pu-photo-store.js`(PuPhotoStore)를 pu-erp.html에 처음으로 로드해 본인 소유 사진 메타데이터만 읽는다. 매칭·필드계산은 전부 순수 함수로 분리해 vm 기반으로 단위 테스트하고, ContractModal 안에는 그 순수 함수를 부르는 얇은 UI 배선(배지·목록 팝업·미리보기 카드)만 둔다.

**Tech Stack:** Preact(h/useState/useEffect, 빌드 없음), Firebase RTDB(compat SDK), Node `vm` 모듈 기반 커스텀 테스트 하네스(이 저장소의 pu-erp.html 테스트 관례).

## Global Constraints

- 검색 범위는 **로그인한 사람 본인**의 사진첩 데이터만 (Firebase 규칙: `puphotos/u/{uid}`는 `auth.uid===$uid` 또는 admin만 읽기 허용 — 규칙 변경 없음).
- 매칭 기준은 **회사명**(느슨한 검색)만. 사업자번호는 계약서에 흔히 없어 기준으로 안 씀.
- **계약유형(`f.kinds`)을 정확히 하나만 체크했을 때만** 가져오기 배지를 보여준다(0개·2개 이상이면 안 보임).
- 부가세는 `fields.vat` 텍스트에 "포함"이 있으면 체크, "별도"가 있으면 해제, 그 외(빈칸·애매함)는 **건드리지 않음** — 잘못 추측해 세금 계산이 틀어지는 것을 막는다.
- CMS 자동이체·개인입금 필드는 OCR에 데이터 자체가 없어 대상에서 제외(설계서 확정 사항, 재론하지 않음).
- 사진첩 쪽 실시간 구독 없음 — 계약추가 창을 열 때 한 번만 읽어 캐시.
- 새로 추가하는 순수 함수는 모두 최상위(top-level) `function` 선언으로 — vm 슬라이스 테스트가 가능해야 한다.
- 테스트에서 최상위 함수를 꺼낼 때는 `fn('함수이름')` 헬퍼를 쓴다(Task 2에서 추가). `slice(a, b)`는 끝 표식을 **포함하지 않아** `'\n}\n'` 같은 표식으로는 닫는 중괄호가 빠져 SyntaxError 가 난다 — 함수 추출에 쓰지 말 것. `slice`는 함수가 아닌 블록(예: 최상위 `var` 선언 여러 줄)을 꺼낼 때만 쓴다.
- 참고 설계서: `docs/superpowers/specs/2026-08-15-사진첩계약서-가져오기-design.md`

// 사진첩에서 온 회사명과 «지금 입력 중인 회사명»을 견주어 후보를 추린다.

var ERP_PHOTO_MATCH_MIN_SCORE = 60;   // _erpNameCmp 의 "이름 부분 일치" 이상만 인정
function erpBuildContractPhotoMatches(companyName, items){
  var qn = erpNormName(companyName);
  if(!qn || qn.length < 2) return [];
  var out = [];
  (items || []).forEach(function(it){
    if(!it || !it.fields) return;
    var cn = erpNormName(it.fields.company);
    if(!cn) return;
    var cmp = _erpNameCmp(qn, cn);
    if(cmp.score >= ERP_PHOTO_MATCH_MIN_SCORE){
      out.push({ id:it.id, year:it.year, fields:it.fields, at:it.at, score:cmp.score });
    }
  });
  out.sort(function(a, b){ return b.score - a.score; });
  return out;
}
