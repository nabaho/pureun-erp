# 구글 캘린더 API 키 — 사이트 제한 걸기

2026-08-15 작성 · **콘솔에서만 되는 작업이다.** 코드로는 못 고친다.

## 왜 해야 하나

푸른통합시스템(`pu-erp.html`) 달력 탭은 회사 구글 캘린더를 읽어 온다. 그때 쓰는 열쇠(API 키)가
코드 안에 그대로 들어 있다:

```
pu-erp.html:50844   AIzaSyA0I_VD_dvFo9CPCDrPCiewcnuG0VeTkuo
```

이 저장소는 **공개**이고 main이 GitHub Pages로 배포되므로, 이 열쇠는 이미 인터넷에 열려 있다.

**그런데 이 열쇠는 코드에서 빼면 안 된다.** 예전에 「하드코딩된 열쇠를 지우자」고 했다가
코드를 읽어 보니 이게 **유일한 열쇠**였다 — 지우면 전 직원 달력이 그날로 멈춘다.
(설정에 `gcal_api_key` 를 넣으면 그걸 먼저 쓰지만, 아무도 안 넣어 뒀다.)

그래서 **막는 방법은 하나뿐이다 — 열쇠에 「우리 사이트에서만 통한다」는 자물쇠를 다는 것.**
그러면 열쇠가 공개되어 있어도 남이 자기 사이트에 붙여 우리 할당량을 태울 수 없다.

> 참고 — 옆에 있는 `AIzaSyDkZz5Ql…` (19개 파일)은 **파이어베이스 웹 열쇠**다. 이건 원래
> 공개되도록 설계된 값이라 급하지 않다(보안은 데이터베이스 규칙과 App Check이 맡는다).
> 이번 건은 **캘린더 열쇠 하나**만 다룬다.

---

## 순서 (5분)

### 1. 열쇠 목록 열기

<https://console.cloud.google.com/apis/credentials> 로 들어간다.

화면 위쪽 프로젝트 이름이 **pureun-erp**(또는 캘린더를 붙여 둔 그 프로젝트)인지 먼저 확인한다.
다르면 이름을 눌러 바꾼다.

### 2. 캘린더 열쇠를 찾는다

「API 키」 목록에서 **`AIzaSyA0I_…VeTkuo` 로 시작·끝나는 줄**을 찾아 이름을 누른다.
목록에는 열쇠 앞부분만 보이므로 **`AIzaSyA0I_`** 로 시작하는 것을 고르면 된다.

> ⚠ `AIzaSyDkZz…` 로 시작하는 파이어베이스 열쇠를 잘못 건드리면 **로그인이 전부 막힌다.**
> 반드시 `AIzaSyA0I_` 를 확인하고 들어간다.

### 3. 「애플리케이션 제한사항」 — HTTP 리퍼러

「애플리케이션 제한사항」에서 **웹사이트**(HTTP 리퍼러)를 고른다.
그러면 아래에 주소를 넣는 칸이 생긴다. **항목 추가**를 눌러 아래 둘을 넣는다:

```
https://nabaho.github.io/*
https://*.firebaseapp.com/*
```

- 첫 줄이 실제 서비스 주소다(`https://nabaho.github.io/pureunall/…`).
- 둘째 줄은 파이어베이스 쪽 주소로 들어오는 경우를 위한 예비다. 안 써도 그만이다.

### 4. 「API 제한사항」 — 캘린더만

「API 제한사항」에서 **키 제한**을 고르고, 목록에서 **Google Calendar API** 하나만 체크한다.
이러면 이 열쇠가 새어 나가도 캘린더 말고는 아무것도 못 부른다.

### 5. 저장

아래 **저장**을 누른다. **반영까지 최대 5분** 걸린다고 구글이 안내한다.

---

## 확인

1. 5분쯤 기다린다.
2. 폰이나 PC에서 <https://nabaho.github.io/pureunall/pu-erp.html> 를 열고 **달력 탭**에 들어간다.
3. 구글 캘린더 일정이 평소대로 보이면 끝이다.

### 안 보이면

달력 탭에 빨간 오류 글이 뜬다. 십중팔구 리퍼러를 잘못 적은 것이다.

- 3번의 두 줄을 **오타 없이** 넣었는지 본다 — 특히 끝의 `/*` 를 빠뜨리기 쉽다.
- 그래도 안 되면 **애플리케이션 제한사항을 「없음」으로 되돌리고 저장**한다. 달력이 바로 살아난다.
  그 뒤에 다시 시도하면 된다. (되돌려도 위험이 늘 뿐 망가지는 것은 없다.)

---

## 하지 말 것

- **코드에서 `AIzaSyA0I_…` 를 지우는 것** — 유일한 열쇠라 전 직원 달력이 멈춘다.
- **`AIzaSyDkZz…`(파이어베이스 열쇠)에 같은 제한을 거는 것** — 잘못 걸면 로그인·저장이 전부 막힌다.
  이건 별건으로 따로 검토한다.
- **열쇠를 새로 만들어 바꾸는 것** — 지금 필요 없다. 제한만 걸면 된다. 정말 바꿔야 할 때가 오면
  코드를 고치지 말고 푸른통합시스템 **설정 → 「Google Calendar 키」 칸**에 새 열쇠를 붙여 넣고
  **저장**을 누르면 된다(코드가 그 값을 먼저 읽는다 · 모든 기기에 같이 반영 · 저장 후 F5).
  이 칸은 열쇠 관리 권한이 있는 사람에게만 보인다.
