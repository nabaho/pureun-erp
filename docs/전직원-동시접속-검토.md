# 푸른이알피, 직원 모두가 동시에 쓰게 하려면 — 검토 결과

작성 2026-08-04

## 한 줄 결론

**시스템은 이미 동시 사용을 전제로 만들어져 있다.** 새로 만들 것은 거의 없다.
남은 것은 ① 대표가 콘솔에서 해야 하는 계정 만들기 두 단계와 ② 화면 한 곳에만
있는 「동시 편집 경고」를 나머지 화면에도 붙이는 일이다.

---

## 1. 이미 되어 있는 것 (다시 만들 필요 없다)

확인한 그대로 적는다.

| 걱정 | 지금 상태 |
|---|---|
| 직원마다 따로 로그인 | **된다.** 사람마다 자기 아이디·비번. 비번 5회 틀리면 보안 확인, 8회면 잠금. 첫 로그인 때 기본 비번(123456)이면 변경을 강제한다 |
| 폰과 PC를 같이 쓰면 서로 덮어쓰지 않나 | **안 덮는다.** 예전에 한 기기만 쓰게 잠그던 장치가 있었는데, 지금은 일부러 풀고 "칸 단위 저장"으로 바꿨다 |
| 두 사람이 같은 업체를 동시에 고치면 | **서로 다른 칸을 고쳤으면 둘 다 남는다.** 바뀐 칸만 서버에 보내기 때문이다. 같은 칸을 고쳤을 때만 문제가 된다(→ 3번) |
| 남이 방금 넣은 자료가 내 저장에 지워지지 않나 | **막혀 있다.** 저장할 때 서버 현재값에 내 변경분만 얹는다. 통째로 덮어쓰기는 옛 형식에만 남아 있다 |
| 실수로 대량 삭제 | **여러 겹 막혀 있다.** 0건으로 줄면 차단, 10건 이상이 절반 이하로 줄면 차단, 내 기기 자료가 서버보다 훨씬 적으면 "옛 데이터"로 보고 차단 |
| 남이 바꾼 걸 내 화면이 모르지 않나 | **알려 준다.** 화면 위에 「새 변경 있음」 띠가 뜬다. 자동으로 새로 그리지는 않는다 — 입력 중인 내용이 날아가면 안 되니 일부러 그렇게 했다 |
| 누가 지금 접속했는지 | **보인다.** 접속하면 다른 사람 화면에 토스트로 알리고, 접속자 목록이 있다. 창을 닫으면 서버가 자동으로 지운다 |
| 급여·재무·직원 개인정보를 다 볼 수 있지 않나 | **권한 있는 사람만.** 보안 규칙이 이미 그렇게 되어 있다. 일반 직원용 슬림 명부가 따로 있어서, 로그인·이름 표시는 되고 비번·주민번호는 안 보인다 |
| 비번이 서버에 그대로 있지 않나 | **아니다.** 소금(salt)을 섞은 해시로만 저장된다. 되돌려 읽을 수 없다 |

## 2. 대표가 해야 하는 것 (순서대로)

이 두 단계를 안 하면 직원이 로그인할 수 없다. 앱 안에 계정을 만드는 기능이
**일부러** 없다 — 아무나 계정을 만들면 안 되기 때문이다.

### ① Firebase 콘솔 → Authentication → 사용자 추가

직원마다 하나씩 만든다.

- 이메일: `사번@pureun.kr` 꼴 (예: `p001@pureun.kr`)
- 비번: `123456` (첫 로그인 때 본인이 바꾸게 되어 있다)

사번은 직원계정 화면에 있는 것과 **똑같이** 써야 한다. 다르면 로그인은 되지만
그 사람이 누군지 앱이 못 찾는다.

### ② 직원마다 한 번씩 로그인하게 한다

첫 로그인 때 그 사람의 권한표가 서버에 자동으로 만들어진다. 이걸 하기 전에는
보안 규칙이 그 사람을 몰라서, 급여·재무 같은 곳을 막는다.

즉 **"계정 만들기 → 본인이 한 번 로그인 → 그 다음부터 정상"** 이다.

### ③ 사진첩 규칙 붙여넣기 (사진첩을 쓰려면)

사진첩은 사람마다 자기 사진만 보게 만들어 두었다. 규칙을 붙여넣기 전까지는
그 칸이 열려 있다. `docs/사진첩-규칙-붙여넣기.md` 그대로 하면 된다.

## 3. 진짜 구멍 하나 — 같은 칸을 동시에 고칠 때

**증상**: 두 사람이 같은 업체의 **같은 칸**을 고치면, 나중에 저장한 사람이
이긴다. 앞사람이 쓴 내용은 **아무 말 없이** 사라진다.

**경고를 띄우는 화면이 계약관리 딱 한 곳뿐이다.** 거기에는 "○○님이 방금
수정했습니다. 그래도 저장하면 그 변경이 사라집니다"가 나온다. 업체관리·사건관리·
컨설팅·급여에는 그 경고가 없다.

**고치는 법**: 계약관리에 있는 그 경고를 공용으로 빼서 다른 저장 화면에도 붙인다.
자료 구조를 바꾸는 일이 아니라 저장 직전에 한 번 확인하는 것이라, 위험 없이
할 수 있다. 반나절 일이다.

→ **동시 접속을 열기 전에 이것부터 하는 편이 낫다.** 사람이 늘면 부딪힐 확률도
같이 늘고, 조용히 사라지는 자료는 나중에 찾을 수도 없다.

## 4. 함께 검토한 것 — 급한 순서

1. **동시 편집 경고 공용화** (3번) — 동시 접속을 열기 전에
2. **사진첩 규칙 적용 + 「사진 옮기기」** — 지금은 서로의 사진이 보일 수 있다
3. **업체 연결·바깥 앱 연결 고정 실행** — 서류 자동 등록이 엉뚱한 업체에 붙지
   않으려면 먼저 해야 한다
4. **쌓인 중복 명함·서류 한 번 훑기** — 오늘 만든 중복 판단을 과거 자료에도
   한 번 돌리는 도구
5. **중소기업확인서 유효기간 만료 알림** — 만료된 확인서로 신청하면 반려된다
6. **2단계 인증** — 대표가 "추후 안내" 하기로 미뤄 둔 것
