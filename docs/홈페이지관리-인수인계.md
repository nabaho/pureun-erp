## ② 캡쳐 3·4 — 「홈페이지」가 한 화면에 일곱 번

단추 이름이 겹친 게 아니다. **낱말은 하나인데 가리키는 홈페이지가 둘**이다.

- **지금 홈페이지** = `xn--o80bs5mdnbm0bf80anms.kr` (라이믹스·카페24). 손님이 보는 곳.
  우리가 **못 고친다.** 읽고, 대조하고, 붙여넣을 글자를 만들어 주는 것까지가 끝.
- **새 홈페이지** = 우리가 만든 거울(GitHub Pages). **자동으로 올라간다.**
  아직 손님은 안 본다 — 도메인이 안 옮겨졌다.

이 둘이 이름으로 안 갈라져 있어서 이렇게 보인다.

| 지금 단추 | 어느 홈페이지 | 실제로 하는 일 |
|---|---|---|
| 홈페이지 다시 확인 | 지금 | 읽어서 대조 딱지를 붙인다 |
| 홈페이지 열기 | 지금 | 손님 화면을 새 창에 |
| 홈페이지에 채우기용 복사 | 지금 | 클립보드에 담는다 (**사람이 붙여넣어야 실린다**) |
| 홈페이지에서 이 사람 글 열기 | 지금 | 라이믹스 편집화면 |
| 홈페이지에서 비공개로 | 지금 | 안 보이게만 (안 지운다) |
| 홈페이지에 올리기 | **새** | 자동으로 실린다 |
| 홈페이지에? 올림 / 안 올림 | **새** | 이 사람을 넣나 빼나 |

### 가장 헷갈리는 한 쌍 — 이름은 반대인데 딴 곳 이야기다

- **「안 올림」** → **새** 홈페이지에서 이 사람을 뺀다. 우리 목록엔 남는다.
- **「홈페이지에 남기기」** → **지금** 홈페이지 이야기. 퇴사자인데 그대로 둘 사람
  (지사장처럼 고용관계가 아닌 분). **경고만 끈다.**

읽으면 둘 다 「올리냐 마냐」로 보인다. 실은 하나는 새 쪽, 하나는 옛 쪽 경고 끄기다.

### 또 하나 — 파란 단추가 둘

「홈페이지 다시 확인」(위)과 「홈페이지에 채우기용 복사」(아래)가 다 파랗다.
한 화면에 으뜸 단추는 하나여야 한다.

### 이미 한쪽은 갈라 적고 있다

쪽 편집칸은 **「새 홈페이지에 올리기」**라고 적는데(`pu-home.html:4564`),
구성원 머리띠는 **「홈페이지에 올리기」**라고만 적는다(`:2744`).
한 화면에서 같은 일을 두 이름으로 부르고 있다.

## ③ 이렇게 고치자 (목업 먼저 → 승인 → 코딩)

### ㉮ 낱말을 갈라 적는다 — 고치는 곳 8군데, 동작은 안 바뀐다

| 지금 | 바꿀 이름 |
|---|---|
| 홈페이지 다시 확인 | **지금 홈페이지와 대조** |
| 홈페이지 열기 | **지금 홈페이지 보기** |
| 홈페이지에 채우기용 복사 | **지금 홈페이지용 복사** |
| 홈페이지에서 이 사람 글 열기 | **지금 홈페이지에서 이 사람 글** |
| 홈페이지에 올리기 | **새 홈페이지에 올리기** (쪽 편집칸과 같게) |
| 홈페이지에? 올림 / 안 올림 | **새 홈페이지에: 넣기 / 빼기** |
| 홈페이지에 남기기 | **퇴사 경고 끄기 (사유 남김)** |

> 도메인을 옮기면 「새」가 「지금」이 된다. 그때 **「지금」이 붙은 단추 다섯 개를
> 통째로 지우고** 「새」를 떼면 끝난다 — 한 자리에서 끝나게 이름을 지어 둔 것이다.

### ㉯ 머리띠를 두 몫으로 가른다

```
줄 모양 [줄바꿈만 ▾]  👁 미리보기 │ 지금 홈페이지와 대조  지금 홈페이지 보기 │ ★새 홈페이지에 올리기
                                   └─ 읽기만 ─┘              └─ 실제로 올라감 ─┘
```

「읽는 것」과 「올리는 것」 사이에 선을 하나 넣는다. 실수로 올리는 일이 없어진다.

### ㉰ 바닥 단추 일곱을 넷으로

자주 쓰는 넷만 두고, 나머지는 「⋯ 더보기」로 접는다.

```
★저장   지금 홈페이지용 복사   경력관리에서 당겨오기   ⋯ 더보기
                                                      └ 되돌리기 · 퇴사 경고 끄기
                                                        지금 홈페이지에서 이 사람 글
```

으뜸(파란) 단추는 **「저장」 하나**. 지금은 저장이 회색이고 복사가 파랗다 —
고친 걸 저장 안 하고 복사부터 누르게 되어 있다.

## ④ 막혀 있는 것 — 지시가 필요하다

**홈페이지에 노무사/직원을 갈라 보이기**가 안 된다. 두 가지가 막는다.

1. 지금 홈페이지 「구성원 소개」는 **칸 아홉 개가 한 덩이**다. 「직원」이라는
   낱말이 그 쪽에 **한 번도 없다.** 구획을 새로 만들어야 갈라 보인다.
2. 새로 넣는 사람은 **얼굴 사진이 없으면 못 올라간다**(`js/pu-site-people.js`).
   직원 사진을 받을지가 대표 판단이다.

그래서 지금은 **우리 목록에서만 갈라 보이고, 홈페이지엔 안 올린다** — 대표 결정
(2026-09-03 「넣되 홈페이지엔 안 올림」).

주간 뉴스레터는 월요일 07:30에 저절로 올라간다. **첫 발행 2026-09-07 확인만.**

### 사람이 바뀔 때 (입사·퇴사·직책 변경)

퇴사자는 **지우지 않는다.** 「비공개로」만 한다 — 대표 지시.

**지금 홈페이지와 대조**를 누른다. 어긋난 것이 「할 일」에 모인다.

## ⑧ 이 대화에서 더 한 것 (2026-09-03 저녁)

**㉮ 편집칸 위 전부를 붙였다** — 경력 목록 위(구분·이름줄·메인 설명·담당 업무·
경력사항 이름줄)가 굴려도 그대로 있다. 열여덟 줄을 고치다 누구 자료인지 잃지 않는다.

- 붙는 것은 코드의 **`붙은칸`** 그릇에 담긴 것뿐이다. 담기지 않은 것은 구른다.
- 높이 한도 56vh — 담당 업무가 열 줄이면 붙은 칸이 화면을 다 먹는다.
- ⚠ **붙은 칸에 `margin` 을 주지 말 것.** 그만큼 틈이 생겨 그 띠로 경력 줄이 비쳐
  지나간다(이번에 2px, 앞선 세션은 13px 로 겪었다). 숨은 `padding-top` 으로 안에서.

**㉯ 거래 끝난 업체는 자문사 명단에서 자동으로 빠진다** — 「올림」으로 표시돼 있어도
빠진다. 사람이 표시를 안 고쳐도 나간다.

- 빼되 **숨기지 않는다**: 「거래 종료 N」 딱지로 다 볼 수 있고, 목록 머리도
  「거래 종료 N곳은 뺐음」이라 말한다.
- **할 일에는 남는다** — 종료됐는데 올림이던 곳은 **지금 홈페이지에 로고가 그대로**
  걸려 있다. 우리가 못 고치는 곳이라 그것만 사람 손에 남는다.
