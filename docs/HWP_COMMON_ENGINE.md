# 푸른 한글문서 공통 엔진

`js/pu-hwp-engine.js`는 푸른통합시스템의 HWP/HWPX 공통 진입점이다.

## 현재 적용 범위

- 실제 파일 서명과 확장자 검사
- 100MB 용량 제한
- 자체 호스팅된 `vendor/rhwp-core`로 문서 검사와 미리보기
- 고급 편집기 연결을 한 곳에서 관리
- 편집기 장애 시 원본 파일을 안전하게 내려받을 수 있는 폴백

첫 적용 대상은 `fund.html`이다. 다른 시스템은 자체 HWP 코드를 새로 만들지 않고 이 엔진을 호출한다.

## 보안 원칙

- 문서와 개인정보는 편집기 모듈로 전달되기 전에 로컬에서 검사한다.
- 원본 HWP/HWPX와 사진은 Realtime Database에 Base64로 저장하지 않는다.
- 운영 문서는 NAS 또는 Firebase Storage에 보관하고 RTDB에는 경로·권한·수정 이력만 저장한다.
- 외부 편집기 주소는 공통 설정에서 교체할 수 있으며, 향후 자체 호스팅 편집기로 전환한다.
