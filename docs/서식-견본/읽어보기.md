# 서식 견본 — 「📎 원본 서식 채우기」 시험용

## 표준근로계약서_푸른견본.hwpx
고용노동부 **외국인근로자 표준근로계약서**(외국인근로자의 고용 등에 관한 법률 시행규칙
[별지 제6호서식], 개정 2020. 1. 10.) 원본에, 푸른 토큰 다섯을 심어 둔 것이다.

| 자리 | 토큰 |
|---|---|
| 업체명 | `{{회사명}}` |
| 전화번호 | `{{대표전화}}` |
| 소재지 | `{{주소}}` |
| 성명(사용자) | `{{대표자}}` |
| 사업자등록번호 | `{{사업자번호}}` |

**쓰는 법**: ERP → 계약 → 서식 창 → **📎 원본 서식 채우기** → 이 파일을 고른다.
계약에 붙은 업체 정보로 다섯 자리가 채워져 내려온다.

## 이 견본은 어떻게 만들었나 (다른 서식도 같은 방법)
```bash
# ① 한글(.hwp) → .hwpx  (한글 프로그램 없이 된다)
python3 .claude/skills/hwpx/scripts/convert_hwp.py 원본.hwp -o 원본.hwpx

# ② 어떤 칸이 있는지 본다
python3 .claude/skills/hwpx/scripts/text_extract.py --include-tables 원본.hwpx

# ③ 채울 자리에 토큰을 심는다 (run 경계를 넘어도 잡는다)
python3 .claude/skills/hwpx/scripts/fill_hwpx.py replace --map 토큰표.json 원본.hwpx 견본.hwpx

# ④ 한글이 여는 모양인지 확인
python3 .claude/skills/hwpx/scripts/validate.py 견본.hwpx
```
쓸 수 있는 토큰 이름은 `pu-erp.html` 의 `fillContractVars` 에 다 있다
(`{{회사명}}` `{{사업자번호}}` `{{대표자}}` `{{주소}}` `{{계약일}}` `{{국민연금관리번호}}` …).

⚠ 이 폴더는 **배포본에 올라가지 않는다**(`docs/` 는 워크플로가 지운다).
