# 푸른통합 온톨로지 — 4단계 업체 360° 조회

작성: 2026-09-02

## 목적

업체 하나를 중심으로 계약·사건·사업·업무·일정·입출금·세금계산서·문서·사진·
임금기록을 공통 관계어로 모아 본다. 기존 메뉴를 돌아다니며 같은 업체를 이름으로
다시 검색하는 일을 줄인다.

## 동작

1. 통합 진단을 실행해 현재 권한으로 읽을 수 있는 관계망을 만든다.
2. 업체명 또는 업체 ID로 업체를 검색한다.
3. 업체를 선택하면 직접 연결된 개체를 종류별로 묶어 보여 준다.
4. 명시적 ID 관계는 `확정`, 이름으로 유일하게 찾은 관계는 `후보`로 표시한다.

## 안전 원칙

- 검색과 묶기는 브라우저 메모리에서만 수행한다.
- 조회 화면에서 원본을 수정하거나 삭제하지 않는다.
- 권한 때문에 읽지 못한 프로그램의 관계는 없는 것으로 단정하지 않는다.
- 동명이인·동일 업체명 때문에 여러 후보가 생기면 자동 연결하지 않는다.
- 원본을 고칠 때는 해당 프로그램으로 이동해 그 프로그램의 권한과 동시편집 잠금을 따른다.

## 다음 단계

5단계에서는 관계를 이용한 검증센터를 만든다. `업체 ID 없는 업무`, `존재하지 않는
담당 사번`, `원본이 사라진 재무 연결`, `이름 후보만 남은 관계`를 담당자가 하나씩
확정할 수 있게 하되, 대량 자동수정은 허용하지 않는다.
