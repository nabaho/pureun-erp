제 생각㉠ + ㉡
㉠이 「주담당 1인 이름만 보이게」를, ㉡이 「추가·변경할 때 확인만」을 그대로 합니다.
  1. 평소엔 주담당 한 줄 — 이름·직급·연락처·맡는 일
  2. 「▾ 다른 담당자 n명 더 보기」로 펴서 본다
  3. 펴면 「주담당으로」를 눌러 주담당을 바꾼다
  4. 기업정보함에서 담을 때 이미 있으면 묻는다 — 더하기 / 바꾸기 / 그만두기
  5. 「바꾸기」는 누가 지워지는지 이름을 먼저 보여 준다
⚠ 미리 말씀드릴 것
ㆍ담당자를 «지우지» 않습니다 — 접을 뿐입니다. 계약서·연락처에는 그대로 쓰입니다. 지우기를 원하시면 그건 따로 말씀해 주세요(되돌릴 수 없습니다).
ㆍ「고치기」를 눌러야 칸이 열립니다. 지금처럼 늘 열려 있길 원하시면 말씀해 주세요 — 한 사람만 늘 펴 두고 나머지를 접는 것도 됩니다.
