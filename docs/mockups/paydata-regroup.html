지금 실제로 공용 칸에 52건이 있고, 그중 51건이 「업체관리에 없는 주소」입니다.
왜 52건이 그대로 있나
배달은 메일을 받을 때 한 번만 합니다. 그래서 업체관리에 주소를 나중에 넣어도, 이미 공용 칸에 떨어진 것은 영원히 그대로입니다.

1
업체관리 → 「📥 급여담당자 엑셀」 → 넣기 어제 만든 화면입니다. 72곳에 담당자·세무 주소가 들어갑니다. 이게 빠진 연결고리입니다.
2
급여데이터함 → 메일로 온 것 → 「🔁 다시 갈라 보내기」 공용 칸 52건을 지금 규칙으로 다시 갈라 각 담당자 칸으로 보냅니다. 새로 만드는 단추입니다.
