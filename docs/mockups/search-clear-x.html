검색창 지우기 X — 어떻게 하는 게 나은가

푸른이알피 검색창 33개를 전부 세어 보고, 두 가지 방법을 견줬습니다.

지금 상태

33개 중 22개는 X 가 아예 없고, 있는 11개도 모양이 넷으로 갈려 있습니다.

지우기 X 없음 22개 있음 11개
있는 11개도 제각각입니다 — × 5곳(단추) · × 2곳(글자) · ✕ 2곳(오른쪽 6px) · ✕ 2곳(오른쪽 5px)

캡쳐에 보내주신 맨 위 통합검색(Ctrl+K)과 컨설팅관리 검색도 X 가 없는 쪽입니다.

지금 X 가 없다

지우려면 글자를 다 지워야 합니다. 긴 검색어일수록 번거롭습니다.

A안 — 추천 브라우저가 주는 X 를 우리 모양으로 꾸민다

입력칸 종류를 text → search 로 바꾸고, CSS 로 X 모양만 맞춥니다.

손질이 아주 적습니다 — 검색창마다 한 단어씩, CSS 6줄. 자리를 새로 잡을 필요가 없습니다.
빈 칸이면 저절로 사라집니다 — 아래 칸에는 X 가 없어야 정상입니다.

⚠ 지금 이 화면에서 직접 눌러봐 주세요. 위 칸의 회색 ⓧ 가 보이고 눌러서 지워지면 대표님 브라우저에서 A안이 그대로 됩니다. 안 보이면 B안으로 갑니다. (크롬·엣지·웨일·사파리는 됩니다. 파이어폭스는 안 됩니다.)

B안 우리가 직접 X 를 그려 넣는다

어느 브라우저에서나 똑같이 나옵니다. 대신 손질이 훨씬 많습니다.

손질이 많습니다 — 24곳 중 22곳은 X 를 얹을 자리(감싸는 상자)가 없어 새로 만들어야 합니다. 게다가 4곳은 값을 지우는 방법이 한 줄로 안 보여 하나씩 뜯어봐야 합니다. 자리를 새로 잡는 곳마다 줄이 밀리거나 겹칠 여지가 생깁니다.
