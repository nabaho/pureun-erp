앱의 진짜 CSS를 그대로 떠 온다. 빨간 세로줄은 이름이 시작하는 자리, 파란 세로줄은 숫자가 끝나는 자리 — 두 줄이 위아래로 이어져야 「안 움직인다」.

👤 담당자📁 업무별 25
무엇을 맞추나 — 넷
① 이름이 시작하는 자리 — 업무별에는 끌기 손잡이(⋮⋮)가 이름 앞에 자리를 차지하는데 담당자에는 없어, 칩을 바꿀 때마다 이름이 18px 씩 좌우로 뛴다. → 담당자 줄에도 같은 폭의 빈 자리를 둔다(손잡이는 업무별에만 나타난다).
② 숫자가 끝나는 자리 — 업무별 오른쪽 끝에는 ⋮ 메뉴 자리가 있고 담당자에는 없어, 숫자가 서로 다른 x 에 선다. → 담당자 줄에도 같은 폭의 빈 자리를 둔다.
③ 아이콘 — ●(6px 점)과 👤(14px 이모지)는 크기·색·세로 위치가 다르고, 이모지는 PC 마다 다르게 그려진다. → 둘 다 같은 크기의 그림(SVG)으로. 뜻은 그대로 가른다(사람 / 칸).
④ 숫자 칸 수 — 담당자는 둘(전체·안읽음), 업무별은 하나(안읽음)다. 칸 수가 다르면 어차피 줄이 안 맞는다. → 안 읽은 수 하나로 맞춘다(전체는 줄에 손을 얹으면 귀띔으로). 이것이 「400 숫자 불필요」와 같은 결이다.
