자료는 이렇게 — 기존 칸을 안 건드린다

phone·email 은 늘 메인이다. 급여·메일·사진첩·경력관리가 지금 읽는 그대로 «메인 값»을 얻는다. 곁칸은 새로 붙는 칸이라 몰라도 안 깨진다. 

// 값이 하나인 사람 — 지금과 «한 글자도» 다르지 않다
{ name:'박지윤', phone:'010-2043-1469', email:'jypark@naraeind.com' }

// 둘 이상일 때만 곁칸이 생긴다
{ name:'박지윤',
  phone:'010-2043-1469',          // ← 늘 메인
  phoneMore:[{ v:'010-9911-2043', label:'개인' }],
  email:'jypark@naraeind.com',    // ← 늘 메인
  emailMore:[{ v:'jy.park@gmail.com', label:'개인' }],
  pcId:'imqqktn0ke74k9',           // ← 명함도 같은 꼴
  pcMore:[{ pcId:'kf03j2n…', at:'2026-09-08', from:'기업정보함' }] }
★ 를 누르면 자리가 맞바뀐다 — phone 과 phoneMore[i].v 를 서로 바꾼다. 저장되는 것은 «어느 것이 메인인가»라는 표시가 아니라 자리 그 자체다.
그래서 체크가 둘이거나 하나도 없는 상태가 생길 수 없다 — 어긋날 것을 아예 안 만든다.

딸려 오는 것

어디무엇이 달라지나
명함첩에서 당겨오기 같은 사람의 명함이 두 장이면 둘째부터 곁칸에 쌓인다. 지금은 뒤엣것이 앞엣것을 덮는다
사업자등록증·명함 판독 번호가 이미 있으면 «덮지 않고» 곁칸에 붙인다 — 사람이 ★ 로 고른다
두 줄로 넣은 3건 한 사람으로 합칠 수 있다 (합치기는 사람이 누를 때만 — 자동으로 안 합친다)
급여·메일·사진첩·경력관리 고칠 것 없음 — phone·email 이 그대로다
⚠ 안 하는 것: 곁칸 값으로 메일 분류·급여담당자 대조를 «자동으로» 넓히지 않는다. 메인 하나로 맞추던 것이 갑자기 여러 개로 맞으면, 한 통이 두 곳에 걸린다. 넓힐지는 따로 정한다.
