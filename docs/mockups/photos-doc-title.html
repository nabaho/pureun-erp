⑤ 무엇을 고치나 (요약)

  • AI에게 주는 지시에 제목 뽑기를 모든 서류로 넓힙니다 — 「사업자등록증」과 「사업자등록증명」은 다른 서류이니 줄여 쓰지 말라고 못박습니다.
  • 이미 읽어 둔 사진은 판독 번호를 올려 다시 읽습니다(한 번에 20장씩, 지금과 같은 방식).
  • 격자 칸에 제목 띠를 더합니다.
  • 도구줄에 최신순 / 제목순 고르개를 더합니다.
  • 내려받는 파일 이름에도 제목이 들어갑니다 — 사진첩_20260810_사업자등록증명_가야엔지니어링.jpg
