지금은 판독 패널에서 저장하기 전에만 고치고 지울 수 있습니다. 한 번 「저장」을 누르면 값 표에서는 손댈 수 없습니다 — 칸을 눌러도 원본 사진만 열립니다.
1↔7·4↔9 같은 필체 오독이 한 칸 섞이면 그 숫자가 그대로 더존까지 갑니다. 아래 세 안은 모두 실제 화면 CSS로 그렸습니다.

제 권고 — A + C

한 칸 오독은 안 A로, 서류 한 장이 통째로 잘못 읽힌 것은 안 C로 처리합니다. 실제로 벌어지는 일이 이 두 가지입니다.

안 B는 권하지 않습니다. 원본을 안 보고 고치게 되는데, 이 함에서 고칠 값은 대부분 1↔7·4↔9 같은 필체 오독입니다 — 원본 없이는 무엇이 맞는지 알 수 없습니다. 표를 눈으로 훑어 「이상해 보이는 것」을 찾는 일은 이미 노란 칸이 해 주고 있습니다.

지우는 것은 값만입니다. 원본 사진·파일은 어느 안에서도 지워지지 않습니다 — 보유기간(3년)도 그대로입니다.
