통합시스템이 홈페이지를 읽어와 대조하므로, 아직 안 올라간 항목이 빨갛게 표시됩니다.

화면 2 — 「붙여넣을 내용 복사」를 누르면

권형하 — 붙여넣을 내용
복사됨 ✓
내용이 복사되었습니다. 아래 순서대로 홈페이지에 붙여넣으세요.
붙여넣는 자리
  1. 홈페이지 관리자로 로그인 푸른노무법인.kr/admin
  2. 구성원 갤러리에서 권형하 글을 찾아 편집
  3. 본문을 Ctrl+A로 전체 선택하고 Ctrl+V로 덮어쓰기
  4. 저장 → 통합시스템으로 돌아와 홈페이지 다시 확인
4번까지 하면 표시가 「안 올라감」에서 「같음」으로 바뀝니다. 안 바뀌면 붙여넣기가 안 된 것입니다.
주의 — 구성원과 자문사는 사람/회사 단위로 하나씩 붙여야 합니다. 홈페이지가 이 둘을 게시판 글 모음으로 만들어 두어서, 페이지를 통째로 바꾸는 자리가 없습니다.
반대로 주요업무와 오시는길은 페이지를 통째로 한 번에 붙이면 끝납니다.

화면 4 — 노무사가 퇴사하면

푸른ERP에 퇴사 처리가 들어가면 홈페이지 관리가 알아서 잡아냅니다. 다만 홈페이지에서 실제로 내리는 건 사장님이 확인 후 하십니다.
퇴사한 노무사 — 홈페이지 정리
내릴 것 (퇴사)
푸른ERP에서 2026-07-31 퇴사 처리되었습니다. 홈페이지 구성원 소개에는 아직 올라가 있습니다.
홈페이지에서 내리는 법
  1. 홈페이지 관리자 로그인 푸른노무법인.kr/admin
  2. 구성원 갤러리에서 해당 글을 찾습니다
  3. 삭제하지 말고 「비공개」로 바꾸십시오. 잘못 내렸어도 되살릴 수 있습니다
  4. 통합시스템으로 돌아와 홈페이지 다시 확인
이름이 다른 쪽에도 남아 있습니다 — 2곳
· 인사말 /greeting — 본문에 이름 1회
· 산재보상 /work4 — 담당자 안내에 이름 1회
동명이인일 수 있으니 알려만 드립니다. 자동으로 고치지 않습니다.
퇴사해도 홈페이지를 자동으로 바꾸지는 않습니다. 푸른ERP에 퇴사일을 잘못 눌렀을 때 기계가 곧바로 홈페이지에서 사람을 지워버리면, 고객이 보는 화면에서 노무사가 사라집니다. 확인 한 번은 사람이 합니다.

이번 판에 넣지 않는 것

사진·로고는 통합시스템에서 관리하지 않습니다. 얼굴사진과 자문사 로고를 바꿀 일이 생기면 홈페이지 관리자 화면에서 직접 올리십시오. 글만 통합시스템이 맡습니다.
자문사현황은 이번 판에서 뺍니다. 홈페이지의 자문사 화면에는 회사 이름이 글자로 없고 로고 그림 14장뿐이라, 관리할 글도 없고 자동 대조도 불가능합니다. 로고까지 관리할 수 있게 되는 다음 판에서 함께 넣습니다.
자동 전송은 하지 않습니다. 통합시스템이 홈페이지에 직접 글을 쓰려면 관리자 비밀번호를 서버에 보관해야 하는데, 그건 위험이 이득보다 큽니다. 마지막 붙여넣기 한 번은 사람이 합니다.
