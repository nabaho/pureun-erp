명함 찍으면 리멤버로 — 「올리기」 단추 없이

대표 지시 2026-08-27: "내폰에서 사진찍고 자동으로 리멤버로 보내기 만들어 달라. 리멤버에 다시 올리는 버튼 누르고 싶지 않다."

⚠ 먼저 솔직히 말씀드릴 것 — 웹 화면(사진첩)은 제 마음대로 다른 앱에 파일을 밀어넣을 수 없습니다. 브라우저가 막아 둔 것입니다(안 그러면 아무 웹페이지나 내 앱에 파일을 집어넣게 됩니다). 그래서 탭 0번은 웹으로는 불가능합니다.
대신 없앨 수 있는 것 — 「리멤버에 올리기」 같은 따로 누르는 단추입니다. 완료를 누르면 리멤버가 저절로 뜹니다. 아래 ①이 그것이고, ②는 진짜 0번이 되는 길인데 리멤버 쪽 설정 하나만 확인하면 됩니다.

② 완료를 누르면 저절로 뜬다. 리멤버 한 번 누르면 끝.
폰이 «자주 쓴 앱»을 맨 앞에 두므로 리멤버가 늘 첫 자리다.

  1. 명함 모드에서 찍는다(지금과 똑같다)
  2. 완료를 누른다 → 사진첩에 저장
  3. 저장되자마자 리멤버가 저절로 뜬다 → 한 번 누름
  4. 리멤버가 명함을 읽는다(리멤버 일이다)

지금과 견주면 — 지금은 ⑴사진첩에서 찍고 ⑵리멤버 앱을 따로 열고 ⑶「명함 등록」을 누르고 ⑷갤러리에서 그 사진을 찾아서 고릅니다. 그 넷이 한 번이 됩니다.

② 진짜 「0번」이 되는 길 — 대표께서 확인해 주실 것 하나

확인 필요

리멤버에 «메일로 명함 보내기» 주소가 있는가

명함 서비스 가운데는 정해진 메일 주소로 명함 사진을 보내면 저절로 등록되는 곳이 있습니다. 리멤버에 그것이 있다면 탭이 아예 0번이 됩니다 — 완료만 누르면 우리 서버가 조용히 보냅니다.

봐 주실 곳 — 리멤버 앱 → 설정(또는 명함 등록) 안에 「메일로 등록」·「이메일 등록」 같은 것이 있는지, 있으면 그 주소.

이미 있음

메일로 보내는 길은 이미 깔려 있다

자료 메일 자동발송 서버가 이미 돌고 있습니다(2026-08-09 배포). 주소만 알면 새로 만들 것이 거의 없습니다 — 명함이 저장될 때 그 주소로 한 통 보내면 끝입니다.

보낸 것은 기록으로 남겨 「갔는지 안 갔는지」를 사진 옆에서 볼 수 있게 합니다.

안 되는 것

웹에서 리멤버를 «몰래» 열기

웹 화면이 특정 앱을 골라 파일을 밀어넣는 길은 없습니다. 안드로이드·아이폰 둘 다 막혀 있고, 뚫는 방법도 없습니다. 전용 앱을 새로 만들면 되지만, 그건 앱 하나를 새로 만들고 폰마다 설치하는 일입니다.
