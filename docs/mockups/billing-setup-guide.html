파이어베이스 사용액 — 켜는 순서

대표님이 하실 일은 두 가지입니다. 나머지는 제가 합니다. 전부 합쳐 5분이면 끝납니다.

지금 상태 — 코드는 다 올라가 있습니다. 아래를 켜야 숫자가 흐르기 시작합니다. 켜기 전에는 화면에 아무것도 안 보입니다(일부러 그렇게 뒀습니다).
1

Cloud Shell 열기

아래를 누르면 바로 열립니다.

› Cloud Shell 열기 (누르세요)

지난번 사진 창고 열어 주셨던 그 자리입니다. 화면 오른쪽 위 >_ 아이콘을 눌러도 같습니다.

Google CloudPUREUN-ERP>_
fair0@cloudshell:~ (pureun-erp)$ ▊
확인 한 가지. 검은 창 앞부분에 (pureun-erp) 라고 적혀 있어야 합니다. 다른 이름이면 아래 3번 붙여넣기가 알아서 바로잡으니 그냥 진행하셔도 됩니다.
2

검은 창에 이걸 통째로 붙여넣기

한 번만 붙여넣으면 됩니다. 번호를 손으로 적으실 필요 없습니다 — 알아서 찾습니다.

gcloud config set project pureun-erp
gcloud pubsub topics create billing-alerts 2>/dev/null || echo "통로는 이미 있습니다"
ACC=$(gcloud billing accounts list --format="value(name)" | head -1 | sed 's|billingAccounts/||')
echo "결제 계정: $ACC"
gcloud billing budgets create \
  --billing-account=$ACC \
  --display-name=pu-total \
  --budget-amount=1000000KRW \
  --filter-projects=projects/pureun-erp \
  --all-updates-rule-pubsub-topic=projects/pureun-erp/topics/billing-alerts

붙여넣고 Enter. 중간에 Authorize 창이 뜨면 눌러 주세요.

이렇게 나오면 된 겁니다
Created topic [...billing-alerts].
결제 계정: 01ABCD-...
Created budget [...].
100만원이 눈금은 아닙니다. 「넘으면 알려 달라」는 방아쇠일 뿐이고 화면에는 안 나옵니다. 넘어도 서비스가 끊기지 않습니다. 실제 눈금은 한 달 지켜보고 대표님이 정하시면 그때 넣습니다.
3

파이어베이스 규칙에 한 칸 넣기

› 규칙 화면 열기 (누르세요)

파이어베이스 콘솔 → Realtime Database → 위쪽 규칙 탭 입니다.

지금 대표님 규칙은 이렇게 시작합니다.

{
  "rules": {
    "uid_roles": {

여기서 "uid_roles" 줄 바로 위에 네 줄을 끼워 넣어 아래 모양으로 만들면 됩니다. (초록색 네 줄이 새로 넣는 것입니다.)

{
  "rules": {
    "billing": {
      ".read": "auth != null && root.child('uid_roles').child(auth.uid).child('isAdmin').val() == true",
      ".write": false
    },
    "uid_roles": {

그리고 오른쪽 위 게시 를 누르세요.

딱 두 군데만 조심하시면 됩니다.
  • 맨 끝 닫는 중괄호 뒤에 쉼표( }, ) — 없으면 게시가 안 됩니다.
  • 나머지는 하나도 건드리지 마세요. 넣기만 하면 됩니다.
왜 이게 필요한가. 실시간DB 는 기본이 「아무도 못 봄」입니다. 이 칸을 안 넣으면 금액이 쌓여도 화면이 못 읽습니다(오류는 안 나고 그냥 안 보입니다).
읽기는 관리자만 — 회사 지출액이라 전 직원에게 열지 않습니다. 쓰기는 아무도 못 합니다 — 금액은 서버만 적습니다.
4

서버 올리기 — 제가 합니다

대표님은 안 하셔도 됩니다. 1·3번 끝났다고 알려만 주시면 제가 올리겠습니다.

(제 쪽에 파이어베이스 열쇠가 이미 붙어 있어서 바로 됩니다.)

대표님과 관리자에게만 보입니다. 다른 직원 화면에는 이 줄이 아예 없습니다.

안 보이면 그냥 알려 주세요. 볼 곳이 세 군데뿐이라 금방 찾습니다 (규칙 · 예산 이름 철자 · 서버 기록).
＋

나중에 해도 되는 것 두 가지

  • 쪼개 보기 — 지금은 총액 하나만 뜹니다. 「사진 창고에 얼마」까지 보시려면 예산을 3개 더 걸어야 합니다(구글이 총액만 쏘기 때문에 다른 방법이 없습니다). 총액만으로도 충분하시면 안 하셔도 됩니다.
  • 눈금 정하기 — 한 달 지켜보고 실제 사용액을 아신 뒤에 정하시면 그때부터 막대가 생깁니다(8할에서 노랑, 다 차면 빨강).

둘 다 말씀만 하시면 그때 제가 해 드리겠습니다.
