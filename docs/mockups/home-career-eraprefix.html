경력 줄마다 前 / 現 고르기

대표 지시 2026-09-03: 「전, 현 한자를 선택해야할 경우가 많다. 이부분은 경력관리와 연결해서 선택하고 전현도 선택할 수 있게 해달라」
실제로 눌러 보십시오 — 딱지를 누르면 글 앞의 한자가 바뀝니다. 아래 검정 칸에 결과가 나옵니다.

① 경력사항 — 줄마다 딱지 지금은 한자를 손으로 친다

「現」·「前」은 자판으로 바로 안 나옵니다. 열여덟 줄을 고치려면 한자를 열여덟 번 찾아 넣어야 했습니다. 딱지를 누르면 글 앞의 한자만 바뀝니다 — 뒤에 오는 글은 손대지 않습니다.

② 경력관리에서 당겨오기 — 넣기 전에 고른다 지금은 자동으로만 정해진다

지금도 기간을 보고 자동으로 現/前 을 정합니다. 그건 그대로 둡니다 — 대개 맞으니까요. 다만 딱지를 눌러 바꿀 수 있게 합니다. 「기간 모름」인 줄이 특히 그렇습니다.

체크한 것만 경력사항에 들어갑니다. 앞의 한자는 딱지로 고르십시오.
앞의 한자를 정하는 규칙
  1. 기간이 안 끝난 것 → 現 으로 미리 골라 둡니다
  2. 기간이 끝난 것 → 前 으로 미리 골라 둡니다
  3. 기간을 모르는 것은 끝났다고 단정하지 않고 現 으로 두되 「기간 모름」을 남깁니다
  4. 어느 것이든 딱지를 눌러 바꿀 수 있습니다 — 자동은 «첫 값»일 뿐입니다
  5. 학력·자격증처럼 전현이 없는 갈래는 없음으로 둡니다

지키는 것

  • 글은 안 건드립니다 — 딱지는 맨 앞의 「現 」·「前 」만 붙이고 뗍니다.
  • 없음이 있습니다 — 학력·자격증에 「現」을 억지로 붙이지 않습니다. 켜진 딱지를 다시 누르면 없음으로 돌아갑니다.
  • 손으로 쳐 넣은 한자도 알아봅니다 — 이미 「現 …」로 적힌 줄은 딱지가 켜진 채로 열립니다.
  • 자동 판단은 그대로입니다 — 당겨올 때 기간으로 정하던 것은 «첫 값»으로 남습니다.
  • 한 줄에 딱지가 붙어도 줄 수는 그대로입니다 — 높이가 늘지 않습니다.
