이 창이 지키는 것

① 넣기 전에 보여 준다
무엇이 어느 칸으로 갈지 표로 먼저 봅니다. 칸을 눌러 그 자리에서 고칠 수 있습니다. 틀린 줄은 체크를 꺼서 뺍니다.
② 이미 있는 것은 «새로 안 만든다»
같은 자격명·취득일이 이미 있으면 「이미 있음」으로 갈라 체크를 꺼 둡니다. 중복이 쌓여 목록이 두 배가 되는 일을 막습니다.
③ 서버·열쇠가 필요 없다
화면 안에서 끝납니다. 파이어베이스 규칙도, 새 서버도, 인터넷도 필요 없습니다. 주민번호가 든 자료가 밖으로 나갈 길이 아예 없습니다.
④ 되돌릴 수 있다
넣은 직후 「방금 넣은 N건 되돌리기」가 뜹니다. 잘못 붙여넣었을 때 한 번에 뺍니다.

「클로드 MCP 로 직접」과 견주면

대표님 질문에 대한 답입니다. 경력관리 자료는 대표님 PC 브라우저 안에 있습니다 — 클라우드는 그 사본입니다. MCP 서버는 브라우저 안을 만질 수 없어서, 「직접」이 되려면 꼭 어딘가를 거칩니다.
길어떻게새로 만들 것위험
㉮ 이 붙여넣기 창 표를 붙여넣고 미리보기 → 넣기화면 하나낮음
㉯ 받은 함 MCP MCP 가 「받은 함」에 넣고 대표가 들이기서버 + 로그인 열쇠낮음
㉰ 클라우드 직접 쓰기 MCP 가 자료 사본을 바로 고친다서버 + 열쇠 + 삭제기억 셈법높음
㉱ 크롬으로 지금 제가 대표님 크롬에서 폼에 넣는다없음보통
  • ㉰ 은 권하지 않습니다. 그 자리는 「지웠다」는 기억(자리표)과 기기 간 순서를 함께 들고 있어, 한 번 잘못 쓰면 대표님 기록이 조용히 사라집니다. 되돌릴 수 없는 쪽입니다.
  • ㉯ MCP 는 되기는 하지만 더 편하지 않습니다. 서버를 만들고 열쇠를 쥐어 줘도, 대표님이 「들이기」를 누르는 것은 그대로입니다.
  • ㉮ 는 오늘 만들 수 있습니다. 그리고 대표님이 전에 말씀하신 「추가 입력은 직접 타이핑으로 넣고 싶다」와 같은 길입니다.
