푸른포털 — 「푸」 표식을 로그인 화면 어디에 세울까

앱 아이콘(휴대폰 홈화면)과 탭 아이콘은 이미 「푸」 표식으로 바꿔 두었습니다. 이름도 「푸른 통합 포털」 → 「푸른포털」 로 줄였습니다.

남은 것은 로그인 화면 한 곳입니다. 지금은 표식이 화면 왼쪽 위 구석에만 작게 있어, 들어올 때 눈에 먼저 들어오는 것은 글자뿐입니다. 아래 세 가지 중 고르시면 그대로 하겠습니다.

지금 표식은 구석에만
