# 자료 덮어쓰기 방어 (2026-08-15 감사)

저장 코드(`dbSet`)를 건드리기 전에 이 문서를 먼저 읽으십시오.
여기 적힌 겹 중 하나라도 빼면 **예전에 실제로 났던 사고가 되살아납니다.**

---

## 한 줄 요약

**모든 항목에 `id` 가 있는 배열만 「병합」됩니다.** 그 밖에는 통째로 덮어씁니다.

병합은 *내가 바꾼 것만* 서버 현재값에 얹는 방식이라, 그 사이 남이 넣은 줄이 살아남습니다.
통째 덮어쓰기는 그 줄을 지웁니다.

---

## dbSet 이 지키는 겹 (모두 실제 사고에서 나왔다)

| 겹 | 무엇을 막나 |
|---|---|
| 초기 동기화 전 쓰기 보류 | 새 기기의 **옛 localStorage** 가 서버를 과거로 되돌리는 것 |
| 0건 차단 | 있던 자료가 통째로 지워지는 것 |
| 급감 차단 (10건↑ → 절반 이하) | 대량 유실. 일부러면 콘솔에 `erpAllowBulk()` 후 15초 안에 저장 |
| 서버 대비 급감 차단 | 내 기기가 서버보다 훨씬 적으면 **옛 자료**로 보고 차단 |
| 확인 실패 시 보류 | 서버 상태를 못 읽으면 **덮어쓸 권리가 없다**(fail-closed) |
| **트랜잭션 병합** | 다른 기기가 방금 넣은 줄을 지우는 것 ← 가장 중요 |
| 묶음표(객체) 병합 | 여럿이 같은 표의 다른 칸을 만질 때 |
| 되돌림 방지 | 서버가 더 최신이면 덮지 않고 받아온 뒤 「다시 확인하세요」 |
| meta 되돌리기 · 재전송 표시 | 실패했는데 **이 기기가 더 최신인 척** 하는 것 |
| 비번 보호 | 실비번이 기본비번으로 되돌려지는 것 |
| 중복 id 자동 제거 | 같은 id 두 줄 |

⚠ **중복 id 제거가 있으므로, 열쇠를 새로 만들 때 겹치면 한 줄이 「지워집니다」.**
겹칠 수 있는 열쇠는 `#2`, `#3` 을 붙이십시오 (연차대장·통장내역·CMS 가 그렇게 합니다).

## 감사 결과 (2026-08-15)

동기화되는 배열 **51개**를 훑었습니다.

- **33개** — 항목에 `id` 가 있어 병합됩니다. 손댈 것 없음
- **1개** — `leave_ledger`(연차대장): 업무 자료인데 `id` 가 없었습니다 → **고쳤습니다**
- **14개** — `id` 가 없지만 그럴 까닭이 있습니다 (아래)
- 나머지는 배열이 아닙니다(설정값·묶음표)

### id 가 없어도 두는 것

| 열쇠 | 까닭 |
|---|---|
| `locked_*_months` 6개 | `['2026-06', …]` 처럼 **달 이름만** 든 배열. 붙일 자리가 없음. 동시에 잠그면 한쪽이 밀리지만 다시 누르면 됨 |
| `holidays` · `pay_items` · `biz_case_types` · `biz_company_types` | 설정표. 대표 혼자 고치고 통째로 바꾸는 것이 정상 |
| `backup_history` · `error_log` · `payroll_audit_log` · `integrity_results` | 기록·결과. 다시 만들면 됨 |

> 이 목록은 `tests/erp-overwrite-guard.test.js` 에 그대로 있습니다.
> **여기 없는 새 배열이 `id` 없이 들어오면 검사가 걸립니다.**

### 연차대장에서 고친 것

1. 행에 `id` 를 붙였습니다 — `ll-이름|연도`, 겹치면 `#2`·`#3`
2. 저장 직전에 **최신을 다시 읽어 내가 고친 행만** 얹습니다
3. 서버가 바뀌면 화면을 다시 읽습니다 — 단, **치고 있는 중에는 안 바꿉니다**
4. 이름·연도가 아니라 `id` 로 **그 줄만** 고칩니다 (겹친 행이 같이 바뀌던 문제)
5. **빈 대장은 저장하지 않습니다** — 2026-07 사고 경로

## 새 자료를 만들 때

- 여럿이 만지는 목록이면 **항목마다 `id` 를 주십시오.** 그래야 병합됩니다
- 열쇠는 **기기마다 같아야** 합니다. 저장된 순서를 기준으로 만드십시오
- 겹칠 수 있으면 `#2` 를 붙이십시오. **겹친 열쇠는 자료를 지웁니다**
- 화면이 목록을 통째로 되쓰지 마십시오. **저장 직전에 최신을 읽어 내 변경만 얹으십시오**
