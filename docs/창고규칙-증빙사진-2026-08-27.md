# 창고(Storage) 규칙 — 증빙 사진용

2026-08-27

---

## ⚠ 먼저: 창고가 **네 개**입니다

지금 화면에 보이는 `pureun-erp.firebasestorage.app` 는 **다른 창고**입니다.
넣으실 곳은 **`pureun-erp-hrphotos`** 입니다.

| 창고 | 무엇이 들어 있나 | 쓰는 앱 |
|---|---|---|
| **`pureun-erp-hrphotos`** ← **여기** | 사진첩 사진 · **증빙 사진(새로 추가)** | 사진첩 · 정부사업일정 · 기금관리 |
| `pureun-erp.firebasestorage.app` | 급여자료(`pu_paydata/`) · 기금 서류 | 급여데이터함 · 기금 · 홈 · 업무 |
| `pureun-erp-photos` | 명함·사업자등록증 원본 | 기업정보함 |
| `pureun-erp.appspot.com` | 급여OS | payroll-os |

---

## 어디로 가나 — 세 걸음

1. 왼쪽 메뉴 **Storage**
2. 화면 위 **창고 이름 옆 ▾** 를 눌러 **`pureun-erp-hrphotos`** 를 고릅니다
   (지금은 `pureun-erp.firebasestorage.app` 로 되어 있습니다)
3. 그 상태에서 **「규칙」** 탭

> **창고를 먼저 바꾸고 규칙 탭으로 가야 합니다.** 창고마다 규칙이 따로입니다.
> 창고를 안 바꾸고 넣으면 엉뚱한 창고에 들어가 아무 일도 안 일어납니다.

---

## 넣을 것 — 이 한 덩이

기존 줄은 **하나도 지우지 마시고**, `match /b/{bucket}/o {` 안쪽에 끼워 넣습니다.

```
    // 정부사업일정 — 현장 사진(증빙). 법인 기록이라 로그인한 직원이면 누구나 본다.
    match /gov_evidence/{sid}/{file} {
      allow read:  if request.auth != null;
      allow write: if request.auth != null;
    }
```

### 넣는 자리 — 이런 모양이 됩니다

```
rules_version = '2';
service firebase.storage {
  match /b/{bucket}/o {

    ... 사진첩(pu_photos) 규칙 — 이미 있는 것, 그대로 둡니다 ...

    // ↓↓↓ 여기에 붙여 넣습니다 ↓↓↓
    match /gov_evidence/{sid}/{file} {
      allow read:  if request.auth != null;
      allow write: if request.auth != null;
    }
    // ↑↑↑ 여기까지 ↑↑↑

  }
}
```

마지막에 **「게시」** 를 누르셔야 적용됩니다.

## 전문으로 받고 싶으시면

**지금 규칙 화면의 글을 통째로 복사해서 붙여 주십시오.**
실시간DB 때처럼 **기존 것 + 이 한 덩이**를 합친 전문을 만들어 드리겠습니다.

> 지금 규칙을 안 보고 전문을 만들면 **사진첩이 막힐 수 있습니다.**
> 창고 규칙은 실시간DB를 못 읽어서, 사진첩은 공유·관리자 접근을
> 「토큰 주소」로 풀고 있습니다. 그 부분을 모르고 덮으면 사진이 안 열립니다.
> 그래서 **덧붙이는 한 덩이**만 먼저 드립니다 — 이건 무엇도 지우지 않아 안전합니다.

---

## 왜 「직원이면 누구나」인가

- 증빙 사진은 **법인 기록**입니다. 담당자가 바뀌거나 대표님이 확인하실 때
  못 보면 안 됩니다.
- 사진첩(`pu_photos`)에 안 넣은 것도 같은 이유입니다 — 사진첩은 **사람별로 갈려**
  있어 주인과 총괄관리자만 읽습니다. **동료가 못 봅니다.**
- 익명 로그인은 2026-07-30 부터 막혀 있으므로 `request.auth != null` 은
  **사실상 「로그인한 직원」** 입니다. 새로 여는 권한이 아닙니다.

---

## 넣은 뒤 확인

1. 정부사업일정 새로고침
2. **환경설정 → 백업/복원** → 맨 위 「☁ 증빙 사진을 창고에도 두기」
3. **[☁ 이 PC 사진 창고에 올리기]**
4. 「몇 장을 창고에 올렸습니다」가 뜨면 성공입니다

규칙이 없으면 **「창고 규칙이 아직 없습니다」** 라고 뜹니다 — 조용히 실패하지 않습니다.

> ⚠ **직원마다 자기 PC 에서 한 번씩** 눌러야 합니다.
> 지금까지 찍은 사진은 각자 PC 안에 있고, 남의 PC 안은 들여다볼 수 없습니다.
> 새로 찍는 사진은 그 뒤로 **저절로** 올라갑니다.
