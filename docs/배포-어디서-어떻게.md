# 배포 — 어디서, 어떻게

대표 지시 2026-09-03: 「어디다가 배포해야되나. 항상 이런것 요구할때 정확하게
어디에 배포해야되는지 알려달라.」

이 글은 그 답이다. **명령만 주고 「어디서」를 안 적는 일이 없게** 여기에 못 박아 둔다.

---

## 배포는 여기서 한다 — 딱 한 곳

```
C:\Users\fair0\Documents\pu-deploy
```

**왜 전용 폴더인가** — 이 저장소는 작업트리가 19개다. 이름이 그럴싸한 폴더도
믿을 수 없다: 2026-09-03 에 재 보니 `pureunall-deploy` 는 **다른 갈래에 안 커밋 4개**를
안고 있었다. 거기서 배포하면 **낡은 코드가 운영에 올라간다.**

⚠ 공용 작업트리(`Documents\pureunall`)에서 배포하지 말 것 —
거기는 여러 세션이 함께 쓰는 «밑둥»이다.

---

## ⚠ 「어디서」만큼 「최신인가」도 중요하다

전용 폴더도 **가만 두면 낡는다.** main 은 하루에 여러 번 움직인다.
2026-09-03 에 이 폴더를 만들면서 실제로 겪었다 — 만든 직후인데도 방금 병합된
함수가 **없었다**(낡은 참조로 만들어져서다).

그래서 배포 전에 **늘 최신으로 맞춘다.** 아래 한 덩이가 그 일을 함께 한다.

---

## 서버 함수 배포 (2단계)

### ① 최신으로 맞추고 «무엇이 올라가는지» 확인

```bash
cd /c/Users/fair0/Documents/pu-deploy && git fetch origin -q && git reset --hard origin/main -q && echo "머리 $(git rev-parse HEAD | cut -c1-8) / origin-main $(git rev-parse origin/main | cut -c1-8) / 안커밋 $(git status --porcelain | wc -l)개"
```

- 두 해시가 **같아야** 한다. 다르면 아직 안 맞은 것이다.
- 안커밋이 **0개**여야 한다.

### ② 이름을 찍어 배포

```bash
cd /c/Users/fair0/Documents/pu-deploy && firebase deploy --only functions:함수이름
```

⚠ **전체 배포(`--only functions`)는 막힌다.** 함수가 37개라 한꺼번에 올리면
할당량에 걸린다. 반드시 **이름을 찍는다.** 여럿이면 쉼표로:

```bash
firebase deploy --only functions:ilaborPull,functions:sendBulkMail
```

## 화면(HTML·JS) 배포는 «배포 명령이 없다»

화면은 **main 에 밀어넣으면 끝**이다. GitHub Pages 가 저절로 올린다.
`firebase hosting` 은 이 저장소에 없다 — `firebase.json` 에 `functions` 칸만 있다.

확인하는 곳: <https://nabaho.github.io/pureunall/>

⚠ `.js` 를 고쳤으면 그것을 부르는 html 의 `?v=` 를 올려야 반영된다.

---

## 파이어베이스 «규칙»은 배포하지 않는다 — 콘솔이 진짜다

```
콘솔 → Realtime Database → 규칙 → 붙여넣고 [게시]
```

⚠ **저장소 규칙 파일을 통째로 올리지 말 것.** 예전에 그렇게 했다가
사진첩·성과확인이 막혔다. 콘솔에는 저장소에 없는 것이 있다.
한 칸씩 끼워 넣는다 — `docs/firebase-rules-*-한칸만-넣기.txt`

CLI 로는 규칙을 **읽지도 쓰지도 못한다**(`database:settings:get` 이 거절한다).

## 비밀값(암호·열쇠)은 대표님만 넣는다

```bash
cd /c/Users/fair0/Documents/pu-deploy && firebase functions:secrets:set 이름
```

실행하면 값을 물어본다. **AI 는 그 값을 못 보고, 넣지도 않는다.**
넣은 뒤 그 값을 쓰는 함수를 **다시 배포**해야 새 값이 붙는다.

지금 쓰는 것: `DAUM_MAIL_PASSWORD` · `ILABOR_ID` · `ILABOR_PW`

지금 무엇이 들어 있나 (값은 안 보인다, 이름만):

```bash
cd /c/Users/fair0/Documents/pu-deploy && firebase functions:secrets:access ILABOR_ID --project pureun-erp 2>&1 | head -1
```

## 한눈에

| 무엇 | 어디서 | 어떻게 |
|---|---|---|
| 서버 함수 | `pu-deploy` | `firebase deploy --only functions:이름` (이름 필수) |
| 화면 | 아무 곳 | main 에 밀어넣기 (자동) |
| DB 규칙 | 콘솔 | 붙여넣고 [게시] (한 칸씩) |
| 비밀값 | `pu-deploy` | `firebase functions:secrets:set 이름` → 함수 재배포 |

## 이 폴더가 없어졌으면

```bash
cd /c/Users/fair0/Documents/pureunall && git worktree add --detach /c/Users/fair0/Documents/pu-deploy origin/main
```

만든 뒤에도 위 ①을 한 번 돌려 최신인지 확인한다.
