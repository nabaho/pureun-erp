# 푸른사진첩 — 파이어베이스 규칙 붙여넣기 안내

작성일: 2026-08-02 · 대상: 대표님 (콘솔 권한이 있는 분)

> **✅ 2026-08-02 저녁 완료됨.** 실시간DB(`puphotos`)·창고(`pu_photos`) 규칙 모두 게시됐다.
> 다만 창고 점검 결과 **`storage/quota-exceeded`** — 규칙이 아니라 요금제 문제(신규 버킷은 Blaze 전용, 현 계정은 체험판)라 **저장 방식은 실시간DB로 확정**했다.
> ⚠ 이 문서와 달리 **콘솔 Storage 규칙은 비어 있지 않았다** — `kcareer`(경력관리)·`fund_erp`(기금 서류)가 이미 있었고, 셋을 합쳐 게시했다. 앞으로 Storage 규칙을 만질 때는 반드시 기존 내용에 끼워 넣을 것.

사진첩이 사진을 담을 자리가 두 곳인데, **둘 다 지금은 잠겨 있어서** 규칙을 넣어 주셔야 다음 단계(사진 저장)가 됩니다.

| 자리 | 무엇을 담나 | 규칙이 필요한 때 |
|---|---|---|
| 실시간DB `puphotos` | 사진 정보(올린 사람·촬영 시각·회사 등) | **저장 방식과 무관하게 반드시** |
| 파일 창고 `pu_photos` | 사진 파일 본문 | 창고 방식으로 정해질 때 (점검 전에 미리 넣어야 점검이 통과함) |

## 순서

1. **실시간DB 규칙** — 이 저장소의 `docs/firebase-rules-현재적용본.json` 파일 **전체**를 복사해 콘솔의 *Realtime Database → 규칙*에 붙여넣고 게시합니다.
   - 이번에 `puphotos` 한 덩이가 추가됐습니다(다른 앱과 같은 기준 — 이메일 로그인 계정만 읽고 쓰기). 기존 규칙은 한 줄도 바꾸지 않았습니다.
   - ⚠ 붙여넣기 전에 콘솔 쪽에 이 파일에 없는 낯선 항목이 보이면 **중단**하고 알려 주세요 (다른 세션이 또 바꿨을 수 있습니다).

2. **파일 창고 규칙** — 콘솔의 *Storage → Rules*를 엽니다.
   - 창고를 한 번도 안 켰다면 먼저 *Storage → 시작하기*를 눌러 켭니다.
   - 규칙 칸이 사실상 비어 있으면(기본 거부 문구뿐이면) 아래 **전체본**을 통째로 붙여넣습니다.
   - 이미 다른 내용이 들어 있으면(예: `fund_erp` 관련) 전체를 갈지 말고 아래 **추가용 조각**만 기존 `match /b/{bucket}/o { … }` 안에 끼워 넣습니다.

3. **창고 점검** — 배포 주소에서 푸른사진첩 → 설정 → **창고 점검**을 누르고, 화면에 나온 문구를 그대로 알려 주세요. 그 결과로 저장 방식을 확정합니다.
   - localhost에서는 로그인이 막혀 점검이 안 됩니다. 반드시 배포 주소에서 하세요.

## 파일 창고 규칙 — 전체본

```
rules_version = '2';
service firebase.storage {
  match /b/{bucket}/o {
    // 푸른사진첩 — 이메일 로그인 계정만 읽고 쓴다 (실시간DB와 같은 기준)
    match /pu_photos/{allPaths=**} {
      allow read, write: if request.auth != null
        && request.auth.token.firebase.sign_in_provider == 'password';
    }
  }
}
```

## 파일 창고 규칙 — 추가용 조각 (기존 규칙이 있을 때)

```
    // 푸른사진첩 — 이메일 로그인 계정만 읽고 쓴다 (실시간DB와 같은 기준)
    match /pu_photos/{allPaths=**} {
      allow read, write: if request.auth != null
        && request.auth.token.firebase.sign_in_provider == 'password';
    }
```

## 참고

- 위 규칙은 로그인한 재직자 전원이 읽고 쓰는 수준입니다. 설계서의 개인잠금·삭제 권한 등 세밀한 제한은 화면 단계(C단계 이후)에서 규칙을 조인 뒤 다시 게시합니다.
- 점검이 "막혔습니다 — 파일 창고가 아직 연결되지 않았습니다"라고 하면 규칙 문제가 아니라 창고가 안 켜진 것입니다(2번의 *시작하기*).
