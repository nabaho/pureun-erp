# 자료 메일 자동 발송 켜기 (명함첩 → 다음메일)

명함첩에서 자료를 보낼 때 **첨부까지 자동으로 붙여 회사 다음메일 주소로** 내보내는 기능입니다.
코드는 모두 올라가 있고, **아래 세 가지는 대표님 계정으로만 할 수 있습니다.**

켜기 전까지는 예전 방식(메일창 열기 + 손으로 첨부)으로 그대로 돌아갑니다.
**켜 두었는데 서버가 아직이면 자동으로 예전 방식으로 되돌아갑니다** — 일이 멈추지 않습니다.

---

## 왜 다음메일 SMTP 인가

Resend 같은 발송 서비스는 **우리가 가진 도메인**으로만 보낼 수 있습니다.
`hanmail.net` 은 카카오 것이라 우리가 인증할 수 없습니다.
회사 주소 그대로 내보내려면 그 계정의 SMTP 로 직접 붙는 수밖에 없습니다.

> 참고: 다음메일의 **자동전달**로는 안 됩니다. 자동전달은 받는 곳이 하나로 고정이라
> 사업장마다 다른 주소로 보낼 수 없습니다.

---

## 접속 아이디는 주소와 다르다

다음메일 설정 화면이 이렇게 알려 준다.

| | 값 |
|---|---|
| SMTP 서버명 | `smtp.daum.net` |
| SMTP 포트 | `465`, 보안연결(SSL) |
| **아이디** | **`370-6`** ← 주소 전체가 아니라 `@` 앞부분 |
| 비밀번호 | 앱 비밀번호 |

**이건 신경 쓰지 않으셔도 된다.** 서버가 `@` 앞부분으로 먼저 붙어 보고,
자격 문제로 막히면 주소 전체로 한 번 더 해 본다. 어느 쪽인지 시험 삼아
보내 볼 필요가 없다.

한 계정에 `@daum.net` 과 `@hanmail.net` 주소가 함께 딸려 온다.
「보내는 주소」에는 **받는 분께 보이고 싶은 쪽**을 넣으면 된다.

---

## 1. 다음메일에서 SMTP 를 켠다

1. 다음메일 → 환경설정 → **IMAP/SMTP 사용** 켜기
2. 2단계 인증을 쓰신다면 **앱 비밀번호**를 따로 만듭니다
   (일반 비밀번호로는 막힙니다)

앱 비밀번호는 **아무에게도, 채팅에도 붙여넣지 마세요.** 아래 2번에서 직접 넣습니다.

## 2. 서버에 계정을 넣는다

Firebase **유료 요금제(Blaze)** 로 올려야 함수가 돕니다. 그 다음:

```bash
firebase functions:secrets:set DAUM_MAIL_PASSWORD
```

물어보면 앱 비밀번호를 입력합니다. 화면에 찍히지 않고 저장됩니다.

보내는 주소는 비밀이 아니므로 **명함첩 화면에서** 넣습니다(4번). 파일을 만들 필요가 없습니다.

## 3. 함수를 올린다

```bash
firebase deploy --only functions:sendMaterialMail
```

---

## 4. 명함첩에서 켠다

명함첩 → **📎 자료함** → **✉️ 메일 본문** →
① 「보내는 방법」에서 **회사 메일로 바로 보내기** 고르기
② 아래에 나타나는 **보내는 주소** 칸에 `370-6@hanmail.net` 넣기

전 직원에게 함께 적용됩니다. **비밀번호는 이 화면에 넣지 않습니다** — 여기는 직원 누구나 읽습니다.

---

## 켜면 달라지는 것

| | 예전 | 자동 발송 |
|---|---|---|
| 첨부 | 내려받아 손으로 붙임 | 저절로 붙음 |
| 보내는 사람 | 그 PC 에 설정된 계정 | `370-6@hanmail.net` |
| 답장 받을 곳 | 그 PC 계정 | **보낸 직원 주소** (누구 건인지 알 수 있게) |
| 보낸편지함 | 안 남음 | 다음메일에 남음 |
| 보낸 기록 | 화면이 남김 | **서버가 실제로 나간 뒤** 남김 |

---

## 막아 둔 것

회사 메일 계정이 공개 발송기가 되지 않도록 서버에서 걸러 냅니다.

- 이메일 로그인 직원만 부를 수 있습니다
- 받는 사람 5명, 참조 5명까지
- 첨부는 **합계** 18MB 까지 (한 개씩만 보면 큰 것 여러 개가 통과합니다)
- 제목의 줄바꿈을 없앱니다 — 남기면 그 뒤에 `Bcc:` 를 붙여 몰래 다른 곳으로도 보낼 수 있습니다
- 파일 이름의 위험한 글자를 바꿉니다

## 안 될 때

명함첩이 실패한 이유를 그대로 띄우고 **예전 방식으로 이어서** 갑니다.

- `메일 서버가 받지 않았습니다` → IMAP/SMTP 가 꺼져 있거나 앱 비밀번호가 아닙니다
- `메일 계정이 설정되지 않았습니다` → 2번을 안 했거나 다시 배포하지 않았습니다
- `서버 응답 404` → 3번(함수 올리기)을 안 했습니다
