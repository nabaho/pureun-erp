# 카카오 로그인 다음 작업

상태: 계획 보류 — 사용자 요청 시 다음 작업으로 실행

## 목표

- 기존 아이디·비밀번호 로그인을 유지한다.
- 사용자가 기존 계정으로 로그인한 뒤 카카오 계정을 1회 연결한다.
- 이후에는 카카오 로그인으로 기존 푸른 계정과 권한을 그대로 사용한다.
- 이메일이 같다는 이유만으로 계정을 자동 연결하지 않는다.
- 관리자가 연결 내역을 확인하고 연결을 해제할 수 있게 한다.

## 실행 순서

1. 카카오 Developers 애플리케이션 등록
2. 운영 도메인과 Redirect URI 등록
3. 최소 동의항목 설정
4. Firebase 인증과 카카오 OAuth/OIDC 연결 방식 확정
5. 푸른 사용자 UID와 카카오 고유번호 연결 데이터 설계
6. 로그인 화면에 `카카오로 로그인` 추가
7. 내 정보에 `카카오 연결/해제` 추가
8. 총괄관리자·관리자·일반 사용자 권한 유지 확인
9. PC·모바일·새 창·로그아웃·연결 해제 시험
10. 일부 사용자 시험 운영 후 전체 적용

## 다음 시작 문구

사용자가 `카카오 로그인 작업 시작`이라고 요청하면 이 문서를 기준으로 현행 로그인 구조부터 점검한다.

## 주의사항

- 기존 로그인은 비상 접근 수단으로 유지한다.
- 카카오 비밀키, Firebase 인증키 및 개인정보는 GitHub에 저장하지 않는다.
- 계정 연결은 기존 푸른 계정 인증 후에만 허용한다.
