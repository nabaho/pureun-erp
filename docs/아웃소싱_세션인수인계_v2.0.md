## 5. 실측 사실 (설계 뼈대)
- 사업장은 급여프로그램 아닌 **수기 엑셀** → 고용보험 단수처리(절사/올림/반올림) 혼재, 요율 0.9/0.899/면제 혼재.
- **연금·건보=공단 고지액**(연금 월고정·건보 4월변동) → 재계산 금지, 고지액 모드.
- 지방세=소득세×10% 절사(확실). 고용보험 요율 **연도별**(2021이하 0.8%, 2022+ 0.9%).
- 급여대장 매체: **xlsx 678(파싱 85%) / PDF 519 / 이미지 467 / hwp 106** → 절반 이상이 PDF·이미지(**OCR 필요**).
- 산정기간: 대부분 1일~말일이나 **비표준 6곳**(알오엠 11~10일 등). 급여일: 5일·말일 각 7곳 등.

## 6. 확정 결정 목록
- **파일럿 3곳**: 화담원 · 제이앤드씨 · 늘봄.

- 개발순서: **①핵심루프(수신함→엔진→검토→확정→명세서) 한바퀴 → ②OCR·어댑터 → ③파생신고 → ④부가모듈**.
- 유지보수: 담당자는 **코드 아닌 설정카드만** 화면에서 수정(사업장별 담당자 잠금+수정기록+승격루프). 충돌 구조적 차단.
