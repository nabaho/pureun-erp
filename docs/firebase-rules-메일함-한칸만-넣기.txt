메일함(mailbox) 규칙 한 칸만 넣기 — 대표님용
════════════════════════════════════════════════════════════════════

전문 40KB 를 다시 붙여넣지 않아도 됩니다. 아래 «네 줄»만 지금 규칙 맨 앞에
끼워 넣으면 됩니다.

── 어디로 가나 ──
1) 파이어베이스 콘솔 → Realtime Database → 위쪽 「규칙」 탭
2) 편집칸 맨 위가 이렇게 생겼습니다:

   {
     "rules": {
       "billing": {
       ...

3) "rules": { 바로 «다음 줄»에 아래 네 줄을 붙여넣습니다.

── 붙여넣을 것 ──

    "mailbox": {
      ".read": "auth != null && root.child('uid_roles').child(auth.uid).child('isAdmin').val() == true",
      ".write": false
    },

── 넣으면 이렇게 됩니다 ──

   {
     "rules": {
       "mailbox": {
         ".read": "auth != null && root.child('uid_roles').child(auth.uid).child('isAdmin').val() == true",
         ".write": false
       },
       "billing": {
       ...

4) 오른쪽 위 [게시] 를 누릅니다. 그 뒤 푸른 메일에서 [새로고침 ↻] 를 누르면 목록이 뜹니다.

── 무슨 뜻인가 ──
· .read  = 총괄관리자로 로그인한 사람만 메일함 목록을 «본다».
           회사 메일함에는 고객사 임직원의 성명·연락처가 제목에까지 들어 있어
           직원 전체에게 열지 않았습니다.
· .write = false — 아무도 «못 고친다». 적는 것은 서버뿐이고, 서버는 규칙을 지나갑니다.
           앱에서 고칠 수 있게 열어 두면 목록을 고쳐 놓고 다음메일과 다르다고 할 수
           있습니다(거울은 원본을 고치지 않습니다).

⚠ 쉼표를 빠뜨리지 마십시오. 붙여넣는 네 줄의 끝 「},」 의 쉼표가 있어야 뒤의
  "billing" 과 이어집니다. [게시] 를 누를 때 콘솔이 문법을 검사해 주므로,
  빨간 줄이 뜨면 그 자리만 보시면 됩니다.

⚠ 규칙은 «콘솔이 진짜»입니다. 저장소 파일로 배포하지 않습니다 —
  예전에 그렇게 해서 사진첩·성과확인이 막힌 적이 있습니다.

전문을 통째로 갈아 넣고 싶으시면:
  docs/firebase-rules-메일함동기화(붙여넣기용).json  ← 지금 규칙 + 이 한 칸이 든 전문
