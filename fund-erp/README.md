# 근로복지기금 통합 운영시스템 (fund-erp)

계획서 v0.5 기준 1단계 구현. 푸른이알피(pu-erp) 업체관리 모듈의 조작 패턴을 채택.

## 실행

```bash
cd "02_프로그램/fund-erp"
pip install -r requirements.txt
python import_excel.py            # 최초 1회: 푸른노무법인 통합 엑셀 → DB 이관
python import_funds_master.py     # 기금 대장(복지기금담당자등 시트) 이관
python scan_archive.py --register # 03_과거자료 스캔 → 문서철 등록
python -m uvicorn app:app --port 8777
# 브라우저: http://localhost:8777
```

## 구성

| 파일 | 역할 |
|---|---|
| `schema.sql` | SQLite 25테이블 (기준정보·관계기관·회계·사업·업무문서) |
| `db.py` | 연결·초기화·감사로그·식별자 발급 |
| `import_excel.py` | 「푸른노무법인 (4).xlsx」 2025/2026 지역공근사업장 시트 이관 + 관계기관 자동 연결(충남 호수별 출연 지자체·공단·푸른노무법인) + 법정서식 5종 서식마스터 시드 |
| `app.py` | FastAPI 백엔드 (대시보드·기금·사업장·스냅샷·엑셀왕복·기관담당자·감사로그) |
| `static/index.html` | 단일 파일 프런트 (무빌드, pu-erp 조작감) |
| `fund.db` | SQLite DB (생성됨) |

## 현재 기능 (1단계)

- **대시보드 매트릭스**: 기금 16개 × 단계(설립·등기·운영·결산보고), 지원기관(지자체·공단)·수탁기관 표시, 연간 갱신 현황(n/m), 누락 경고
- **기금 상세**
  - 기관·담당자 패널: 출연지자체 / 지원기관 / 위탁기관 / 수탁기관 + 담당자 등록(교체 시 이력 보존)
  - 참여사업장: 참여중/탈퇴·폐업 탭, 검색, 정렬, **엑셀식 인라인 편집**(Enter=저장 후 ↓, Tab=→, Esc=취소)
  - 마스터 필드(상호·사업자번호·대표자·소재지·업종·비고)와 연도값(근로자수·근로자대표·출연액)을 자동 구분 저장
  - 급변동(전년 대비 ±50% & 5명↑) 주황 표시, 누락 "+ 입력" 표시
  - 탈퇴·폐업 = 삭제 아닌 종료 처리(종료일·사유, 복구 가능)
  - 사업자번호 중복 감지(409)
- **연도 스냅샷**: 연도 셀렉터, 확정 잠금(잠금 시 연도값 수정 423 차단), 과거 연도 값 보존
- **갱신 엑셀 왕복**: 현재 값 채운 엑셀 내려받기(연번 텍스트 서식) → 수정 → 올리기(사업자번호/정규화 명칭 매칭, 변경분 upsert, 급변동·누락·신규 리포트 모달)
- **감사로그**: 모든 생성·수정·잠금·가져오기 기록 (`/api/audit`)

## 개인정보 원칙 (0단계 반영)

- 주민등록번호 등 민감정보는 **스키마에 저장 칸 자체가 없음** (persons.birth 수준까지만)
- 이관 시 업무 연락처(성명·직무·전화·이메일)만 읽음
- 원본 문서 폴더의 PII 파일(재직증명·인감·주민번호 포함 시트)은 시스템에 올리지 말 것

## 구현 완료 기능 (1~3단계)

기금 상세 탭 6종:
1. **참여사업장** — 인라인 편집·연도 스냅샷·갱신 엑셀 왕복·탈퇴 처리
2. **문서철** — 과거자료 2,932건 종류별 열람·원본 열기
3. **일괄수정 (M8)** — 공통정보·인가등기·등기전용·예산·임원 1회 입력 → 모든 서류 반영
4. **서류 생성 (M6·M7)** — 설립 6종 + 등기 8종, 기금 종류별 세트 자동, 인쇄/PDF
5. **회계·결산 (M11·M12·M13)** — 계좌 등록 → 통장 엑셀 가져오기(중복·이체·취소 검사) → 자동분개 제안 → 담당자 승인 → 결산 관문(미분류 0·미승인 0·대차 일치) → 재무제표 → 별지15호 매핑 → 마감 잠금
6. **지원금 (M14, 공동 전용)** — 공고·신청·정산 관리, 지원신청서 생성, 정산 대사(미집행/과다)

## 남은 작업

- 검수: X공동(2025) / T공동(2019-20) 실통장으로 기존 제출본과 숫자 대조
- 서식 트랙(§18): docgen 초안 → 현행 법정서식 HWPX/PDF 실서식 재현으로 단계 교체
