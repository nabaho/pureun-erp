# 근로복지기금 운영시스템 — 설치·실행 안내

새 PC에 처음 설치하는 사람만 아래 **1회 설치**를 하면 됩니다. 그다음부터는 **실행**만 하면 됩니다.

---

## 1회 설치 (처음 한 번만)

### ① Python 설치
1. https://www.python.org/downloads/ 에서 **Python 3.10 이상**을 내려받아 설치합니다.
2. 설치 첫 화면에서 **`Add Python to PATH`** 체크박스를 반드시 켜고 설치하세요.

### ② 서식 원본 엑셀 넣기 (중요)
아래 두 파일은 **사업장 실데이터가 담긴 내부 파일**이라 코드와 따로 관리됩니다.
담당자에게 받아 `fund-erp\templates\` 폴더 안에 넣어주세요.

- `2024년 근로복지기금 설립인가신청서 양식_240906.xlsx`
- `2025년 공동근로복지기금지원신청서 양식(폐업 사업장 미포함).xlsx`

> 이 파일이 없으면 "설립 서식 엑셀 받기 / 지원신청서 엑셀 받기"만 동작하지 않습니다. 나머지 기능은 정상입니다.

### ③ 데이터 파일 넣기
- `fund.db` (기금 실데이터). 담당자에게 받아 `fund-erp\` 폴더에 넣습니다. 없으면 빈 상태로 시작됩니다.

---

## 실행 (매번)

`fund-erp` 폴더의 **`실행.bat`** 을 더블클릭하세요.

- 처음 실행 시 필요한 구성요소가 자동 설치됩니다(1~2분, 인터넷 필요).
- 잠시 후 브라우저가 열리고 시스템 화면이 나타납니다. 안 열리면 주소창에 `http://localhost:8777` 입력.
- **검은 명령창은 프로그램이 켜져 있는 동안 닫지 마세요.** 종료하려면 그 창을 닫으면 됩니다.

---

## 자주 묻는 것

| 상황 | 해결 |
|---|---|
| "Python이 설치되어 있지 않습니다" | Python 설치 시 `Add Python to PATH` 체크를 안 한 것. 재설치 |
| 브라우저가 안 열림 | 주소창에 `http://localhost:8777` 직접 입력 |
| 포트가 이미 사용 중 | 이전 검은 창이 남아 있는 것. 그 창을 닫고 다시 실행 |
| 서식만 빈칸/오류 | `templates\` 폴더에 원본 엑셀 2종이 들어 있는지 확인 |
| 구성요소 설치 실패 | 인터넷 연결 확인 후 재실행. 계속 실패 시 담당자 문의 |

---

## 백업

- `fund-erp\fund.db` — 모든 기금 데이터. 정기적으로 복사해 두세요.
- `fund-erp\uploads\` — 업로드한 스캔 서류 원본.

이 두 가지만 백업하면 데이터가 보존됩니다.
