# 참고자료

## 고용노동부 2026년 표준취업규칙

- 발간: 고용노동부 근로기준정책과, 2026-02-13
- 원본: `표준취업규칙(2026년, 배포).hwp` (278KB)
- 출처: https://www.moel.go.kr/policy/policydata/view.do?bbs_seq=20260200740
- 내용: 일반근로자용·단시간근로자용 표준취업규칙 + 별지 서식
- 본칙 조문 98개(제1조 목적 ~ 제98조 취업규칙의 변경).
  제61조·제62조는 노동부 원본이 대안 문안을 2개씩 제시하므로 파싱 결과는 100개.

**원본 .hwp는 저장소에 두지 않는다** (`.gitignore`의 `*.hwp`).
필요하면 위 출처에서 다시 받으면 된다.

본문 텍스트는 저장소의 `std_2026.js`에 담겨 있고, 규정관리(rules.html)가
표준규칙 보관함에 자동 등록한다(`stdSeedBundled`). 담당자가 로그인하면
공용(Firebase `chwieop/standard/2026`)으로 올라가 전원이 같은 기준으로 대조한다.

## 별지 제15호서식 (취업규칙 신고서·변경신고서)

- 근거: 근로기준법 시행규칙 [별지 제15호서식] <개정 2018. 6. 29.>
- 원본 내려받기(PDF, 107KB):
  https://www.law.go.kr/flDownload.do?gubun=&flSeq=35206442&bylClsCd=110202
  (2012. 2. 9. 개정본은 `flSeq=28008444`)
- **PDF도 저장소에 두지 않는다**(`.gitignore`의 `*.pdf`). 위 주소에서 다시 받으면 된다.

rules.html의 `applyFormHwpx()`는 이 원본을 PyMuPDF로 잰 좌표(`F15` 상수)로 만든다.
값을 고치기 전에 원본을 다시 받아 `scratchpad/measure15b.py`로 재 볼 것.
실측값(단위 HWPUNIT, 1pt=100·1mm≒283):

| 항목 | 값 |
|---|---|
| 용지 | A4 세로, 좌여백 5740 · 우여백 5710 · 표 폭 48070(169.6mm) |
| 접수 줄 | 16170 / 14760 / 17140, 높이 2380, 배경 #D6D6D6, 9pt |
| 신고내용 | 5280 / 25650 / 17140, 5행 × 3120, 10pt, 라벨·값이 한 칸 |
| 첨부서류 | 6020 / 34560 / 7490, 높이 6120, 7.5~8pt |
| 처리절차 제목 | 표 폭 1칸, 높이 2260, 배경 #BBBBBB, 10pt |
| 처리절차 상자 | 8060·1850·8420·1900·8760·1510·8620·1630·7320, 높이 2370 |
| 칸 여백 | 좌우 280, 표 바깥 0 |

※ 공개 배포 자료만 둔다. 사업장 실데이터는 저장소에 올리지 않는다.
