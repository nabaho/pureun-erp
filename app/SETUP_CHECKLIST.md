## ☐ 1. Firebase 프로젝트 만들기  → 3-6 백엔드
- console.firebase.google.com 접속(구글 계정으로 로그인)
- "프로젝트 만들기" → 이름 예: `pu-payroll`
- **리전은 서울(asia-northeast3)** 선택 (개인정보 국내 보관)
- 만들 것 2개:
  - **Realtime Database** (자료 창고)
  - **Storage** (명세서 PDF·원본 파일)
- ⚠️ **개발용/운영용 2개**를 따로 만드세요 (예: `pu-payroll-dev`, `pu-payroll`)
  → 테스트가 실제 급여를 건드리지 않게

**제게 주실 것**: 프로젝트 설정의 "웹 앱 구성값"(apiKey 등). ※ 비밀 아님(공개 설정)

---

## ☐ 2. 구글 로그인 켜기  → 3-2 인증
- Firebase → Authentication → "시작하기" → **Google** 로그인 사용 설정
- 담당자 5명 + 관리자 구글 계정 준비

**그다음 제가**: 로그인 버튼 + 권한(담당자/관리자) 연결, 담당자별 배정 사업장만 보이게

---

## ☐ 3. 법인 메일 도메인  → 3-3 수신함
- 이미 있으신 것: 발신 `payroll@fairrunlabor.com` (Resend 인증 완료)
- 필요: **수신 주소**(예: `자료@fairrunlabor.com`) — 사업장이 자료 보내는 곳
- 다음메일 자동전달을 이 주소로 유입 (사업장 재안내 불필요)

**그다음 제가**: 수신 웹훅 + 자동 태깅 + D-7 미도착 독촉 코드
