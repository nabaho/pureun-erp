# 2026-09-08 · 이관이 「적어 둔 계약기간」을 쓴다

- PR: [#1117](https://github.com/nabaho/pureunall/pull/1117)
- 대표 지시: 「계약정보는 자문으로 하였다. **수정한것이기 때문에 이부분 반영하여야 한다**」

## 무엇이 문제였나

계약 입력창의 「계약기간」은 `startDate`·`endDate` 에 적힌다.
그런데 이관은 **`signDate`(서명일)만 보고 「계약일 + 1년」을 지어냈다.**

★ **두 길이 갈라져 있었다.** 같은 일을 하는 `erpContractToCoFields`
(「계약관리에서 당겨오기」)는 `startDate` 를 먼저 본다 — 그 주석에는
「이관 때 쓰는 규칙과 «같게»」라고 적혀 있었는데 **정작 이관은 따로 셈하고 있었다.**
주석이 사실이라고 믿고 한쪽만 고쳤던 것이다(2026-09-06 당겨오기 쪽을 고칠 때).

## 고친 것

이관도 `erpContractToCoFields` 를 부른다 — 규칙이 **한 곳**이다.

| | |
|---|---|
| 개시일 | `startDate` → `contractStartDate` → `signDate` |
| 종료일 | `endDate` → `contractEndDate` → 서명일 + 1년 |
| 부가세 | 계약서에 적힌 것 (없을 때만 「별도」 — 옛 행동 그대로) |
