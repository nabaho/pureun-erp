# 2026-09-08 · 기업정보함 — 유형 탭을 「전체」에서 «폴더 안»으로

- 왜: 대표 지시 「전체명함에 캡쳐2는 필요없다. 캡쳐3 업체관리에 캡쳐2의 세부정보가
  필요하다. … 명함, 사업자 근로자 모두 같다. 전체에 자문 급여 노조 기금 해지 등은
  필요없다. 대시보드에 있기 때문에 2중으로 있고 많이 헤깔린다. 한번에 깔끔하게 정리하라」
- 무엇: 유형 탭(자문·급여·노조·기금·사무대행·🚪 해지)을 **없애지 않고 자리를 옮겼다**

## 무엇이 문제였나

유형 탭은 `scope:'all'` 로 심겨 있어 **「전체」에서만** 보였다. 그래서

| | |
|---|---|
| ① | 「전체」에서는 옆줄 폴더와 겹쳐 **같은 것을 두 번 세는 줄**이 되었다 |
| ② | 정작 필요한 「업체관리 안의 자문 몇 곳」은 **어디에서도 볼 수 없었다.** 전체의 「자문 231」은 어느 폴더의 수도 아니다 |
| ③ | 「노조 0 · 기금 0」이 늘 서 있어 줄만 길었다 |

## 만든 것

```
[전체 명함]   📋 전체 6,309                                    ＋ 탭 추가
[업체관리]    📋 전체 257 · 🔍 자문 231 · 🔍 급여 30            ＋ 탭 추가
[지인]        📋 전체 214                                       ＋ 탭 추가
```

- **잣대 한 곳** — `isErpTypeTab(v)`(유형 탭인가) · `tabChipLent(v)`(지금 빌려 온 것인가).
  그리는 곳과 «누르는 곳»이 이 둘만 본다. 칩에 갈래를 심어 보내면 한쪽만 고쳐져
  「보이는 수와 눌러서 나오는 수가 다르다」가 된다.
- 폴더 안에서는 조건에 **그 폴더를 끼워** 세고 그린다.
- **0 곳이면 칩이 빠진다** — 유형이 없는 폴더는 예전 「전체」 모양 그대로다.
- 누르면 `applyView(id, keepFolder)` 로 **지금 폴더를 그대로 두고** 조건만 입힌다.

## ⚠ 남긴 함정

- **탭 자체(`pucards/views`)는 지우지 않았다.** 지우면 대표가 바꿔 둔 이름까지 사라지고,
  씨앗(`seedErpTabs`·`seedClosedTab`)은 `localStorage` 열쇠 때문에 **다시 심기지 않는다** —
  되돌릴 길이 없어진다. 「내 탭 관리」(환경설정)는 예전대로 **모든** 탭을 보여 준다.
- **폴더를 «값»으로 넘기지 않는다.** `state.group` 은 **빈 글자가 미분류 폴더**라,
  넘겨받은 값을 `group||'all'` 로 갈음하는 순간 미분류에서 전체로 튄다. 그래서 갈래를
  참/거짓(`keepFolder`)으로 넘긴다.
- **「전체」에서만** 유형 탭을 뺀다. 「유형 탭은 다 뺀다」로 줄이면 폴더 **안에서** 대표가
  직접 만든 유형 탭(`scope` 가 그 폴더인 것)까지 함께 사라진다.
- `updateView`(⋮ → 조건 갱신)가 유형 탭에 **지금 폴더를 박지 못하게** 막았다. 박으면
  다른 폴더에서 0 곳이 되어 칩이 통째로 사라진다.
- 세는 일은 목록을 통째로 훑는 것이다(`listItems`). 0 인지 보려고 한 번, 화면에 쓰려고
  또 한 번 세면 폴더를 열 때마다 두 벌씩 훑는다 — **미리 센 수를 들고 온다.**

## 🚪 근로자·기업 상세는 손대지 않았다

- 근로자는 이미 **사건별 탭**이라 유형 탭이 없다(2026-09-07 #979).
- 기업 상세는 폴더 안의 `＃탭`(coFTab)이 따로 있고, 그것도 **폴더를 골랐을 때만** 나온다 —
  이번 규칙과 이미 같은 결이다.

## 검사

`tests/cards-type-tabs-in-folder.test.js` 17건 — 탭 줄을 **통째로 그려** 본다.
고장 18개를 넣어 모두 잡았다. 그 가운데 둘이 처음에 샜다:

- **미리 센 수를 안 쓴다** — 다시 세도 «수는 같아» 값만 보는 검사로는 못 잡았다.
  이제 «몇 번 셌는지»를 본다.
- **`tabChipLent` 에서 scope 검사를 뗀다** — 폴더가 제 유형 탭을 이미 가진 경우
  겹침 검사가 대신 막아 화면이 멀쩡했다. 이제 «뜻»을 바로 못 박는다.
