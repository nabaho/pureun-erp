## ⚠ 일부러 «안» 한 것

**「2. 지금 손이 필요한 것」 은 안 갈랐다.** 거기서 부딪히는 것은 두 방이 같은 항목을
다르게 고쳤다는 뜻이라 **사람이 봐야 한다.** 자동으로 합치면 어긋난 안내가 조용히 남는다.

`.gitattributes` 의 `merge=union` 도 안 썼다 — 로컬 git 에서는 듣지만
**GitHub 의 합치기에서는 안 듣는다.** 우리가 겪은 충돌은 GitHub 쪽이라
합치기 도구에 기대면 아무것도 해결되지 않는다. 그래서 **이름으로** 갈랐다.
