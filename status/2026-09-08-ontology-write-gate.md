# 2026-09-08 · 푸른통합 온톨로지 저장 관문 통합·안전성 검증

- 무엇: 15개 운영 프로그램과 Firebase를 여는 딸린 화면 3개, Cloud Functions 관리자 SDK에 공용 저장 관문을 연결했다.
- 안전: 기존 프로그램은 관찰 모드라 현재 업무를 막거나 원본을 자동 변경하지 않는다. 새 프로그램은 저장계약 선언과 완전한 레코드가 없으면 기본 차단한다.
- 동시접속·삭제: 공용 gateway에 `revision` 트랜잭션과 삭제표식을 제공하고, 부분 `update`·직접 `transaction` 우회를 강제 모드에서 막았다.
- 규칙: 관계망 개체·관계의 필수 모양과 판 내부 불변을 추가했다. 살아 있는 콘솔과 비교해 삭제되는 규칙 0개, Firebase dry-run 문법 통과 후 전용 안전 배포기로 적용했다.
- 검증: 관련 46개 검사와 관계망 규칙 검사 32개 통과. 전체 회귀검사는 최종 커밋 뒤 다시 실행한다.

- ⚠ 남긴 단계: 기존 15개 앱은 아직 관찰 상태다. 자료별 이관과 실제 저장 호출의 gateway 교체가 끝나기 전에는 동시 수정·물리 삭제를 완전히 차단했다고 말할 수 없다.
