# 푸른 하나문자 연결

권형하 휴대폰의 삼성 메시지 또는 Google 메시지에 도착하는 하나은행·하나카드 거래 알림을 푸른ERP 거래내역 대기함으로 전달하는 내부용 Android 앱입니다.

## 최초 연결

1. 푸른ERP → 재무관리 → 거래내역에서 `휴대폰 연결`을 누릅니다.
2. 휴대폰 앱에 PC 화면의 8자리 연결번호를 입력합니다.
3. `알림 접근 허용`을 누르고 `푸른 하나문자 연결`만 허용합니다.
4. 하나 거래문자가 도착한 뒤 ERP에서 `문자 가져오기`를 누릅니다.

## 보안 원칙

- `READ_SMS` 권한을 사용하지 않습니다.
- 삼성 메시지와 Google 메시지 알림만 확인합니다.
- 하나은행·하나카드 거래 형식이 아니면 휴대폰에서 버립니다.
- 인증번호·OTP·비밀번호가 포함된 알림은 휴대폰과 서버에서 이중 차단합니다.
- 연결키는 Android Keystore로 암호화합니다.
- 서버는 문자 원문을 저장하지 않고 거래일시·금액·입출금·가맹점만 보관합니다.

## 빌드

GitHub Actions의 `권형하 휴대폰 하나문자 앱 만들기` 작업에서 APK를 내려받습니다.
내부 배포용 debug APK이므로 설치할 때 Android의 `이 출처 허용`을 한 번 켜야 합니다.
